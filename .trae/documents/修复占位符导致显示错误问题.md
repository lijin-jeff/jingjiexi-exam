## 问题描述

第一次点击57题跳转正确，全部题目加载完成后，再次点击57题跳转到56题。

## 根本原因

合并逻辑添加了占位符，但 `activeQuestions` 和 `displayQuestionIndex` 没有过滤占位符：

1. `swiperList[56]` 是占位符（`isPlaceholder: true`）
2. `activeQuestions` 用 `find` 按 uid 查找，找到了占位符
3. 占位符的 `question: null`，导致显示错误

## 修复方案

### 修复1：修改 `activeQuestions` 过滤占位符（第807-819行）

```javascript
// 原代码
if (prevUid) {
  prevQ = this.swiperList.find(item => item.uid === prevUid);
}
if (currUid) {
  currQ = this.swiperList.find(item => item.uid === currUid);
}
if (nextUid && nextUid !== currUid) {
  nextQ = this.swiperList.find(item => item.uid === nextUid);
}

// 新代码
if (prevUid) {
  prevQ = this.swiperList.find(item => item.uid === prevUid && !item.isPlaceholder);
}
if (currUid) {
  currQ = this.swiperList.find(item => item.uid === currUid && !item.isPlaceholder);
}
if (nextUid && nextUid !== currUid) {
  nextQ = this.swiperList.find(item => item.uid === nextUid && !item.isPlaceholder);
}
```

### 修复2：修改 `displayQuestionIndex` 过滤占位符（第688-692行）

```javascript
// 原代码
const currentQuestion = this.swiperList[this.swiperCurrentIndex];
if (currentQuestion && currentQuestion.uid && this.simplifiedQuestionList) {
  const index = this.simplifiedQuestionList.findIndex(item => item.uid === currentQuestion.uid);
  if (index !== -1) {
    return index;
  }
}

// 新代码
const currentQuestion = this.swiperList[this.swiperCurrentIndex];
if (currentQuestion && currentQuestion.uid && !currentQuestion.isPlaceholder && this.simplifiedQuestionList) {
  const index = this.simplifiedQuestionList.findIndex(item => item.uid === currentQuestion.uid);
  if (index !== -1) {
    return index;
  }
}
```

## 影响范围

- 只影响 `activeQuestions` 和 `displayQuestionIndex`
- 不会影响其他组件或页面
- 修复后占位符不会导致显示错误

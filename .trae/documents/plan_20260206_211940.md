# 实现方式二：创建综合公用方法处理查询条件和排序规则

## 实现计划

### 1. 创建综合公用方法

创建一个名为 `prepareQuestionQuery` 的综合公用方法，该方法将：

- **处理通用参数**：
  - 处理 `uid`/`library_uid` 获取题库 ID
  - 处理 `selecte_type` 获取题目类型（全部、未做、已做、错题）
  - 处理 `random_type` 获取排序方式
  - 处理 `limit`/`question_count` 获取题目总数
  - 处理 `offset` 获取偏移量
  - 处理 `chapter_uid` 获取章节 ID 列表
  - 处理 `analysis_quid` 获取题目 UID 列表
  - 处理 `ratio_params` 获取题型比例

- **构建查询条件**：
  - 构建基础查询条件（`is_show`、`delete_time` 等）
  - 构建题库、章节、类型、难度等查询条件
  - 构建未做、已做、错题等特定类型的查询条件
  - 构建排序规则

- **返回结果**：
  - 返回准备好的查询对象
  - 返回处理后的参数
  - 返回排序方式

### 2. 修改 getQuestionStructure 方法

修改 `getQuestionStructure` 方法，让它：

- 调用 `prepareQuestionQuery` 方法处理参数和构建查询条件
- 根据返回的结果执行查询
- 处理按比例获取题目的逻辑
- 返回题目结构信息

### 3. 修改 orderOptionList 方法

修改 `orderOptionList` 方法，让它：

- 调用 `prepareQuestionQuery` 方法处理参数和构建查询条件
- 根据返回的结果执行查询
- 处理按比例获取题目的逻辑
- 处理题目详情的附加信息
- 返回题目列表

## 技术实现细节

### 1. prepareQuestionQuery 方法设计

```php
/**
 * 准备题目查询
 * @param array $params 查询参数
 * @return array [query, processedParams, sortMethod]
 */
private static function prepareQuestionQuery(array $params): array
{
    // 处理通用参数
    $libraryUid = $params['uid'] ?? $params['library_uid'] ?? null;
    $userId = $params['user_uid'] ?? null;
    $selecteType = $params['selecte_type'] ?? 1;
    $randomType = $params['random_type'] ?? 0;
    $questionCount = (int)($params['question_count'] ?? $params['limit'] ?? 50);
    $offset = (int)($params['offset'] ?? 0);
    $chapterUid = $params['chapter_uid'] ?? null;
    $analysisQuid = $params['analysis_quid'] ?? null;
    $ratioParams = $params['ratio_params'] ?? [];
    $examType = $params['exam_type'] ?? [];
    $examLevel = $params['exam_level'] ?? 0;
    
    // 构建章节 ID 列表
    $chapterUids = [];
    if (!empty($chapterUid) && $chapterUid !== 0) {
        $getAllChapterUids = function ($parentUid) use (&$getAllChapterUids) {
            $uids = [$parentUid];
            $children = TenantExamChapter::query()->where([
                ['parent_uid', '=', $parentUid],
                ['is_show', '=', 1]
            ])->column('uid');
            foreach ($children as $childUid) {
                $uids = array_merge($uids, $getAllChapterUids($childUid));
            }
            return $uids;
        };
        $chapterUids = $getAllChapterUids($chapterUid);
    }
    
    // 构建题目 UID 列表（用于未做、已做、错题）
    $optionUid = [];
    $doneQuestionIds = [];
    if (empty($analysisQuid)) {
        switch ($selecteType) {
            case 2:
                // 类型2：未做题目
                // 获取已做题目 ID 列表
                $optionUid = TenantExamExaminationHistory::query()
                    ->where(['user_uid' => $userId])
                    ->field('JSON_EXTRACT(options, "$[*].uid") as uids')
                    ->select()
                    ->map(function($item) {
                        $uids = $item['uids'] ?? '[]';
                        return json_decode($uids, true) ?? [];
                    })
                    ->toArray();
                $flattened = [];
                foreach ($optionUid as $subArray) {
                    if (is_array($subArray)) {
                        $flattened = array_merge($flattened, $subArray);
                    }
                }
                $optionUid = $flattened;
                break;
            case 3:
                // 类型3：已做题目
                // 获取已做题目 ID 列表
                $doneQuestionIds = TenantExamExaminationHistory::query()
                    ->where(['user_uid' => $userId])
                    ->field('JSON_EXTRACT(options, "$[*].uid") as uids')
                    ->select()
                    ->map(function($item) {
                        $uids = $item['uids'] ?? '[]';
                        return json_decode($uids, true) ?? [];
                    })
                    ->toArray();
                $flattened = [];
                foreach ($doneQuestionIds as $subArray) {
                    if (is_array($subArray)) {
                        $flattened = array_merge($flattened, $subArray);
                    }
                }
                $doneQuestionIds = $flattened;
                break;
            case 4:
                // 类型4：错题题目
                // 获取未被消灭的错题 ID 列表
                $doneQuestionIds = self::getErrorQuestionIds($userId, $params['uid'] ?? null);
                break;
            default:
                // 类型1：默认全部题目
                $doneQuestionIds = [];
                break;
        }
    } else {
        // 处理 analysis_quid 参数
        if (is_string($analysisQuid)) {
            $doneQuestionIds = explode(',', $analysisQuid);
            $doneQuestionIds = array_filter(array_map('trim', $doneQuestionIds));
        } else if (is_array($analysisQuid)) {
            $doneQuestionIds = $analysisQuid;
        } else {
            $doneQuestionIds = [$analysisQuid];
        }
        if (!is_array($doneQuestionIds)) {
            $doneQuestionIds = [];
        }
    }
    
    // 构建基础查询条件
    $query = Db::name('tenant_exam_question')->where([
        ['is_show', '=', 1],
        ['delete_time', '=', NULL]
    ]);
    
    // 构建题库、章节、类型、难度等查询条件
    if (!empty($libraryUid)) {
        $query->where('library_uid', '=', $libraryUid);
    }
    if (!empty($chapterUids)) {
        $query->where('chapter_uid', 'IN', $chapterUids);
    }
    if (!empty($examType)) {
        $query->where('exam_type', 'IN', $examType);
    }
    if (!empty($examLevel) && $examLevel !== 0) {
        $query->where('exam_level', '=', $examLevel);
    }
    if (!empty($optionUid)) {
        $query->where('uid', 'NOT IN', $optionUid);
    }
    if (!empty($doneQuestionIds)) {
        $query->where('uid', 'IN', $doneQuestionIds);
    }
    
    // 构建排序规则
    $sortMethod = $randomType;
    
    // 返回结果
    return [
        'query' => $query,
        'params' => [
            'libraryUid' => $libraryUid,
            'userId' => $userId,
            'selecteType' => $selecteType,
            'randomType' => $randomType,
            'questionCount' => $questionCount,
            'offset' => $offset,
            'chapterUids' => $chapterUids,
            'optionUid' => $optionUid,
            'doneQuestionIds' => $doneQuestionIds,
            'ratioParams' => $ratioParams,
            'examType' => $examType,
            'examLevel' => $examLevel
        ],
        'sortMethod' => $sortMethod
    ];
}

### 4. 修改 getQuestionStructure 方法

修改 `getQuestionStructure` 方法，让它调用 `prepareQuestionQuery` 方法处理参数和构建查询条件：

```php
public static function getQuestionStructure(array $params): array
{
    try {
        // 调用公用方法处理参数和构建查询条件
        $result = self::prepareQuestionQuery($params);
        $query = $result['query'];
        $processedParams = $result['params'];
        $sortMethod = $result['sortMethod'];
        
        $libraryUid = $processedParams['libraryUid'];
        if (empty($libraryUid)) {
            return [];
        }
        
        // 检查是否需要按比例获取题目
        if (!empty($processedParams['ratioParams']) && is_array($processedParams['ratioParams'])) {
            // 按比例获取题目
            $totalCount = $processedParams['questionCount'];
            $ratioParams = $processedParams['ratioParams'];
            
            // 计算各题型需要的数量
            $typeCounts = [];
            $remainingCount = $totalCount;
            
            // 首先计算每种题型的数量
            foreach ($ratioParams as $type => $percentage) {
                $count = round($totalCount * $percentage / 100);
                $typeCounts[$type] = $count;
                $remainingCount -= $count;
            }
            
            // 处理余数，分配给最后一种题型
            if ($remainingCount > 0 && !empty($typeCounts)) {
                end($typeCounts);
                $lastType = key($typeCounts);
                $typeCounts[$lastType] += $remainingCount;
            }
            
            // 分别查询每种题型的题目
            $questions = [];
            foreach ($typeCounts as $type => $count) {
                if ($count <= 0) continue;
                
                $typeQuery = clone $query;
                $typeQuery->where('exam_type', '=', $type);
                
                // 应用排序规则
                if ($sortMethod == 1) {
                    $typeQuery->orderRaw('RAND()');
                } else {
                    $typeQuery->order('sort', 'desc');
                }
                
                $typeQuestions = $typeQuery->field(['uid', 'exam_type'])->limit($count)->select();
                $questions = array_merge($questions, $typeQuestions->toArray());
            }
            
            return $questions;
        } else {
            // 传统方式获取题目
            // 应用排序规则
            if ($sortMethod == 1) {
                $query->orderRaw('RAND()');
            } else {
                $query->order('exam_type', 'asc')->order('sort', 'desc');
            }
            
            $questions = $query->field(['uid', 'exam_type'])->select();
            return $questions->toArray();
        }
    } catch (\Exception $e) {
        \think\facade\Log::error('获取题目结构信息失败: ' . $e->getMessage());
        return [];
    }
}
```

## 预期效果

通过实现方式二，创建一个综合公用方法 `prepareQuestionQuery`，我们可以：

1. **确保参数处理一致性**：`getQuestionStructure` 和 `orderOptionList` 方法使用相同的参数处理逻辑
2. **确保排序规则一致性**：两个方法使用相同的排序规则
3. **提高代码可维护性**：修改参数处理逻辑时，只需修改 `prepareQuestionQuery` 方法
4. **减少代码重复**：避免重复的参数处理和查询条件构建代码

这样，无论使用哪个方法查询题库，都能得到一致的结果，避免了因为参数处理或排序规则不同导致的题目顺序不一致问题。

# 修复fetchQuestionList方法的chunkIndex未定义错误

## 问题分析
通过分析错误信息和代码，发现了以下问题：

1. **错误信息**：`commonQuestion.vue:2016 题目加载异常: ReferenceError: chunkIndex is not defined`

2. **根本原因**：
   - `fetchQuestionList` 方法定义中没有参数：`async fetchQuestionList()`
   - 但在方法内部，代码尝试使用 `chunkIndex` 和 `chunkSize` 变量
   - 代码中混合使用了 `chunkIndex`（局部变量）和 `this.chunkIndex`（实例属性）

3. **具体问题位置**：
   - 第1752行：`if (chunkIndex === 0) {` - 尝试使用未定义的局部变量
   - 第1765行：`chunkIndex !== undefined && chunkSize !== undefined` - 尝试使用未定义的局部变量
   - 第1768-1773行：使用了 `this.chunkIndex` 和 `this.chunkSize` - 但这些实例属性可能未定义

## 实现计划

### 1. 修复fetchQuestionList方法定义
- 修改方法定义，添加默认参数：`async fetchQuestionList(chunkIndex = 0, chunkSize = 10)`
- 确保方法签名与调用方式一致

### 2. 统一变量使用方式
- 在方法内部统一使用方法参数 `chunkIndex` 和 `chunkSize`
- 替换所有 `this.chunkIndex` 和 `this.chunkSize` 为方法参数

### 3. 确保buildApiParams方法调用正确
- 确保调用 `this.buildApiParams()` 时传递正确的参数
- 或者修改 `buildApiParams` 方法，使其在没有参数时使用默认值

### 4. 测试和验证
- 测试题目加载功能是否正常
- 验证向右滑动和向左滑动时的加载逻辑
- 确保没有其他相关错误

## 技术要点
- 确保方法定义与内部使用的变量一致
- 统一变量使用方式，避免混合使用局部变量和实例属性
- 确保默认参数设置合理，与系统其他部分保持一致

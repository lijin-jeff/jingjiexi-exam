## 问题分析

当前多选题判断逻辑仅依赖选项数量（=5个选项），这会导致误判：
- 单选题有5个选项时会被误判为多选题
- 多选题有4个选项时无法识别

## 解决方案

优化题型判断逻辑，增加以下判断方式：

### 1. 正确答案格式检测
检查正确答案是否包含多个字母（如 "AB"、"ABC"、"ABCD"）

### 2. 题干特征词检测
检查题干中是否包含多选题特征词（如 "哪些"、"多项"、"多个"、"两项以上"）

### 3. 选项数量作为辅助判断
保留选项数量判断，但降低其优先级

## 修改内容

```javascript
// 根据选项数量和特征判断
if (optionsArray.length > 0) {
  // 获取正确答案
  const correctAnswer = (result.correct_answer || result.answer || '').toUpperCase()
  
  // 检查正确答案是否为多选格式（多个字母组合，如AB、ABC、ABCD）
  const isMultipleAnswer = /^[A-E]{2,}$/.test(correctAnswer.replace(/[,、\s]/g, ''))
  
  // 检查题干中的多选题特征词
  const multipleKeywords = ['哪些', '多项', '多个', '两项以上', '两项或以上', '至少两个']
  const hasMultipleKeyword = multipleKeywords.some(keyword => questionStem.includes(keyword))
  
  if (isMultipleAnswer || hasMultipleKeyword) {
    // 多选题
    examType = 2
    examTypeName = '多选题'
  } else if (optionsArray.length === 2) {
    // 判断题检测...
  }
}
```

## 预期结果

- 正确答案为 "AB"、"ABC" 等格式时，准确识别为多选题
- 题干包含 "哪些" 等特征词时，准确识别为多选题
- 减少单选题误判为多选题的情况

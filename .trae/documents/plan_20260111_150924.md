## 问题分析

当前资源编辑页面存在的问题：
1. 添加资源时，题库分类可以自由编辑，不符合业务需求
2. 题库分类应该与所选资源分类关联，使用资源分类的题库分类
3. 需要确保资源分类选择后，题库分类自动设置并不可编辑

## 修复方案

### 1. 修改页面结构

- 添加 `disabled` 属性到题库分类级联选择器
- 根据 `mode` 和资源分类选择状态动态控制 `disabled` 属性

### 2. 优化资源分类选择逻辑

- 修改 `handleChange` 方法，当选择资源分类后：
  - 自动获取该资源分类对应的 `exam_category_uid`
  - 将获取到的 `exam_category_uid` 设置到表单数据中
  - 确保表单验证通过

### 3. 调整表单验证规则

- 确保题库分类字段在添加模式下，即使不可编辑也能通过验证

### 4. 优化数据处理

- 确保资源分类数据包含 `exam_category_uid` 字段
- 处理资源分类为多级结构的情况

## 修复步骤

1. **修改级联选择器属性**：
   - 为题库分类级联选择器添加 `:disabled` 属性
   - 动态控制禁用状态

2. **更新 handleChange 方法**：
   - 实现资源分类选择后自动设置题库分类
   - 处理多级分类的情况

3. **优化表单验证**：
   - 确保题库分类字段在添加模式下能通过验证

4. **测试功能完整性**：
   - 确保添加资源时题库分类不可编辑
   - 确保题库分类自动使用资源分类的题库分类
   - 确保编辑资源时题库分类可以正常编辑

## 预期效果

1. **添加资源时**：
   - 题库分类级联选择器默认禁用
   - 选择资源分类后，题库分类自动填充并保持禁用
   - 表单可以正常提交

2. **编辑资源时**：
   - 题库分类级联选择器可以正常编辑
   - 保持原有功能不变

3. **用户体验**：
   - 减少用户操作步骤
   - 确保数据一致性
   - 提高添加资源的效率

## 技术实现

- 使用 Vue 3 的响应式系统动态控制禁用状态
- 利用级联选择器的 `change` 事件实现自动填充
- 确保资源分类数据包含必要的 `exam_category_uid` 字段
- 调整表单验证规则以适应新的业务逻辑

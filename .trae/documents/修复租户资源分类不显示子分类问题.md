## 修复方案

基于对比分析和 Element Plus 官方文档，修复租户资源分类不显示子分类的问题：

### 1. 统一 row-key 配置
将 `tenant_resource_category/index.vue` 中的表格 row-key 从 "uid" 改为 "id"，与参考文件保持一致：

```vue
<el-table
    :data="pager.lists"
    row-key="id"  <!-- 从 uid 改为 id -->
    :tree-props="{ children: 'children', hasChildren: 'hasChildren' }"
>
```

### 2. 设置默认展开（可选）
为了更直观地显示子分类，设置默认展开所有节点：

```vue
<el-table
    :data="pager.lists"
    row-key="id"
    :default-expand-all="true"  <!-- 新增默认展开 -->
    :tree-props="{ children: 'children', hasChildren: 'hasChildren' }"
>
```

### 3. 确保 usePaging 正确处理数据
验证 usePaging 钩子能正确从 API 响应中获取树形结构数据。

这个修复将确保 Element Plus 表格能正确识别和渲染树形结构，从而显示子分类。

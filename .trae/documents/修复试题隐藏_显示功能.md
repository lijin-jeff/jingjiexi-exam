## 修复试题隐藏/显示功能计划

### 问题分析

当前的实现存在以下问题：
1. **功能单一**：只能隐藏试题，不能切换显示状态
2. **参数固定**：始终将 `is_show` 设置为 0（隐藏）
3. **操作后移除**：成功后直接从列表中移除试题，无法再次操作

### 修复计划

#### 1. 修改 `handleHideQuestion` 方法

* **文件**: `c:\Users\44343\jingjiexi\my_client1\subpages\examEdit\index.vue`

* **功能**: 实现正确的隐藏/显示切换逻辑

* **步骤**:
  * 根据当前试题的 `is_show` 状态切换显示/隐藏
  * 调用 API 时传递正确的 `is_show` 值
  * 操作成功后更新本地数据列表中的 `is_show` 状态
  * 提供清晰的操作反馈

#### 2. 更新操作菜单文本（可选）

* **文件**: `c:\Users\44343\jingjiexi\my_client1\subpages\examEdit\index.vue`

* **功能**: 根据当前试题状态显示相应的菜单文本

* **步骤**:
  * 动态生成操作菜单，根据试题的 `is_show` 状态显示 "隐藏" 或 "显示"

### 技术实现要点

1. **状态检测**:
   * 检查 `item.is_show` 值，1 表示显示，0 表示隐藏
   * 切换时设置相反的值

2. **API 调用**:
   * 使用 `this.$api.apiExamQuestionHide` 方法
   * 传递正确的 `uid` 和 `is_show` 参数

3. **本地数据更新**:
   * 操作成功后，更新本地 `questionList` 中对应试题的 `is_show` 状态
   * 不从列表中移除试题，以便可以再次操作

4. **用户反馈**:
   * 根据操作类型显示 "隐藏成功" 或 "显示成功"
   * 使用 `uni.showToast` 提供操作反馈

### 预期效果

* 点击 "隐藏/显示" 菜单项时，能够正确切换试题的显示状态
* 操作成功后，本地数据列表会相应更新
* 用户会收到清晰的操作反馈
* 可以重复对同一试题进行隐藏/显示操作

### 验证步骤

1. **隐藏操作**:
   * 选择一个显示状态的试题
   * 点击 "隐藏/显示" 菜单
   * 验证试题状态变为隐藏
   * 验证收到 "隐藏成功" 提示

2. **显示操作**:
   * 选择一个隐藏状态的试题
   * 点击 "隐藏/显示" 菜单
   * 验证试题状态变为显示
   * 验证收到 "显示成功" 提示

3. **重复操作**:
   * 对同一试题多次执行隐藏/显示操作
   * 验证每次操作都能正确切换状态

通过这些修改，隐藏/显示功能将能够正确切换试题的显示状态，提供更好的用户体验。

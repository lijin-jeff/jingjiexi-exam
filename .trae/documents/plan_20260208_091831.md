## 问题描述

首次点击57题加载正确，但左滑时一次跳了2题（从57题直接跳到55题），再次点击57题显示错误题目。

## 根本原因

`handleSwiperChange` 方法的滑动逻辑错误：

1. 当从57题（索引56）左滑时，计算 `targetQuestionNum = 55`（前一题）
2. 但 `activeQuestions` 数组可能包含错误的题目顺序
3. 导致实际跳转到了更前面的题目

## 修复方案

### 修改 `handleSwiperChange` 滑动逻辑（第3079-3084行）

```javascript
// 原逻辑：简单递减题号
if (swiperIndex === 0) {
  // 向左滑动，显示前一题
  targetQuestionNum = Math.max(0, currentQuestionNum - 1);
}

// 新逻辑：使用 activeQuestions 数组的索引
if (swiperIndex === 0) {
  // 向左滑动，显示前一题
  // 直接基于 activeQuestions 数组计算，避免题号计算错误
  const currentIndex = this.swiperCurrentIndex;
  targetQuestionNum = Math.max(0, currentIndex - 1);
}
```

## 根本原因确认

在 `handleQuestionChange` 方法中（第3141行）：
```javascript
this.swiperCurrentIndex = actualIndex;
```

这里使用 `actualIndex`（题目在 `swiperList` 中的索引）作为 `swiperCurrentIndex`。

**问题：**
- `simplifiedQuestionList` 和 `swiperList` 可能保持不同的题目顺序
- 57题在 `simplifiedQuestionList` 中的索引是56
- 但57题在 `swiperList` 中的索引可能是41（因为顺序不一致）
- 设置 `swiperCurrentIndex = 41` 后，向左滑动到40
- 显示 `simplifiedQuestionList[40]`，即42题

## 修复方案

将 `handleQuestionChange` 中的：
```javascript
this.swiperCurrentIndex = actualIndex;
this.swiperDisplayIndex = actualIndex;
```

改为：
```javascript
this.swiperCurrentIndex = index;
this.swiperDisplayIndex = index;
```

因为 `swiperCurrentIndex` 应该表示当前题号索引（从0开始），而不是题目在 `swiperList` 中的位置。

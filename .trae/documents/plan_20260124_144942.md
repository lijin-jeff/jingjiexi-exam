# 错题检测与自动消灭功能实现方案

## 问题分析
当前 `submitExamination` 方法已经实现了将答错题目存入错题表的功能，以及手动消灭错题的功能，但缺少根据用户设置自动消灭错题的逻辑。需要实现以下功能：
1. 当用户答对题目时，检查该题目是否是错题
2. 如果是错题，更新其 `correct_count`
3. 根据用户的 `auto_eliminate_threshold` 设置，判断是否自动消灭错题
4. 如果符合条件，自动将错题状态设为已消灭

## 修复方案

### 1. 新增用户设置查询逻辑
在答题提交处理完成后，获取用户的 `auto_eliminate_threshold` 设置，用于判断是否自动消灭错题。

### 2. 新增答对题目处理逻辑
- 遍历答对的题目，检查是否存在于错题表中
- 如果是错题，更新 `correct_count` 字段
- 根据用户设置的 `auto_eliminate_threshold`，判断是否自动消灭错题

### 3. 新增自动消灭错题逻辑
- 当 `correct_count` 达到用户设置的阈值时，自动将 `eliminated_status` 设为1
- 更新 `eliminated_at` 和 `eliminated_by` 字段

### 4. 完善高频错题判断
- 在更新错题记录时，检查 `error_count` 是否 ≥ 2
- 如果是，将 `is_high_frequency` 设为1

## 具体实现步骤

### 1. 导入必要的模型
确保已经导入 `TenantExamQuestionError` 和 `User` 模型。

### 2. 添加自动消灭错题处理函数
```php
/**
 * 处理自动消灭错题
 * @param array $correctOptionUid 答对的题目UID列表
 * @param string $userUid 用户UID
 * @param array $optionItems 答题数据
 */
private static function handleAutoEliminateError(array $correctOptionUid, string $userUid, array $optionItems): void
{
    // 获取用户设置的自动消灭阈值
    $userSetting = User::where('uid', $userUid)->value('auto_eliminate_threshold') ?: 2;
    
    // 如果没有答对题目，直接返回
    if (empty($correctOptionUid)) {
        return;
    }
    
    // 将optionItems转换为以uid为键的数组，便于快速查找
    $optionItemsMap = array_column($optionItems, null, 'uid');
    
    // 遍历答对的题目
    foreach ($correctOptionUid as $questionUid) {
        // 检查是否是错题
        $errorRecord = TenantExamQuestionError::where('question_uid', $questionUid)
            ->where('user_uid', $userUid)
            ->find();
        
        if ($errorRecord) {
            // 获取用户答案
            $userAnswer = $optionItemsMap[$questionUid]['user_answer'] ?? '';
            
            // 更新正确次数
            $newCorrectCount = ($errorRecord->correct_count ?? 0) + 1;
            
            // 准备更新数据
            $updateData = [
                'correct_count' => $newCorrectCount,
                'update_time' => time(),
                'user_answer' => $userAnswer
            ];
            
            // 检查是否需要自动消灭
            if ($newCorrectCount >= $userSetting) {
                $updateData['eliminated_status'] = 1;
                $updateData['eliminated_at'] = date('Y-m-d H:i:s');
                $updateData['eliminated_by'] = 'auto';
            }
            
            // 更新错题记录
            TenantExamQuestionError::where('id', $errorRecord->id)->update($updateData);
        }
    }
}
```

### 3. 在答题提交流程中调用自动消灭函数
在 `submitExamination` 方法中，处理完答错题目存入错题表后，调用新增的自动消灭函数：

```php
// 将答错题目存入错题表
if (!empty($errorOptionUid)) {
    // ... 原有逻辑 ...
}

// 新增：处理答对题目，检查是否需要自动消灭错题
self::handleAutoEliminateError($correctOptionUid, $userUid, $optionItems);
```

### 4. 完善错题更新逻辑
在答错题目存入错题表的逻辑中，添加高频错题判断：

```php
// 准备错题数据
$errorData = [
    // ... 原有字段 ...
    'update_time' => $now,
];

// 如果不存在，则插入
if (!$exists) {
    $errorData['create_time'] = $now;
    $errorData['error_count'] = 1;
    $errorData['is_high_frequency'] = 0;
    $result = TenantExamQuestionError::create($errorData);
} else {
    // 更新错误次数
    $errorData['error_count'] = ($exists->error_count ?? 0) + 1;
    // 判断是否为高频错题
    $errorData['is_high_frequency'] = $errorData['error_count'] >= 2 ? 1 : 0;
    
    $result = TenantExamQuestionError::query()
        ->where('id', $exists['id'])
        ->update($errorData);
}
```

## 预期效果

### 1. 高频错题自动标记
- 当用户答错同一题目2次或以上时，自动将 `is_high_frequency` 设为1
- 方便用户快速识别需要重点复习的题目

### 2. 自动消灭错题
- 用户可在设置中选择"答对1次自动消灭"或"答对2次自动消灭"
- 当用户答对题目次数达到设置的阈值时，自动将错题状态设为已消灭
- 减少用户手动操作，提高学习效率

### 3. 增强用户体验
- 系统根据用户设置自动处理错题状态
- 用户无需手动操作，专注于学习内容
- 个性化设置满足不同用户的学习习惯

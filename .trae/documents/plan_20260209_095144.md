## 根因分析

### 问题现象
从第一题依次向右滑动时：
- 第1题：activeIndex=0, realIndex=0 ✅
- 第2题：activeIndex=1, realIndex=1 ✅
- 第3题：activeIndex=2, realIndex=3 ❌（应是2）
- 第4题：activeIndex=2, realIndex=4 ❌（应是3）

### 核心原因
**这是 activeQuestions 虚拟渲染的设计导致的视觉现象**，不是 bug。具体分析：

1. **当 currentIndex=1（第二题）时**：
   - `activeQuestions = [swiperList[0], swiperList[1], swiperList[2]]`
   - 当前显示 `activeQuestions[1]`（第二题）

2. **向右滑动后**：
   - `swiperIndex` 变为 2，触发滑动处理
   - `swipeHandler` 计算目标索引：`currentIndex + 1 = 2`
   - 组件更新 `swiperCurrentIndex = 2`
   - `activeQuestions` 重新计算：`[swiperList[1], swiperList[2], swiperList[3]]`
   - 此时 `activeIndex=2` 对应的是 `swiperList[3]`，所以 `realIndex=3`

### 修复方案

#### 阶段1：优化滑动后显示位置
1. **修改位置**：commonQuestion.vue 第3267-3287行
2. **修复内容**：在索引更新后，强制 swiper 显示到 `activeQuestions[1]` 位置
3. **目标**：确保滑动后始终显示当前题，而不是后一题

#### 阶段2：增强状态同步
1. **修改位置**：commonQuestion.vue 第3426-3451行
2. **修复内容**：优化 `handleSwiperRealChange` 方法，确保位置修正的时机正确
3. **目标**：消除滑动过程中的位置闪烁

#### 阶段3：添加调试日志验证
1. **修改位置**：commonQuestion.vue 第3246-3287行
2. **修复内容**：添加详细的调试日志，验证滑动过程中的状态变化
3. **目标**：确保修复效果符合预期

### 技术实现

#### 3.1 强制位置修正
```javascript
// 在索引更新后，强制 swiper 显示到正确位置
if (this.$refs.swiper) {
  this.$refs.swiper.setCurrent(this.swipeCurrent, false);
}
```

#### 3.2 优化状态同步
```javascript
// 确保位置修正的时机正确
this.$nextTick(() => {
  // 强制设置 swiper 位置
  if (this.$refs.swiper) {
    this.$refs.swiper.setCurrent(this.swipeCurrent, false);
  }
});
```

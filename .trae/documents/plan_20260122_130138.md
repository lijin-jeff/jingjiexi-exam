# 修复按住拖动调整科目顺序功能

## 问题分析
1. **模板数据访问错误**：tn-drag 组件的 slot 中，entity 是通过 `item.data` 传递的，但当前模板直接使用 `entity.name` 访问
2. **dragList 结构与组件预期不符**：tn-drag 组件内部会将传入的 list 数据包装成特定结构，但当前 dragList 直接传递了原始数据
3. **onDragChange 方法处理错误**：change 事件传递的 event.data 是包装后的列表，需要正确处理

## 修复方案

### 1. 修复模板数据访问
将模板中 `{{ entity.name }}` 改为 `{{ entity.data.name }}`，确保正确访问科目名称

### 2. 修复 dragList 结构
恢复 dragList 为组件预期的格式：
```javascript
dragList() {
  return this.localMySubjects.map((subject, index) => ({
    id: subject.id,
    data: subject,
    fixed: false
  }))
}
```

### 3. 修复 onDragChange 方法
确保正确处理 change 事件传递的数据：
```javascript
onDragChange(event) {
  const newList = event.data || []
  this.localMySubjects = newList.map(item => item.data)
  
  this.$emit('sort', [...this.localMySubjects])
  
  if (this.autoSave) {
    this.saveSubjectsToStorage(this.localMySubjects)
  }
}
```

### 4. 确保组件属性完整
- 确认传递了所有必要的属性
- 保持 `:columns="4"` 确保正确的网格布局
- 保持 `:item-height="120"` 提供足够的拖拽区域
- 保持 `:edit="true"` 确保拖拽功能开启

## 修复原理
根据 tn-drag.vue 源码，组件内部会将传入的 list 数据重新包装为包含 `id`、`fixed` 和 `data` 属性的对象，slot 中通过 `entity` 传递的是 `item.data`。因此需要确保：
1. 模板中正确访问 `entity.data.name`
2. onDragChange 方法中通过 `item.data` 获取原始数据

## 预期效果
修复后，用户可以按住已选中的科目进行拖动调整顺序，拖拽过程中有视觉反馈，拖拽完成后科目顺序会更新并自动保存。

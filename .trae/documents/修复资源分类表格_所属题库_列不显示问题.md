## 问题分析

表格中第79行"所属题库"列不显示的原因是：
1. 表格使用 `prop="exam_category_title"` 绑定数据
2. TenantResourceCategory 模型中缺少 `exam_category_title` 虚拟字段
3. 虽然 API 接口中会手动处理该字段，但模型本身没有定义，可能导致数据传递异常

## 修复方案

### 1. 在 TenantResourceCategory 模型中添加虚拟字段

修改 `c:\Users\44343\jingjiexi\server\app\common\model\resource\TenantResourceCategory.php` 文件，添加 `exam_category_title` 虚拟字段：

```php
/**
 * 获取所属题库分类名称
 * @param $value
 * @param $data
 * @return mixed|tring
 */
public function getExamCategoryTitleAttr($value, $data)
{
    if (isset($this->examCategory) && $this->examCategory) {
        return $this->examCategory->title;
    }
    return '';
}
```

### 2. 确保 API 接口正确关联查询

检查并确保 `c:\Users\44343\jingjiexi\server\app\api\logic\resource\TenantResourceCategoryLogic.php` 文件中的 `lists` 方法正确关联了 `examCategory`：

```php
// 确保在查询时关联了 examCategory
$list = $query->with(['children', 'examCategory'])->select()->toArray();
```

### 3. 优化 API 数据返回处理

确保 API 接口在返回数据时，`exam_category_title` 字段被正确设置：

```php
// 如果手动处理逻辑存在问题，优化该逻辑
foreach ($list as &$item) {
    $item['exam_category_title'] = $item['exam_category']['title'] ?? '';
    unset($item['exam_category']);
}
```

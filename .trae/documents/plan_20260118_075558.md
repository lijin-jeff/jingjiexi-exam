## 修复导航链接参数问题

### 问题分析
1. **参考代码** (`examinationHistory.vue#L651`)：使用字符串格式的uid（包含多个题目uid）
   ```javascript
   this.$func.navigatorTo('/subpages/examHistory/history/chart?uid=' + item.uid + '&examination_uid=' + this.queryParams.uid);
   ```

2. **当前代码** (`analysis.vue#L746`)：使用单个uid（考试记录的uid）
   ```javascript
   this.$func.navigatorTo('/subpages/examHistory/history/chart?uid=' + this.uid + '&examination_uid=' + this.examination_uid);
   ```

3. **关键发现**：`analysis.vue` 中已经有 `this.allQuestionUid` 变量，它是通过 `optionsList.map(item => item.uid).filter(uid => uid).join(',')` 生成的所有题目uid的字符串

### 修复方案
1. 修改 `analysis.vue` 的 `showChart` 方法
2. 将 `this.uid` 替换为 `this.allQuestionUid`
3. 保持 `examination_uid` 参数不变

### 预期效果
- 当用户点击查看图表时，会传递所有题目的uid字符串给图表页面
- 与 `examinationHistory.vue` 的导航链接格式保持一致
- 确保图表页面能够正确显示所有题目的数据

## 真正的问题确认

在 `handleSwiperTransition` 中（第2720-2727行）：
```javascript
if (dx > 0) {
  predictedIndex = Math.min(currentRealIndex + 1, listLength - 1);
} else {
  predictedIndex = Math.max(currentRealIndex - 1, 0);
}
this.transitionQuestionIndex = predictedIndex;
```

这里假设 `currentRealIndex ± 1` 就是上一题/下一题。但当 `swiperList` 顺序与 `simplifiedQuestionList` 不一致时，这个假设是错误的。

例如：
- 57题在 `swiperList` 中的索引是41
- `currentRealIndex = 41`
- 向左滑动时，`predictedIndex = 40`
- 但 `swiperList[40]` 可能是42题，而不是56题

## 修复方案

禁用 `transitionQuestionIndex` 的验证逻辑，强制使用备用方案（基于swiperIndex计算），然后在我的修复代码中基于题号索引计算正确的 `swiperList` 索引。

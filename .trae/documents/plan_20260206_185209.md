# 修复打开答题卡影响题号的问题

## 问题分析

打开答题卡会影响题号的原因：

1. **计算逻辑变化**：打开答题卡后，`displayQuestionIndex` 计算属性会优先使用 `simplifiedQuestionList` 中的索引作为题号，而不是 `swiperCurrentIndex`

2. **数据源不一致**：`getQuestionStructure()` 和 `fetchQuestionList()` 可能返回不同顺序或数量的题目

3. **顺序差异**：如果两个 API 返回的题目顺序不同，题号会发生变化

## 修复方案

### 1. 修复 `displayQuestionIndex` 计算属性

修改 `displayQuestionIndex` 计算属性，确保其在打开答题卡前后保持一致的行为：

```javascript
displayQuestionIndex() {
  const currentQuestion = this.swiperList[this.swiperCurrentIndex];
  if (!currentQuestion) {
    return this.swiperCurrentIndex;
  }
  
  // 始终使用 swiperCurrentIndex 作为题号，确保打开答题卡前后一致
  return this.swiperCurrentIndex;
}
```

### 2. 确保 `simplifiedQuestionList` 与 `swiperList` 顺序一致

修改 `handleShowAnswerCard` 方法，确保 `simplifiedQuestionList` 与 `swiperList` 的顺序一致：

```javascript
handleShowAnswerCard() {
  // ... 现有代码 ...
  
  // 构建精简的题目列表（包含uid和题型）
  // 确保顺序与 swiperList 一致
  const simplifiedQuestionList = this.swiperList.map((item, index) => ({

    user_answer: this.getUserAnswer(item.uid),
    is_correct: this.getQuestionCorrectness(item.uid)
  }));
  
  // ... 现有代码 ...
}
```

### 3. 优化 `getQuestionStructure` 方法

修改 `getQuestionStructure` 方法，确保其返回的题目顺序与 `swiperList` 一致：

```javascript
getQuestionStructure() {
  return new Promise((resolve, reject) => {
    // 如果已经有 swiperList，直接使用其数据构建 simplifiedQuestionList
    if (this.swiperList && this.swiperList.length > 0) {
      console.log('[getQuestionStructure] 使用 swiperList 构建 simplifiedQuestionList');
      // 直接基于 swiperList 构建 simplifiedQuestionList
      const simplifiedQuestionList = this.swiperList.map((item, index) => ({
        uid: item.uid,
        exam_type: item.exam_type,
        // 保持与原有结构兼容的字段
        is_answered: this.checkIfAnswered(item.uid),
        user_answer: this.getUserAnswer(item.uid),
        is_correct: this.getQuestionCorrectness(item.uid)
      }));
      resolve(simplifiedQuestionList);
      return;
    }
    
    // 否则调用 API 获取
    const params = {
      uid: this.questionParams.uid || this.questionParams.library_uid,
      ratio_params: this.ratioParams,
      question_count: this.questionParams.question_count || 50
    };
    
    this.$api.getQuestionStructure(params).then(res => {
      if (res.code === 1) {
        resolve(res.data);
      } else {
        reject(res.msg);
      }
    }).catch(err => {
      reject(err);
    });
  });
}
```

## 修复效果

1. **题号一致性**：打开答题卡前后题号保持一致，不会发生变化

2. **用户体验**：用户不会看到题号突然变化，提升用户体验

3. **逻辑清晰**：题号计算逻辑更加清晰，避免混淆

4. **性能优化**：如果已经有 `swiperList`，直接使用其数据构建 `simplifiedQuestionList`，减少 API 调用

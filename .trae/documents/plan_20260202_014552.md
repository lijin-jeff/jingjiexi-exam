## 滑动切换异常跳转问题修复计划

### 问题根因
从第2题滑动到第3题时会跳到第4题，原因是：
1. swiper的`:current`绑定不直接，导致同步问题
2. 防抖机制不足以应对极端情况
3. 缺少对滑动变化的一致性验证

### 修复方案

#### 1. 修改swiper的current绑定
```vue
<swiper :current="swipeCurrent" ...>
```
- 添加`swipeCurrent`计算属性，直接反映当前swiper位置
- 确保与`virtualSwiperList`同步

#### 2. 增强handleSwiperChange
- 增加一致性验证：检查swiperIndex是否与预期一致
- 延长防抖时间到200ms
- 添加滑动方向验证

#### 3. 添加swipeCurrent计算属性
```javascript
swipeCurrent() {
  const listLength = this.swiperList.length
  if (listLength <= 3) {
    return this.swiperCurrentIndex
  }
  if (this.swiperCurrentIndex === 0) {
    return 0
  } else if (this.swiperCurrentIndex === listLength - 1) {
    return 2
  }
  return 1
}
```

### 测试验证
- 测试场景1：第2题→第3题（慢速滑动）
- 测试场景2：第2题→第3题（快速滑动）
- 测试场景3：第5题→第4题（反向滑动）
- 测试场景4：边界题切换（第1题↔第2题，最后一题↔倒数第二题）

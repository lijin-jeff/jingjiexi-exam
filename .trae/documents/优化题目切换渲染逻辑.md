## 修改计划

### 目标
将题目切换的渲染逻辑从"始终渲染3个题目"优化为：
- 第一题时渲染2个题目（当前题+后一题）
- 中间题渲染3个题目（前一题+当前题+后一题）
- 最后一题渲染2个题目（前一题+当前题）

### 修改文件
1. **commonQuestion.vue**
   - `activeQuestions` 计算属性
   - `swipeCurrent` 计算属性
   - `handleSwiperChange` 方法

2. **swipeHandler.js**
   - `handleSwipe` 方法

### 修改内容

#### 1. activeQuestions 计算属性
```javascript
// 根据位置返回2个或3个题目
- 第一题：返回 [题1, 题2]
- 中间题：返回 [题n-1, 题n, 题n+1]
- 最后一题：返回 [题n-1, 题n]
```

#### 2. swipeCurrent 计算属性
```javascript
// 动态计算当前索引
- 第一题：返回 0
- 其他情况：返回 1
```

#### 3. swipeHandler.js
```javascript
// 支持动态长度和边界判断
- 接收 activeQuestionsLength 参数
- 根据当前题目位置判断滑动方向
- 处理第一题和最后一题的边界情况
```

#### 4. handleSwiperChange 方法
```javascript
// 传入 activeQuestions 长度
- 调用 swipeHandler 时传入 activeQuestionsLength
```

### 测试验证
1. 第一题右滑到第二题
2. 第二题左滑到第一题
3. 最后一题左滑到倒数第二题
4. 答题卡跳转到第一题和最后一题
5. 边界滑动限制（第一题不能左滑，最后一题不能右滑）

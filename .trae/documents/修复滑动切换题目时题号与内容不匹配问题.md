## 问题描述

当用户从最后一题（57题）向左滑动执行上一题切换操作时，题号正确更新为56题，但题目内容区域错误地显示了55题的信息。这表明滑动操作实际切换了两道题目。

## 根本原因

`swipeCurrent` computed 属性基于 `displayQuestionIndex` 计算，而 `displayQuestionIndex` 又依赖于 `swiperCurrentIndex`。当 `handleSwiperChange` 更新 `swiperCurrentIndex` 后，`displayQuestionIndex` 和 `activeQuestions` 都会立即重新计算，导致 `swipeCurrent` 返回的 Swiper 位置与实际滑动位置不一致。

## 修复方案

**方案3：移除** **`swipeCurrent`** **对** **`displayQuestionIndex`** **的依赖**

让 `swipeCurrent` 直接基于 `swiperCurrentIndex` 计算，保持与 `handleSwiperChange` 的一致性。

## 具体修改

### 1. 修改 `swipeCurrent` 计算属性（第707-760行）

将原来的逻辑：

```javascript
swipeCurrent() {
  const currentIndex = this.swiperCurrentIndex;
  const currentQuestion = this.swiperList[currentIndex];
  // ... 在 activeQuestions 中通过 uid 查找位置
}
```

改为直接基于 `swiperCurrentIndex`：

```javascript
swipeCurrent() {
  const currentIndex = this.swiperCurrentIndex;
  const currentQuestion = this.swiperList[currentIndex];
  // ... 在 activeQuestions 中通过 uid 查找位置
}
```

### 2. 同步修改 `activeQuestions` 计算属性（第776-817行）

确保 `activeQuestions` 也基于 `swiperCurrentIndex` 计算，而非 `displayQuestionIndex`：

```javascript
activeQuestions() {
  const currentIndex = this.swiperCurrentIndex;
  // 获取前一题、当前题、后一题的索引
  const prevIndex = Math.max(0, currentIndex - 1);
  const currIndex = currentIndex;
  const nextIndex = Math.min(this.swiperList.length - 1, currentIndex + 1);
  // ... 返回对应的题目
}
```

## 预期效果

* 题号显示（`displayQuestionIndex`）与题目内容（`activeQuestions`）保持同步

* 滑动切换时只切换一道题目，不会出现跳题现象

* `swipeCurrent` 返回的 Swiper 位置与实际滑动

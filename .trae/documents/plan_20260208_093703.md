## 问题描述

首次点击57题加载正确，但左滑时一次跳了2题（从57题直接跳到55题），再次点击57题显示错误题目。

## 根本原因

Swiper 组件配置和滑动逻辑不一致：

1. Swiper 组件使用 `:current="swipeCurrent"`
2. 但 `handleSwiperChange` 方法使用 `swiperCurrentIndex` 计算目标题目
3. 导致滑动时索引计算错误，一次跳了2题

## 修复方案

### 修复1：修改 `handleSwiperChange` 滑动逻辑（第3062行）

```javascript
// 原逻辑
const currentQuestionNum = this.swiperCurrentIndex;

// 新逻辑
const currentQuestionNum = this.displayQuestionIndex;
```

### 修复2：确保 `swipeCurrent` 计算正确（检查相关计算逻辑）

### 修复3：统一滑动逻辑和 activeQuestions 构建

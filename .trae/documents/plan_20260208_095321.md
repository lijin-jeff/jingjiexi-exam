# 滑动处理逻辑替换计划

## 目标

将 `commonQuestion.vue` 中的复杂滑动处理逻辑替换为使用 `swipeHandler.js` 工具类，简化代码并解决滑动跳题问题。

## 步骤

### 步骤1：导入 swipeHandler 工具类

在 `commonQuestion.vue` 顶部添加导入语句：

```javascript
import swipeHandler from '../utils/swipeHandler';
```

### 步骤2：修改 handleSwiperChange 方法

替换现有的复杂逻辑，使用 swipeHandler 处理滑动：

```javascript
// 原逻辑
async handleSwiperChange(e) {
  // 复杂的滑动处理逻辑...
}

// 新逻辑
async handleSwiperChange(e) {
  try {
    // 使用 swipeHandler 处理滑动
    const result = await swipeHandler.handleSwipe({
      event: e,
      currentIndex: this.swiperCurrentIndex,
      items: this.swiperList,
      swiperDisplayIndex: this.displayQuestionIndex
    });
    
    if (result.newIndex !== undefined && result.newIndex !== this.swiperCurrentIndex) {
      // 更新用户浏览速度
      const timeSpent = Date.now() - (this._lastSwiperChangeTime || Date.now());
      this.updateUserSpeed(this.swiperCurrentIndex, result.newIndex, timeSpent);
      
      console.log('[handleSwiperChange] 滑动处理结果:', {
        currentIndex: this.swiperCurrentIndex,
        newIndex: result.newIndex
      });
      
      // 更新 swiperCurrentIndex
      this.swiperCurrentIndex = result.newIndex;
      
      // 重置状态
      this._lastProcessedIndex = -1;
      this.forceShowAnswer = false;
      this._cachedQuestionIndex = -1;
      this._cachedCurrentQuestion = null;
      
      // 保存进度
      this.triggerAutoSave();
      
      // 使用 displayQuestionIndex 触发预加载
      this.smartPreload(this.displayQuestionIndex);
    }
    
    // 更新最后滑动时间
    this._lastSwiperChangeTime = Date.now();
    
    // 重置滑动状态标志
    this.$nextTick(() => {
      this.isUserSwiping = false;
      this.transitionQuestionIndex = -1;
    });
    
  } catch (error) {
    console.error('[handleSwiperChange] 滑动处理错误:', error);
    this._lastSwiperChangeTime = Date.now();
    this.$nextTick(() => {
      this.isUserSwiping = false;
      this.transitionQuestionIndex = -1;
    });
  }
}
```

### 步骤3：移除冗余逻辑

删除不再需要的滑动相关冗余代码，包括：
- 复杂的索引计算逻辑
- 重复的边界检查
- 冗余的加载逻辑

### 步骤4：添加重置机制

在适当的位置添加 swipeHandler 重置：

```javascript
// 例如在页面初始化或重置时
onLoad() {
  // 其他初始化逻辑...
  swipeHandler.reset();
}

// 或者在切换模式时
switchMode() {
  // 其他逻辑...
  swipeHandler.reset();
}
```

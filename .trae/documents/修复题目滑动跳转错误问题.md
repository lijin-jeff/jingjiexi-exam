## 问题描述

从51题左滑跳转到43题（应该跳转到50题）

## 根本原因

`handleSwiperChange` 方法依赖 `activeQuestions` 的索引来获取目标题目，但 `activeQuestions` 在边界情况下会用当前题填充，导致索引和实际题号不匹配。

## 修复方案

### 修复1：修改 `handleSwiperChange` 方法（第3026-3088行）

根据滑动方向（swiperIndex）计算目标题号，而不是依赖 `activeQuestions` 的索引：

* swiperIndex === 0（左滑）：目标题号 = currentQuestionNum - 1

* swiperIndex === 1（当前）：不处理

* swiperIndex === 2（右滑）：目标题号 = currentQuestionNum + 1

### 修复2：移除 `loadPreviousChunkIfNeeded` 中的错误跳转补偿（第3446-3460行）

删除加载上一块后强制跳转到上一块最后一个题的逻辑。

// 在 simplifiedQuestionList 中查找目标题目的 uid

// 在 swiperList 中查找对应的题目
let newRealIndex = this.swiperList.findIndex(item => item.uid === targetUid);

// 如果找不到，说明需要加载对应的块
if (newRealIndex === -1) {

  const targetChunkIndex = Math.floor(targetQuestionNum / chunkSize);

    await this.loadNextChunkIfNeeded();

  newRealIndex = this.swiperList.findIndex(item => item.uid === targetUid);

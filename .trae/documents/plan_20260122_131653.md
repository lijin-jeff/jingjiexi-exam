# 微信小程序拖拽兼容性修复

## 问题分析
1. **HTML5拖放API不兼容**：微信小程序不支持HTML5的拖放API（draggable, dragstart, dragenter等）
2. **DOM操作不兼容**：`document.querySelectorAll`在微信小程序中不被支持
3. **事件对象结构不同**：微信小程序的触摸事件对象结构与Web不同
4. **样式处理差异**：微信小程序的样式处理有自己的规则
5. **事件处理差异**：微信小程序的事件处理方式与Web不同

## 修复方案

### 1. 移除HTML5拖放API依赖
- 删除所有与HTML5拖放API相关的属性和事件绑定
- 只保留触摸事件支持，因为微信小程序支持触摸事件

### 2. 替换DOM操作
- 使用微信小程序的API替换DOM操作，如`wx.createSelectorQuery`
- 实现基于数据的拖拽位置检测，避免直接操作DOM

### 3. 适配微信小程序事件对象
- 调整触摸事件处理，适配微信小程序的事件对象结构
- 确保正确获取触摸位置和其他事件属性

### 4. 优化拖拽位置检测
- 实现基于数据的拖拽位置检测算法
- 计算拖拽项与目标项的相对位置
- 确定拖拽项应该插入的位置

### 5. 优化样式处理
- 确保样式在微信小程序中正确显示
- 调整拖拽元素的样式，适配微信小程序

## 实现步骤

1. **移除HTML5拖放API**
   - 删除`draggable="true"`属性
   - 删除所有`@drag*`事件绑定
   - 保留`@touch*`事件绑定

2. **替换DOM操作**
   - 移除`updateDragOverIndex`方法中的`document.querySelectorAll`
   - 实现基于数据的拖拽位置检测
   - 使用微信小程序的API获取元素位置和尺寸

3. **适配微信小程序事件对象**
   - 调整`handleTouchStart`方法，适配微信小程序的事件对象
   - 调整`handleTouchMove`方法，适配微信小程序的事件对象
   - 调整`handleTouchEnd`方法，适配微信小程序的事件对象

4. **优化拖拽位置检测**
   - 实现基于拖拽位置和科目项位置的数据计算
   - 确定拖拽项应该插入的目标索引

5. **测试和调试**
   - 在微信小程序环境中测试拖拽功能
   - 调试和修复可能出现的问题
   - 确保拖拽功能在微信小程序中正常工作

## 预期效果
- 拖拽功能在微信小程序中正常工作
- 支持触摸拖拽
- 拖拽过程有明显的视觉反馈
- 拖拽结束后科目顺序正确更新
- 保持与原有UI风格一致

## 技术要点
- 使用微信小程序的触摸事件API
- 实现基于数据的拖拽位置检测
- 适配微信小程序的事件对象结构
- 优化样式处理，确保在微信小程序中正确显示

## 积分计算提取计划

### 1. 分析当前积分计算流程

当前积分计算主要发生在以下位置：
- `processUserAnswers`方法：处理用户答题结果，为正确答案添加积分
- `initializeScoreConfigs`方法：构建各题型的积分配置
- 积分值来自题目配置的`integral`字段

### 2. 提取独立的积分计算方法

创建一个新的`calculateUserIntegral`方法，集中处理积分计算逻辑：

```php
/**
 * 计算用户答题获得的积分
 * @param array $correctOptionUid 正确答案UID数组
 * @param array $questionItems 题目列表
 * @param array $scoreConfigs 评分配置
 * @return float 计算后的积分值
 */
private static function calculateUserIntegral(array $correctOptionUid, array $questionItems, array $scoreConfigs): float
{
    $totalIntegral = 0.0;
    
    // 遍历正确答案，计算积分
    foreach ($correctOptionUid as $questionUid) {
        // 查找对应题目
        $question = array_find($questionItems, fn($q) => $q['uid'] === $questionUid);
        if ($question) {
            // 根据题目类型获取积分配置
            $questionType = $question['exam_type'] ?? self::EXAM_TYPE_SINGLE;
            $totalIntegral += $scoreConfigs[$questionType]['integral'] ?? 0;
        }
    }
    
    return $totalIntegral;
}
```

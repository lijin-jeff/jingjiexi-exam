## 问题分析

**问题现象**：切换到高频错题标签后，API返回空数据，但`tn-load-more`组件（第197-203行）没有显示"没有更多数据啦"提示。

**根本原因**：
1. `tn-load-more`组件的`status`属性从未设置为`nomore`
2. `tn-load-more`组件只有在有数据且还有更多数据时才显示（`collectData['all'].length > 0 && hasMoreData['all']`）
3. 当没有数据时，我们显示的是独立的"没有更多数据啦"文本，而不是使用`tn-load-more`组件的`nomore`状态

## 修复方案

### 1. 修复`tn-load-more`组件的使用
优化`tn-load-more`组件的显示逻辑，确保它能正确显示"没有更多数据啦"：

```html
<!-- 加载更多：始终显示，根据状态显示不同内容 -->
<view class="load-more-container tn-margin-top">
  <tn-load-more 
    :status="loading['all'] ? 'loading' : (hasMoreData['all'] ? 'loadmore' : 'nomore')" 
    loadingIconType="flower"
    :loadText="{
      loadmore: '上拉加载更多',
      loading: '加载中...',
      nomore: '没有更多数据啦'
    }"
    fontColor="#666"
    :fontSize="28"
  />
</view>
```

### 2. 修复重复的加载中状态
删除重复的加载中状态组件，只保留一个：

```html
<!-- 加载中状态：覆盖整个列表区域 -->
<view v-if="loading['all']" class="loading-container tn-margin-top-lg tn-text-center">
  <tn-loading
    mode="spinner"
    text="加载中..."
  />
</view>
```

### 3. 优化显示逻辑的条件判断
调整显示逻辑，确保在没有数据时也能正确显示"没有更多数据啦"：

```html
<!-- 非加载中状态 -->
<view v-else>
  <!-- 如果有数据，显示列表 -->
  <tn-time-line v-if="collectData['all'] && collectData['all'].length > 0" class="time-line__wrap">
    <!-- 数据列表内容 -->
  </tn-time-line>
  
  <!-- 加载更多：始终显示，根据状态显示不同内容 -->
  <view class="load-more-container tn-margin-top">
    <tn-load-more 
      :status="loading['all'] ? 'loading' : (hasMoreData['all'] ? 'loadmore' : 'nomore')" 
      loadingIconType="flower"
      :loadText="{
        loadmore: '上拉加载更多',
        loading: '加载中...',
        nomore: '没有更多数据啦'
      }"
      fontColor="#666"
      :fontSize="28"
    />
  </view>
  
  <!-- 空数据状态：只有当没有数据时显示 -->
  <view v-if="(!collectData['all'] || collectData['all'].length === 0)" class="empty-container tn-margin-top-lg">
    <tn-empty
      mode="list"
      text="暂无高频错题数据"
    />
  </view>
</view>
```

### 4. 确保`fetchHighFrequencyErrors`方法正确更新状态
确保`fetchHighFrequencyErrors`方法在API返回空数据时正确设置`hasMoreData['all'] = false`：

```javascript
// 判断是否还有更多数据：如果返回的数据小于每页大小，说明没有更多数据
this.hasMoreData['all'] = resultData.length >= this.queryParams.page_size;
```

## 预期效果

修复后，当切换到高频错题标签且API返回空数据时：
1. `tn-load-more`组件会显示"没有更多数据啦"
2. 不再有重复的加载中状态
3. 显示逻辑更加清晰

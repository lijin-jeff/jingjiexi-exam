## 问题分析

**问题现象**：切换到高频错题标签后，API返回空数据，但页面显示空白，没有显示"没有更多数据啦"提示。

**根本原因**：
1. 当API返回空数据时，`collectData.all`数组为空
2. 当前模板缺少空状态组件，所以没有数据时列表区域显示空白
3. 虽然有`tn-load-more`组件，但它的显示条件过于严格，且从未进入`nomore`状态

## 修复方案

### 1. 添加空状态组件
在高频错题列表区域添加`<tn-empty>`组件，当`collectData.all`为空时显示"没有更多数据啦"：

```html
<!-- 高频错题列表 -->
<view class="high-frequency-questions-list">
  <!-- 现有列表渲染代码 -->
  <tn-time-line v-if="collectData['all'] && collectData['all'].length > 0" class="time-line__wrap">
    <block v-for="(item, index) in collectData['all']" :key="item.question_uid">
      <!-- 列表项内容 -->
    </block>
  </tn-time-line>
  
  <!-- 新增：空状态组件 -->
  <tn-empty 
    v-if="collectData['all'].length === 0" 
    mode="list" 
    text="没有更多数据啦" 
    icon="none"
    class="empty-state"
  />
  
  <!-- 现有加载更多组件 -->
  <view class="load-more-container tn-margin-top">
    <tn-load-more 
      :status="loading['all'] ? 'loading' : (hasMoreData['all'] ? 'loadmore' : 'nomore')" 
      loadingIconType="flower"
      :loadText="{
        loadmore: '上拉加载更多',
        loading: '加载中...',
        nomore: '没有更多数据啦'
      }"
      fontColor="#666"
      :fontSize="28"
    />
  </view>
</view>
```

### 2. 确保数据初始化
确保`collectData`在`data()`中正确初始化：

```javascript
data() {
  return {
    collectData: {
      all: [] // 确保始终是数组，避免undefined
    },
    // 其他数据...
  }
}
```

### 3. 优化API响应处理
在`fetchHighFrequencyErrors`方法中，确保即使API返回空列表，`collectData.all`也能正确更新：

```javascript
fetchHighFrequencyErrors(isLoadMore = false) {
  // 现有代码...
  this.$api.apiQuestionErrorList(apiParams).then(res => {
    if (res.code === 1) {
      const resultData = result.list || []; // 确保是数组
      // 现有数据处理...
      this.collectData['all'] = isLoadMore ? [...this.collectData['all'], ...processedData] : processedData;
      
      // 判断是否还有更多数据
      this.hasMoreData['all'] = resultData.length >= this.queryParams.page_size;
    } else {
      // API返回错误时，确保数据数组存在
      if (!isLoadMore) {
        this.collectData['all'] = [];
        this.hasMoreData['all'] = false;
      }
    }
  });
}
```

## 预期效果

修复后，当切换到高频错题标签页时：
- 如果API返回数据，正常显示列表
- 如果API返回空数据，显示`<tn-empty>`组件，内容为"没有更多数据啦"
- 不再显示空白页面，提升用户体验

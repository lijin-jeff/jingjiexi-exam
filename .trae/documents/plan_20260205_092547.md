# 案例题滑动切换问题分析与修复方案

## 问题分析

**问题现象**：答题卡中，57题是案例题，滑动切换到56题时，56题也显示为案例题。

**根本原因**：

1. **Swiper 组件配置问题**：
   - `swiper` 组件的 `current` 属性固定为 0，意味着始终从中间位置开始显示
   - 但当 `activeQuestions` 长度小于3时（例如在最后一题），这个配置会导致显示错误

2. **ActiveQuestions 计算逻辑问题**：
   - `activeQuestions` 只包含当前、上一个和下一个题目（共3个）
   - 当在第57题（最后一题）时，`activeQuestions` 实际包含 56、57 题
   - 当滑动切换到56题时，`activeQuestions` 应该包含 55、56、57 题
   - 但由于 `swiper` 的 `current` 属性固定为 0，导致显示的仍然是 `activeQuestions[0]`，即57题

3. **滑动切换逻辑问题**：
   - 滑动切换时，`handleSwiperChange` 方法会更新 `swiperCurrentIndex`
   - 但 `swiper` 组件的 `current` 属性没有相应更新，导致显示索引与实际索引不符

## 修复方案

### 1. 优化 Swiper 组件配置

**修改 `swiper` 组件配置**：
- 移除固定的 `current` 属性，让 swiper 组件根据实际情况自动调整
- 或者根据 `activeQuestions` 的长度动态设置 `current` 属性

### 2. 改进 ActiveQuestions 计算逻辑

**修改 `activeQuestions` 计算属性**：
- 确保 `activeQuestions` 始终返回正确的题目顺序
- 当在边界位置时（如第一题或最后一题），确保返回的题目列表顺序正确

### 3. 修复滑动切换逻辑

**修改 `handleSwiperChange` 方法**：
- 确保在滑动切换时，正确更新 `swiperCurrentIndex`
- 确保 `activeQuestions` 重新计算后，swiper 组件显示的是正确的题目

### 4. 案例题特殊处理

**添加案例题特殊处理**：
- 案例题（exam_type = 6）通常是复合题，可能包含多个子问题
- 确保在滑动切换时，案例题的子问题也能正确显示和切换

## 具体修改步骤

1. **修改 Swiper 组件配置**：
   ```vue
   <swiper 
     :current="Math.min(1, activeQuestions.length - 1)"
     :disable-touch="disableSwipe"
     class="question-swiper"
     @transition="handleSwiperTransition"
     @animationfinish="handleSwiperChange"
   >
   ```

2. **优化 ActiveQuestions 计算逻辑**：
   - 确保返回的题目列表顺序正确
   - 当在边界位置时，调整返回的题目顺序

3. **修复滑动切换逻辑**：
   - 确保在滑动切换时，正确计算新的索引
   - 确保 `activeQuestions` 重新计算后，swiper 组件显示的是正确的题目

4. **测试验证**：
   - 测试从案例题（57题）滑动切换到56题
   - 测试从56题滑动切换到57题
   - 测试其他边界情况，如第一题和最后一题的滑动切换

## 预期效果

通过以上修复，预期可以解决以下问题：
- 从案例题（57题）滑动切换到56题时，正确显示56题的内容
- 从56题滑动切换到57题时，正确显示57题（案例题）的内容
- 其他边界情况的滑动切换也能正常工作

## 技术要点

- **Swiper 组件动态配置**：根据 `activeQuestions` 的长度动态设置 `current` 属性
- **ActiveQuestions 计算优化**：确保返回的题目列表顺序正确，特别是在边界位置
- **滑动切换逻辑修复**：确保在滑动切换时，正确计算新的索引并更新显示
- **案例题特殊处理**：确保案例题的子问题也能正确显示和切换

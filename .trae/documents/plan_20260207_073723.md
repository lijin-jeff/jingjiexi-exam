# 分析 getQuestionStructure 接口返回空数据的原因及修复方案

## 问题分析

从用户提供的 URL 参数来看：
- uid=6959207d02f7c
- mode=learnPractice
- question_count=37
- exam_type=1,2,3,4,5,6
- selecte_type=2（未做题目）
- practice_mode=1
- questions_type=8
- random_type=2
- ratio_params=%7B%221%22:30,%222%22:20,%223%22:10,%224%22:10,%225%22:15,%226%22:15%7D
- offset=0
- limit=10

## 可能的原因

1. **selecte_type=2 导致的问题**：
   - `selecte_type=2` 表示获取未做题目
   - 在 `prepareQuestionQuery` 方法中，会查询已做题目 ID 列表，然后使用 `where('uid', 'NOT IN', $optionUid)` 来排除已做题目
   - 如果用户已经做过所有题目，那么 `optionUid` 会包含所有题目 ID，导致查询结果为空

2. **exam_type 参数处理问题**：
   - `exam_type=1,2,3,4,5,6` 表示要获取所有题型
   - 在 `prepareQuestionQuery` 方法中，`exam_type` 被转换为数组 `[1, 2, 3, 4, 5, 6]`
   - 查询条件是 `where('exam_type', 'IN', $examType)`
   - 但是，如果 `selecte_type=2` 的逻辑导致 `optionUid` 包含所有题目 ID，那么查询结果为空

3. **ratio_params 参数解析问题**：
   - `ratio_params=%7B%221%22:30,%222%22:20,%223%22:10,%224%22:10,%225%22:15,%226%22:15%7D` 是 URL 编码的 JSON 字符串
   - 在 `prepareQuestionQuery` 方法中，会尝试解码 URL 编码的字符串并解析 JSON
   - 如果解析失败，`ratioParams` 会是空数组，导致 `typeCounts` 为空
   - 如果 `typeCounts` 为空，那么查询逻辑会走 `else` 分支，直接使用 `prepareQuestionQuery` 返回的查询条件

4. **数据库查询条件问题**：
   - 如果 `selecte_type=2` 的逻辑导致 `optionUid` 包含所有题目 ID，那么查询条件 `where('uid', 'NOT IN', $optionUid)` 会排除所有题目
   - 如果同时 `exam_type` 限制了题型，那么查询结果可能为空

### 2. 检查查询条件

```php
// 检查 selecte_type=2 的逻辑
if ($selecteType == 2) {
    // 类型2：未做题目
    // 获取已做题目 ID 列表
    $optionUid = TenantExamExaminationHistory::query()
        ->where(['user_uid' => $userId])
        ->field('JSON_EXTRACT(options, "$[*].uid") as uids')
        ->select()
        ->map(function($item) {
            $uids = $item['uids'] ?? '[]';
            return json_decode($uids, true) ?? [];
        })
        ->toArray();
    
    $flattened = [];
    foreach ($optionUid as $subArray) {
        if (is_array($subArray)) {
            $flattened = array_merge($flattened, $subArray);
        }
    }
    $optionUid = $flattened;
    
    // 添加调试日志
    \think\facade\Log::info('prepareQuestionQuery - selecte_type=2, optionUid count: ' . count($optionUid));
}
```

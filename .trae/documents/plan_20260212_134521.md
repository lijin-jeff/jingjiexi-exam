# 修复背题模式答案判定状态不一致问题

## 问题分析

**现象：**
- 用户进入背题模式页面时，`AnswerCard.vue` 组件将用户答案判定为正确答案并显示为绿色
- 当用户滑动到对应的题目后，系统又将同一用户答案判定为错误答案并显示为红色

**根本原因：**
- 各题型组件在背题模式下，`initReviewMode()` 方法将 `is_correct` 设置为 true
- 但当用户滑动到题目后，`showAnswerAfterSelection()` 方法被调用，重新计算 `is_correct` 的值并设置为 false
- 这个状态变化同步到了 `AnswerCard` 组件，导致显示颜色从绿色变为红色

## 修复方案

### 1. 修复判断题组件 (JudgeOption.vue)
- 修改 `showAnswerAfterSelection()` 方法，在背题模式下跳过重新计算 `is_correct` 的逻辑
- 保持 `initReviewMode()` 方法设置的 `is_correct: true` 状态

### 2. 修复单选题组件 (RadioOption.vue)
- 类似修复判断题的逻辑，在背题模式下跳过 `is_correct` 的重新计算
- 确保背题模式下状态保持稳定

### 3. 修复多选题组件 (CheckBoxOption.vue)
- 修改 `showAnswerAfterSelection()` 方法，在背题模式下保持 `is_correct` 状态不变
- 确保多选题答案判定的一致性

### 4. 修复填空题组件 (FillOption.vue)
- 检查并修复 `submitAnswer()` 方法，在背题模式下保持 `is_correct` 状态
- 确保填空题答案判定的一致性

### 5. 修复简答题组件 (WriteOption.vue)
- 检查并修复 `showAnswerAfterSubmission()` 方法，在背题模式下保持 `is_correct` 状态
- 确保简答题答案判定的一致性

## 修复目标

1. **页面初始加载时**：AnswerCard 组件正确显示用户答案为绿色（正确）
2. **滑动题目过程中**：答案状态保持稳定，不发生从绿色变为红色的变化
3. **视觉反馈准确**：答案正确/错误的视觉反馈（绿色/红色）与实际判定结果一致
4. **背题模式稳定**：在背题模式中，切换题目后不再次判断答案正确性，保持初始判定结果

## 技术实现

- 在各题型组件的答案判定方法中添加背题模式的条件判断
- 当 `currentMode === 'reviewOnly'` 时，跳过重新计算 `is_correct` 的逻辑
- 保持 `initReviewMode()` 方法设置的状态，确保背题模式下答案判定的一致性
- 确保状态同步机制正常工作，避免 AnswerCard 组件显示与实际状态不符

## 验证方法

1. 进入背题模式页面，检查 AnswerCard 组件显示的答案状态
2. 滑动到各个题目，观察答案状态是否保持稳定
3. 验证不同题型的答案判定是否一致
4. 确认背题模式下答案状态的稳定性

## 检查并创建user_subscribe表方案（带租户隔离）

### 问题分析

当前项目是一个多租户系统，大部分表都包含`tenant_id`字段用于租户隔离。`user_subscribe`表用于记录用户订阅状态，同样需要租户隔离，否则会出现数据混乱。

### 解决方案

1. **检查数据库是否存在user_subscribe表**
   - 连接数据库，执行SQL查询：`SHOW TABLES LIKE 'la_user_subscribe'`
   - 如果结果为空，则表不存在，需要创建

2. **创建user_subscribe表（带租户隔离）**
   - 表名：`la_user_subscribe`（符合项目表名前缀规范）
   - 字段：
     - `id`：主键，自增
     - `tenant_id`：租户ID，用于租户隔离
     - `user_id`：用户ID，外键关联`la_user`表
     - `template_id`：模板ID
     - `status`：订阅状态（1-订阅，0-取消订阅）
     - `update_time`：更新时间
     - `create_time`：创建时间
   - 索引：
     - 主键索引：`id`
     - 唯一索引：`tenant_id`、`user_id`和`template_id`的组合，避免重复记录
     - 普通索引：`user_id`，用于快速查询用户的所有订阅
     - 普通索引：`tenant_id`，用于快速查询租户的所有订阅

3. **创建表的SQL语句**
```sql
-- 创建user_subscribe表（带租户隔离）
CREATE TABLE IF NOT EXISTS `la_user_subscribe` (
  `id` int(11) unsigned NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `tenant_id` int(11) unsigned NOT NULL DEFAULT '1' COMMENT '租户ID',
  `user_id` int(11) unsigned NOT NULL COMMENT '用户ID',
  `template_id` varchar(50) NOT NULL COMMENT '订阅消息模板ID',
  `status` tinyint(1) NOT NULL DEFAULT '1' COMMENT '订阅状态：1-订阅，0-取消订阅',
  `create_time` int(11) unsigned NOT NULL DEFAULT '0' COMMENT '创建时间',
  `update_time` int(11) unsigned NOT NULL DEFAULT '0' COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_tenant_user_template` (`tenant_id`,`user_id`,`template_id`),
  KEY `idx_tenant_id` (`tenant_id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户订阅消息模板表';
```

4. **修改业务代码，添加租户ID条件**
   - 修改`handleUnsubscribe`方法，添加`tenant_id`条件
   - 修改`checkSubscription`方法，添加`tenant_id`条件

### 预期效果

创建带租户隔离的user_subscribe表后，`MessageService.php`中的方法将能够正常工作，同时保证不同租户的数据隔离，避免数据混乱。

### 实施步骤

1. 连接数据库
2. 执行SQL查询，检查表是否存在
3. 如果表不存在，执行创建表的SQL语句
4. 验证表是否创建成功
5. 修改`MessageService.php`中的方法，添加租户ID条件
6. 测试方法是否能正常工作

### 注意事项

1. 表名必须使用项目统一的`la_`前缀
2. 确保`user_id`字段与`la_user`表的`id`字段类型一致
3. 创建表时添加`IF NOT EXISTS`条件，避免重复创建
4. 添加合适的索引，提高查询效率
5. 修改业务代码时，确保所有操作都添加了`tenant_id`条件
6. 测试方法是否能正常工作，确保表结构符合预期

# 高频错题及自适应自动消灭功能数据表优化方案

## 问题分析
当前 `la_tenant_exam_question_error` 表用于存储用户的错题记录，但缺少：
1. 统计和标识高频错题的机制
2. 跟踪正确答题次数的字段
3. 根据用户设置自适应调整自动消灭错题的阈值

为实现"打错2次以上列为高频错题"和"用户可选择答对次数阈值（1次或2次）后自动标记为已消灭错题"的功能，需要对表结构进行优化。

## 优化方案

### 1. 添加核心字段
在现有表中添加以下新字段：
- `error_count`：记录用户对某题目的错误次数
- `is_high_frequency`：标识该题目是否为高频错题（打错2次以上）
- `correct_count`：记录用户对某题目的正确次数
- `auto_eliminate_threshold`：用户设置的自动消灭阈值（1或2）

### 2. 添加索引
为提高查询效率，添加复合索引：
- `idx_user_question`：用于快速查找用户的错题记录
- `idx_user_high_frequency`：用于快速查找用户的高频错题

### 3. 数据更新逻辑

#### 高频错题逻辑
- 当用户答错题目时：
  - 检查是否已存在该用户该题目的记录
  - 若存在：更新 `error_count`+1，若 `error_count`≥2 则将 `is_high_frequency` 设为1
  - 若不存在：插入新记录，`error_count`=1，`is_high_frequency`=0

#### 自动消灭逻辑
- 当用户答对题目时：
  - 检查是否已存在该用户该题目的记录
  - 若存在：
    - 更新 `correct_count`+1
    - 若 `correct_count`≥`auto_eliminate_threshold`：
      - 将 `eliminated_status` 设为1
      - 更新 `eliminated_at` 为当前时间
      - 更新 `eliminated_by` 为 'auto'
  - 若不存在：插入新记录，`correct_count`=1

## 具体修改语句

### 1. 添加字段
```sql
ALTER TABLE `la_tenant_exam_question_error` 
ADD COLUMN `error_count` int(10) UNSIGNED DEFAULT '1' COMMENT '错误次数' AFTER `examination_uid`,
ADD COLUMN `is_high_frequency` tinyint(4) DEFAULT '0' COMMENT '是否高频错题：0-否，1-是' AFTER `error_count`,
ADD COLUMN `correct_count` int(10) UNSIGNED DEFAULT '0' COMMENT '正确次数' AFTER `is_high_frequency`,
ADD COLUMN `auto_eliminate_threshold` int(10) UNSIGNED DEFAULT '2' COMMENT '自动消灭阈值：1-答对1次自动消灭，2-答对2次自动消灭' AFTER `correct_count`;
```

### 2. 添加索引
```sql
ALTER TABLE `la_tenant_exam_question_error` 
ADD INDEX `idx_user_question` (`user_uid`, `question_uid`),
ADD INDEX `idx_user_high_frequency` (`user_uid`, `is_high_frequency`);
```

## 预期效果
1. 自动统计每个用户每个题目的错误和正确次数
2. 自动标识打错2次以上的题目为高频错题
3. 支持用户设置自动消灭错题的答对次数阈值（1次或2次）
4. 根据用户设置的阈值，自动标记已掌握的题目为已消灭
5. 支持高效查询用户的高频错题和未消灭错题
6. 不影响现有功能的正常使用

## 应用场景
1. 用户端：
   - 展示高频错题列表，方便重点复习
   - 提供设置选项，选择答对1次或2次后自动消灭错题
   - 根据设置自动消灭已掌握的题目，减少复习负担

2. 教师端：
   - 分析班级高频错题，优化教学内容
   - 查看学生掌握情况，提供个性化指导

3. 系统端：
   - 根据高频错题推荐相关学习资源
   - 基于掌握情况调整学习路径

该优化方案实现了用户需求的全部功能，结构清晰，性能高效，能够满足高频错题和自适应自动消灭功能的需求。

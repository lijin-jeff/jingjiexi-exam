# 修复答题卡不显示题型和题号的问题

## 问题分析

答题卡不显示题型和题号的原因：

1. **数据处理逻辑错误**：
   - 当 `swiperList` 存在时，`getQuestionStructure` 方法直接返回完整的 `swiperList`
   - `handleShowAnswerCard` 方法对返回的 `structure` 进行 `map` 操作构建 `simplifiedQuestionList`
   - 这种处理导致数据结构不正确，`AnswerCard` 组件无法正确解析题型和题号

2. **条件判断问题**：
   - `handleShowAnswerCard` 方法的第一行条件判断可能导致提前返回
   - 按钮的 `disabled` 条件与方法内的条件相同，可能导致点击事件不触发

3. **数据结构不匹配**：
   - `AnswerCard` 组件期望 `questionList` 中的每个题目对象都有完整的题型信息
   - 如果 `simplifiedQuestionList` 中的对象缺少必要字段，题型和题号就无法显示

## 修复方案

### 1. 修复 `handleShowAnswerCard` 方法

修改 `handleShowAnswerCard` 方法，确保它能正确处理 `getQuestionStructure` 返回的数据：

```javascript
handleShowAnswerCard() {
  console.log('[handleShowAnswerCard] 方法被调用');
  
  if (this.questionParams.questions_type === 0 && this.currentMode === 'reviewOnly') {
    console.log('[handleShowAnswerCard] 条件满足，提前返回');
    return
  }
  
  // 直接使用 swiperList 构建 simplifiedQuestionList
  if (this.swiperList && this.swiperList.length > 0) {
    console.log('[handleShowAnswerCard] 使用 swiperList 构建 simplifiedQuestionList');
    const simplifiedQuestionList = this.swiperList.map((item, index) => ({
      uid: item.uid,
      exam_type: item.exam_type,
      is_answered: item.is_answered || this.checkIfAnswered(item.uid),
      user_answer: item.user_answer || this.getUserAnswer(item.uid),
      is_correct: item.is_correct !== undefined ? item.is_correct : this.getQuestionCorrectness(item.uid)
    }));
    
    console.log('[handleShowAnswerCard] 验证UID匹配情况:', {
      simplifiedCount: simplifiedQuestionList.length,
      swiperCount: this.swiperList.length,
      firstSimplifiedUid: simplifiedQuestionList[0]?.uid,
      firstSwiperUid: this.swiperList[0]?.uid
    });
    
    this.simplifiedQuestionList = simplifiedQuestionList;
    this.showAnswerCard = true;
  } else {
    // 获取题目结构信息
    this.getQuestionStructure().then(structure => {
      console.log('[handleShowAnswerCard] API返回题目数量:', structure.length);
      
      // 构建精简的题目列表（包含uid和题型）
      const simplifiedQuestionList = structure.map((item, index) => ({
        uid: item.uid,
        exam_type: item.exam_type,
        is_answered: this.checkIfAnswered(item.uid),
        user_answer: this.getUserAnswer(item.uid),
        is_correct: this.getQuestionCorrectness(item.uid)
      }));
      
      console.log('[handleShowAnswerCard] 验证UID匹配情况:', {
        simplifiedCount: simplifiedQuestionList.length,
        swiperCount: this.swiperList.length,
        firstSimplifiedUid: simplifiedQuestionList[0]?.uid,
        firstSwiperUid: this.swiperList[0]?.uid
      });
      
      this.simplifiedQuestionList = simplifiedQuestionList;
      this.showAnswerCard = true;
    }).catch(err => {
      console.error('获取题目结构信息失败:', err);
      
      // 失败时使用 swiperList 构建 simplifiedQuestionList
      if (this.swiperList && this.swiperList.length > 0) {
        console.log('[handleShowAnswerCard] 失败时使用 swiperList 构建 simplifiedQuestionList');
        const simplifiedQuestionList = this.swiperList.map((item, index) => ({
          uid: item.uid,
          exam_type: item.exam_type,
          is_answered: item.is_answered || false,
          user_answer: item.user_answer || null,
          is_correct: item.is_correct
        }));
        this.simplifiedQuestionList = simplifiedQuestionList;
      } else {
        this.simplifiedQuestionList = null;
      }
      
      // 确保已加载所有题目
      if (this.totalQuestionCount > 0 && this.swiperList.length < this.totalQuestionCount) {
        const chunkSize = 10;
        const currentChunkIndex = Math.floor(this.swiperList.length / chunkSize);
        this.preloadNextChunk(currentChunkIndex, chunkSize);
        
        setTimeout(() => {
          this.showAnswerCard = true;
        }, 2000);
      } else {
        this.showAnswerCard = true;
      }
    });
  }
}
```

### 2. 修复 `getQuestionStructure` 方法

修改 `getQuestionStructure` 方法，确保它返回正确的数据结构：

```javascript
getQuestionStructure() {
  return new Promise((resolve, reject) => {
    // 如果已经有 swiperList，直接使用其数据
    if (this.swiperList && this.swiperList.length > 0) {
      console.log('[getQuestionStructure] 使用 swiperList');
      resolve(this.swiperList);
      return;
    }
    
    // 传递与 fetchQuestionList 相同的参数
    const params = {
      uid: this.questionParams.uid || this.questionParams.library_uid,
      ratio_params: this.ratioParams,
      question_count: this.questionParams.question_count || 50
    };
    
    console.log('[getQuestionStructure] 传递参数:', params);
    
    this.$api.getQuestionStructure(params).then(res => {
      if (res.code === 1) {
        console.log('[getQuestionStructure] API返回题目数量:', res.data.length);
        resolve(res.data);
      } else {
        reject(res.msg);
      }
    }).catch(err => {
      reject(err);
    });
  });
}
```

### 3. 增强 `AnswerCard` 组件的容错能力

修改 `AnswerCard.vue` 中的 `questionsByType` 计算属性，增强容错能力：

```javascript
questionsByType() {
  const result = {};
  
  // 初始化题型分类
  if (this.questionList && this.questionList.length > 0) {
    this.questionList.forEach((question, index) => {
      // 确保 question 是对象
      if (question && typeof question === 'object') {
        const typeKey = question.exam_type || 1;
        if (!result[typeKey]) {
          result[typeKey] = [];
        }
        result[typeKey].push({
          question: question,
          index: index,
          uniqueKey: question.uid || `question_${index}`
        });
      }
    });
  }
  
  return result;
}
```

## 修复效果

1. **题型显示正常**：打开答题卡后，题型分类会正确显示
2. **题号显示正常**：每个题目旁边会正确显示题号
3. **功能完整性**：答题卡的所有功能都会正常工作
4. **错误处理**：即使 API 调用失败，也能使用 `swiperList` 构建 `simplifiedQuestionList`

通过这些修复，打开答题卡后，题型和题号都会正确显示，用户可以正常使用答题卡的所有功能。

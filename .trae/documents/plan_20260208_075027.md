## 问题描述

从53题左滑到52题、51题、50题，每滑动一题都加载一个题块，这是不合理的。

## 根本原因

加载上一块后，`swiperCurrentIndex` 被错误更新，导致跳转到加载的块内，而不是保持当前题目位置。

## 正确逻辑

**左滑滑动到51题**：
1. 正常显示51题
2. 加载上一块（40-49题）后，保持51题的位置不变
3. 再次左滑，滑动到50题

## 修复方案

### 修改 `handleSwiperChange` 加载逻辑（第3097-3140行）

**关键原则**：加载新块后，**不更新 `swiperCurrentIndex`**，保持当前题目位置

```javascript
// 如果找不到，说明需要加载对应的块
if (newRealIndex === -1) {
  const chunkSize = this.preloadConfig.chunkSize || 10;
  const targetChunkIndex = Math.floor(targetQuestionNum / chunkSize);
  
  console.log('[handleSwiperChange] 目标题目未加载，检查情况:', {
    targetQuestionNum,
    targetChunkIndex
  });
  
  // 检查目标块是否已部分加载
  const chunkStartNum = targetChunkIndex * chunkSize;
  const chunkEndNum = Math.min(chunkStartNum + chunkSize, this.simplifiedQuestionList.length);
  let loadedCount = 0;
  for (let i = chunkStartNum; i < chunkEndNum; i++) {
    const uid = this.simplifiedQuestionList[i]?.uid;
    if (uid && this.swiperList.some(item => item.uid === uid)) {
      loadedCount++;
    }
  }
  
  console.log('[handleSwiperChange] 目标块加载情况:', {
    targetChunkIndex,
    loadedCount,
    totalInChunk: chunkEndNum - chunkStartNum
  });
  
  // 关键修复：无论是否加载，都不更新 swiperCurrentIndex
  // 保持当前题目位置，让用户可以继续滑动
  if (loadedCount === 0) {
    console.log('[handleSwiperChange] 目标块未加载，开始加载（保持当前位置）:', targetChunkIndex);
    await this.fetchQuestionList(targetChunkIndex, chunkSize);
    
    // 重要：不更新 swiperCurrentIndex，保持当前题目位置
    console.log('[handleSwiperChange] 加载完成，保持当前题目位置');
  } else {
    console.log('[handleSwiperChange] 目标块已部分加载，不处理');
  }
  
  // 不更新 swiperCurrentIndex，保持当前题目位置
  // 让用户可以继续向左滑动查看新加载的题目
  this._lastSwiperChangeTime = Date.now();
  this.$nextTick(() => {
    this.isUserSwiping = false;
    this.transitionQuestionIndex = -1;
  });
  return;
}
```

### 修改后的行为

1. 从53题左滑到52题
2. 52题未找到 → 加载第5块（保持52题位置）
3. 用户仍在52题，可以继续左滑到51题
4. 从52题左滑到51题 → 正常显示51题

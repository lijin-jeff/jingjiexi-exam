# z-paging 组件集成计划

## 集成目标
将 z-paging 组件集成到考试历史页面，替换现有的 scroll-view 分页逻辑，实现更高效、更统一的分页体验。

## 集成步骤

### 1. 引入 z-paging 组件
在 `examinationHistory.vue` 文件中引入 z-paging 组件

### 2. 替换 scroll-view 为 z-paging
将每个 swiper-item 内的 scroll-view 替换为 z-paging 组件

### 3. 调整分页逻辑
- 移除手动管理的分页状态（pageNo, hasMoreData 等）
- 使用 z-paging 的 @query 事件处理数据加载
- 使用 z-paging 的 complete 方法通知数据加载完成

### 4. 调整样式
- 确保 z-paging 与现有布局兼容
- 调整 padding 和 margin，确保内容显示正常

## 具体修改

### 1. 引入组件
在 script 标签中添加 z-paging 组件引入

### 2. 修改模板结构
```vue
<!-- 替换前 -->
<scroll-view 
  class="exam-ul" 
  scroll-y 
  :scroll-into-view="scrollIntoView[tab.value]"
  scroll-with-animation
  :enable-back-to-top="true"
  @scrolltolower="onScrollToLower(tab.value)"
>
  <!-- 列表内容 -->
</scroll-view>

<!-- 替换后 -->
<z-paging 
  ref="paging"
  v-model="historyData[tab.value]"
  @query="loadExamHistory"
  :custom-key="'examHistory' + tab.value"
  :auto="false"
  :default-page-size="10"
>
  <!-- 列表内容 -->
</z-paging>
```

### 3. 调整数据加载逻辑
- 移除 fetchData 方法，使用 loadExamHistory 方法处理 @query 事件
- 移除 onScrollToLower 方法
- 移除 pageNo, hasMoreData 等手动管理的状态

### 4. 调整样式
- 移除 .exam-ul 类的 height 属性
- 调整 z-paging 与 swiper-item 的布局关系

## 预期效果
- 统一的下拉刷新和上拉加载体验
- 自动管理分页状态，减少手动代码
- 提升性能，支持虚拟列表
- 统一的空状态和加载状态显示

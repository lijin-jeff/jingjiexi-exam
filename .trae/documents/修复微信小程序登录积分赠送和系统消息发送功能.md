## 修复计划

### 1. 修复目标
修改后端 `apiMnpLogin` 接口实现，在用户登录成功后自动执行：
- 检查用户是否符合积分赠送条件
- 调用积分赠送服务，为用户添加登录积分
- 调用消息发送服务，向用户发送系统消息
- 将积分和消息相关信息返回给前端

### 2. 修复内容

#### 2.1 分析现有代码
- `apiMnpLogin` 接口位于 `LoginLogic.php` 文件的 `mnpLogin` 方法中
- 该方法已经包含新用户注册积分的逻辑
- `updateLoginInfo` 方法中包含每日首次登录积分的逻辑
- `MessageService` 类提供了消息发送功能

#### 2.2 修改点
1. **增强 `mnpLogin` 方法**：确保积分赠送逻辑完整执行
2. **添加系统消息发送**：在登录成功后发送欢迎消息
3. **扩展返回数据**：将积分和消息相关信息返回给前端

### 3. 具体修改方案

#### 3.1 修改 `LoginLogic.php` 文件
- **文件路径**：`c:\Users\44343\jingjiexi\server\app\api\logic\LoginLogic.php`
- **修改内容**：
  1. 在 `mnpLogin` 方法中添加登录成功系统消息发送
  2. 确保 `updateLoginInfo` 方法的每日登录积分逻辑正常执行
  3. 扩展返回数据，包含积分和消息相关信息

#### 3.2 系统消息发送实现
- 使用 `MessageService::createMessage` 方法发送登录成功系统消息
- 消息类型：系统消息
- 消息内容：欢迎登录，包含积分奖励信息

#### 3.3 返回数据扩展
- 在返回的用户信息中添加：
  - `integral_change`：本次登录获得的积分
  - `message_count`：用户未读消息数量
  - `system_message`：本次登录发送的系统消息

### 4. 代码修改示例

```php
// 在 mnpLogin 方法的登录成功后添加系统消息发送
MessageService::createMessage(
    $userInfo['id'],
    UserMessage::TYPE_SYSTEM,
    '登录成功',
    '欢迎回来！您已成功登录系统',
    [],
    UserMessage::SUBTYPE_LOGIN_SUCCESS
);

// 扩展返回数据
$userInfo['integral_info'] = [
    'total_integral' => IntegralLogic::getUserIntegral($userInfo['id']),
    'today_login_integral' => $todayLoginIntegral ?? 0,
    'register_integral' => $registerIntegral ?? 0
];

$userInfo['message_info'] = [
    'unread_count' => MessageService::getUnreadCount($userInfo['id']),
    'login_message' => '登录成功，欢迎回来！'
];
```

## 根因分析

### 问题现象
从第3题开始，realIndex 比预期大1，跳过了中间题目：
- 第1题：activeIndex=0, realIndex=0 ✅
- 第2题：activeIndex=1, realIndex=1 ✅
- 第3题：activeIndex=2, realIndex=3 ❌（应是2）
- 第4题：activeIndex=2, realIndex=4 ❌（应是3）

### 根本原因
**activeQuestions 生成逻辑存在索引偏移**

**位置**：commonQuestion.vue 第849-851行
```javascript
// 中间题的 activeQuestions 生成（3个题目）
questions.push(this.swiperList[currentIndex - 1]); // 前一题 (index=0)
questions.push(this.swiperList[currentIndex]);     // 当前题 (index=1)
questions.push(this.swiperList[currentIndex + 1]); // 后一题 (index=2)
```

**问题**：当 `currentIndex=1`（第2题）时：
- `activeQuestions[0] = swiperList[0]` ✅
- `activeQuestions[1] = swiperList[1]` ✅  
- `activeQuestions[2] = swiperList[2]` ✅

**但实际截图显示**：`activeIndex=2` 对应 `realIndex=3`，说明：
- `activeQuestions[2]` 实际是 `swiperList[3]`
- 索引偏移了1位

### 可能原因
1. **swiperList 顺序异常**：题目列表构建时索引错位
2. **activeQuestions 缓存问题**：计算属性返回了错误的缓存结果
3. **uid 映射错误**：getRealQuestionIndex 方法查找错误

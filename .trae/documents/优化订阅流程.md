## 优化计划

### 1. 分析当前问题

* **代码重复**：`update.vue` 和 `examinationContent.vue` 各自实现了完整的订阅逻辑，与 `countdown/detail.vue` 重复

* **一致性问题**：三个页面的订阅流程不完全一致，可能导致用户体验差异

* **维护成本高**：修改订阅逻辑需要同时修改多个文件

### 2. 优化方案

参考 `countdown/detail.vue` 的实现，使用统一的 `handleSubscribeMessage` 函数处理订阅流程

### 3. 具体优化点

#### 3.1 优化 `subpages/common/update.vue`

* 移除当前的 `uni.requestSubscribeMessage` 直接调用

* 使用 `this.$func.handleSubscribeMessage` 统一处理订阅

* 保留原有的 `subscribeLoading` 状态管理

* 优化成功回调，使用返回的 `result.subscribeResults` 获取订阅结果

#### 3.2 优化 `subpages/examination/examinationContent.vue`

* 移除当前的 `uni.requestSubscribeMessage` 直接调用

* 使用 `this.$func.handleSubscribeMessage` 统一处理订阅

* 保留原有的 `isFollowed` 状态管理

* 优化成功回调，使用返回的 `result.subscribeResults` 获取订阅结果

### 4. 预期效果

* 统一三个页面的订阅流程

* 减少代码重复

* 提高维护效率

* 确保用户体验一致性

* 利用已有的错误处理和状态管理

#### 5.1 update.vue 优化

```javascript
subscribe() {
  // 防止重复点击
  if (this.subscribeLoading) {
    return;
  }
  
  // 从Vuex获取订阅模板ID
  const templates = this.subscribeTemplates;
  const tmplIds = templates.slice(0, 3).map(item => item.template_id);
  
  if (tmplIds.length === 0) {
    this.$func.showToast('暂无可用的订阅模板，请联系管理员');
    return;
  }
  
  // 获取最新版本信息作为模板数据
  const latestVersion = this.expressData[0] || {};
  
  // 构建模板数据
  const templateData = {
    thing1: {
      value: latestVersion.version + '\n' + latestVersion.info.replace(/<br>/g, '\n')
    },
    time2: {
      value: latestVersion.time
    },
    thing3: {
      value: '感谢您使用我们的应用，欢迎体验新功能并提出宝贵意见！'
    }
  };
  
  // 设置loading状态
  this.subscribeLoading = true;
  
  // 使用统一的订阅消息处理函数
  this.$func.handleSubscribeMessage({
    tmplIds: tmplIds,
    apiCall: this.$api.apiSubscribe,
    apiParams: {
      type: 'version_update',
      related_id: latestVersion.id || 0,
      subscribe_status: 1
    },
    templateData: templateData,
    isSubscribed: false, // 版本更新订阅无需检查是否已订阅
    successCallback: (result) => {
      this.$func.showToast('✅ 订阅成功\n\n您将在应用更新时收到提醒消息');
      
      // 记录订阅授权状态
      const now = Date.now();
      
      // 检查是否有模板被接受
      const hasAccepted = Object.values(result.subscribeResults).some(status => 
        status === 'accept' || status === 'acceptWithAudio' || status === 'acceptWithAlert'
      );
      
      if (hasAccepted) {
        // 只调用一次apiRecordSubscribe，避免重复插入导致唯一键冲突
        let acceptedTemplateId = '';
        const acceptedEntry = Object.entries(result.subscribeResults).find(([_, status]) => 
          status === 'accept' || status === 'acceptWithAudio' || status === 'acceptWithAlert'
        );
        if (acceptedEntry) {
          acceptedTemplateId = acceptedEntry[0];
          this.$api.apiRecordSubscribe({
            template_id: acceptedTemplateId,
            subscribe_time: now,
            type: 'version_update',
            related_id: latestVersion.id || 0,
          });
        }
      }
    },
    failCallback: (err) => {
      console.error('订阅失败:', err);
      this.$func.showToast('订阅失败，请稍后重试');
    },
    complete: () => {
      this.subscribeLoading = false;
    }
  });
}
```

toggleExamFollow() {
  if (!isUserLoggedIn()) {
    // 未登录处理
    return;
  }
  
  // 如果已经订阅，直接取消订阅
  if (this.isFollowed) {
    // 调用后端统一订阅API保存订阅状态
    this.$api.apiSubscribe({ 
      type: 'exam',
      related_id: this.examinationInfo.id,
      subscribe_status: 0,

        this.isFollowed = false;

### 6. 依赖检查

确保 `handleSubscribeMessage` 函数已正确实现，支持以下参数：

* `tmplIds`：模板ID数组

* `apiCall`：API调用函数

* `apiParams`：API参数

* `templateData`：模板数据

* `isSubscribed`：当前订阅状态

* `successCallback`：成功回调

* `failCallback`：失败回调

* `complete`：完成回调（可选）

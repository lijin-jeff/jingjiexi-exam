## 问题描述

首次点击57题加载正确，但左滑时一次跳了2题（从57题直接跳到55题），再次点击57题显示错误题目。

## 根本原因

`activeQuestions` 计算逻辑与 `handleSwiperChange` 不一致：

1. `activeQuestions` 使用 `swiperList.length` 作为边界
2. `handleSwiperChange` 使用 `simplifiedQuestionList.length` 作为边界
3. 导致滑动时 `activeQuestions` 数组构建错误，一次跳了2题

## 修复方案

### 修复1：统一 `activeQuestions` 边界计算（第776行）

```javascript
// 原代码
const nextNum = Math.min(this.swiperList.length - 1, currentQuestionNum + 1);

// 新代码
const nextNum = Math.min(this.simplifiedQuestionList.length - 1, currentQuestionNum + 1);
```

### 修复2：恢复正确的题目查找逻辑（第782-796行）

```javascript
// 原代码
// 前一题
if (prevNum !== currNum) {
  prevQ = this.swiperList[prevNum];
  if (prevQ && prevQ.isPlaceholder) prevQ = null;
}

// 新代码
// 前一题
if (prevNum !== currNum) {
  const prevUid = this.simplifiedQuestionList[prevNum]?.uid;
  if (prevUid) {
    prevQ = this.swiperList.find(item => item.uid === prevUid && !item.isPlaceholder);
  }
}

// 后一题
if (nextNum !== currNum) {
  const nextUid = this.simplifiedQuestionList[nextNum]?.uid;
  if (nextUid) {
    nextQ = this.swiperList.find(item => item.uid === nextUid && !item.isPlaceholder);
  }
}
```

### 修复3：统一 `currentQuestionNum` 计算（第772行）

```javascript
// 原代码
const currentQuestionNum = this.swiperCurrentIndex;

// 新代码
const currentQuestionNum = this.displayQuestionIndex;
```

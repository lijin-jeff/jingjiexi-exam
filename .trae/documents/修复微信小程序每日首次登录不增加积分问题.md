## 问题分析

微信小程序自动登录时每日首次登录不增加积分的问题，经过代码分析发现：

1. **登录流程**：
   - 用户点击微信登录按钮 → 调用codeLogin方法 → 调用apiMnpLogin接口 → 后端调用LoginLogic::mnpLogin方法
   - mnpLogin方法通过WechatUserService处理微信登录，获取或创建用户
   - 然后调用updateLoginInfo方法处理每日首次登录积分

2. **问题根源**：
   - 在LoginLogic::mnpLogin方法中，updateLoginInfo方法的调用位置不正确
   - 当前调用顺序：authUserLogin() → 检查新用户并赠送注册积分 → updateLoginInfo()
   - 问题在于：authUserLogin()方法内部可能已经更新了用户的login_time字段
   - 导致updateLoginInfo()方法中，首次登录判断的条件`$lastLoginTime < $todayStart`不成立
   - 因为此时$lastLoginTime已经是当天的时间了

3. **解决方案**：
   - 调整updateLoginInfo方法的调用位置，将其放在authUserLogin()之后，检查新用户之前
   - 确保首次登录的判断是基于登录前的login_time字段
   - 同时需要调整其他登录方法（如oaLogin、silentLogin、scanLogin）的相同逻辑

## 修复方案

1. **修改LoginLogic::mnpLogin方法**：
   - 将updateLoginInfo调用位置从第362行移动到第331行之后，第334行之前
   - 确保在检查新用户之前更新登录信息，以便正确判断首次登录

2. **修改LoginLogic::oaLogin方法**：
   - 同样调整updateLoginInfo调用位置，确保在检查新用户之前调用

3. **修改LoginLogic::silentLogin方法**：
   - 调整updateLoginInfo调用位置，确保在检查新用户之前调用

4. **修改LoginLogic::scanLogin方法**：
   - 调整updateLoginInfo调用位置，确保在检查新用户之前调用

## 预期效果

修复后，微信小程序自动登录时：
1. 用户点击微信登录按钮
2. 后端获取或创建用户
3. 立即调用updateLoginInfo方法，基于登录前的login_time判断是否为首次登录
4. 如果是首次登录，正确赠送积分
5. 然后继续处理新用户注册积分等其他逻辑

这样就能确保每日首次登录时，积分能够正确增加。

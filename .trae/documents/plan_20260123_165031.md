## 修复方案

### 问题分析
从`questionError.vue`和`questionCollection.vue`跳转至`commonQuestion.vue`后不加载题目，核心问题在于`mounted`方法的逻辑有误。当前代码在`mounted`方法中会从全局状态获取`currentExamSettings`，如果全局状态有值，会覆盖之前在`onLoad`方法中从`option.examSettings`设置的`questionParams`，导致API调用时使用了错误的参数，最终无法加载题目。

### 修复内容
修改`commonQuestion.vue`中的`mounted`方法，删除从全局状态获取`currentExamSettings`的代码，直接使用`onLoad`方法中设置的`questionParams`：

1. 删除`mounted`方法中从全局状态获取`currentExamSettings`的代码块
2. 确保`onLoad`方法中设置的`questionParams`和`shouldStartNewPractice`能够被正确使用
3. 保留`mounted`方法中的其他初始化逻辑

### 代码修改
```javascript
// 修改前的mounted方法
mounted() {
  // 从全局状态重新获取答题设置（避免使用data中的缓存）- 作为备选方案
  const currentExamSettings = getApp().globalData.currentExamSettings
  if (currentExamSettings && Object.keys(currentExamSettings).length > 0) {
    this.questionParams = { ...currentExamSettings }
    this.isExamination = this.questionParams.isExamination
    // 设置shouldStartNewPractice为true，确保后续会调用startNewPractice()
    this.shouldStartNewPractice = true
    // 清空全局设置，避免被其他组件复用
    getApp().globalData.currentExamSettings = null
  }
  
  // 其他初始化逻辑...
}

// 修改后的mounted方法
mounted() {
  // 从 questionParams 获取答题设置
  const examSettings = this.questionParams
  if (examSettings && examSettings.mode) {
    this.currentMode = examSettings.mode
  }

  //exam_time: "10:27:57",转换为时间戳（秒）
  if (this.examTime) {
    // 时间转换逻辑...
  }
  // 保存初始 questionParams 到本地存储
  if (Object.keys(this.questionParams).length > 0) {
    uni.setStorageSync('questionParams', this.questionParams)
  }
  
  // 修复：确保selectedCategoryUid始终有值
  this.selectedCategoryUid = uni.getStorageSync('selectedCategoryUid')
  
  // 修复：处理直接跳转的场景
  if (this.shouldRestoreOnMount && this.savedProgress) {
    // 使用本地保存的进度数据
    this.restoreProgress(this.savedProgress)
  } else if (this.shouldStartNewPractice || Object.keys(this.questionParams).length > 0) {
    // 直接调用startNewPractice加载题目，不再依赖外部调用
    // 当shouldStartNewPractice为true或questionParams有值时，都需要加载题目
    this.startNewPractice()
  }
  
  // 启动计时器
  this.startTimer()
}
```

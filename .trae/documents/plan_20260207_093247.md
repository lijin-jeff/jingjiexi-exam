# 修改 getQuestionStructure 方法，确保按比例分配时总数等于 question_count

## 问题分析

从日志来看：
- 数据库中每种题型的题目数量：`{"1":37,"2":19,"3":0,"4":0,"5":0,"6":1}`
- 总共：57 个题目 ✅
- ratio_params：`{"1":30,"2":20,"3":10,"4":10,"5":15,"6":15}`
- 按比例计算的 typeCounts：`{"1":17,"2":11,"3":6,"4":6,"5":9,"6":9}`
- 总共：58 个题目 ❌

**问题在于**：按比例计算的 `typeCounts` 总和是 58，超过了数据库中的实际题目数量 57。

## 解决方案

修改 `prepareQuestionQuery` 方法，根据数据库中实际的题目数量来调整 `typeCounts`，确保总和等于 `question_count`。

### 1. 修改 `prepareQuestionQuery` 方法

在 `prepareQuestionQuery` 方法中，添加逻辑来调整 `typeCounts`：

```php
// 处理按比例获取题目
$typeCounts = [];
if (isset($ratioParams) && is_array($ratioParams) && !empty($ratioParams)) {
    // 使用totalQuestionCount计算typeCounts，优先使用question_count参数，确保与前端传递的总题数一致
    $totalQuestionCount = (int)($params['question_count'] ?? $params['limit'] ?? 50);
    $totalCount = $totalQuestionCount;
    $remainingCount = $totalCount;
    
    // 先从数据库中查询各个题型的实际题目数量
    $typeQuestionCounts = [];
    foreach ($examType as $type) {
        $count = Db::name('tenant_exam_question')
            ->where([
                ['library_uid', '=', $libraryUid],
                ['is_show', '=', 1],
                ['delete_time', '=', null],
                ['exam_type', '=', $type]
            ])
            ->count();
        $typeQuestionCounts[$type] = $count;
    }
    
    // 计算各题型需要的数量
    foreach ($ratioParams as $type => $percentage) {
        $count = (int)round($totalCount * $percentage / 100);
        $typeCounts[$type] = min($count, $typeQuestionCounts[$type] ?? 0);
        $remainingCount -= $typeCounts[$type];
    }
    
    // 处理余数，分配给有剩余题目的题型
    if ($remainingCount > 0) {
        foreach ($ratioParams as $type => $percentage) {
            $availableCount = ($typeQuestionCounts[$type] ?? 0) - ($typeCounts[$type] ?? 0);
            if ($availableCount > 0) {
                $addCount = min($remainingCount, $availableCount);
                $typeCounts[$type] += $addCount;
                $remainingCount -= $addCount;
                if ($remainingCount <= 0) break;
            }
        }
    }
}
```

### 2. 移除 getQuestionStructure 方法中的条件判断

移除之前添加的条件判断，恢复原来的逻辑：

```php
// 检查是否需要按比例获取题目
$items = [];
if (!empty($typeCounts)) {
    // 按比例获取题目，与orderOptionList方法完全一致
    foreach ($typeCounts as $type => $count) {
        if ($count <= 0) continue;
        
        $typeParams = $params;
        $typeParams['exam_type'] = [$type];
        
        // 使用prepareQuestionQuery方法处理每种题型的参数，与orderOptionList方法一致
        $typeResult = self::prepareQuestionQuery($typeParams);
        $typeQuery = $typeResult['query'];
        
        // 执行查询，与orderOptionList方法一致
        $typeItems = $typeQuery
            ->field(['uid', 'exam_type', 'sort'])
            ->when(
                $randomType == 1,
                function ($query) {
                    $query->orderRaw('RAND()');
                },
                function ($query) {
                    $query->order('sort', 'desc');
                }
            )
            ->limit($count)
            ->select()
            ->toArray();
        
        // 添加调试日志
        \think\facade\Log::info('getQuestionStructure - type ' . $type . ' count: ' . count($typeItems) . ', expected: ' . $count);
        
        $items = array_merge($items, $typeItems);
    }
    
    // 添加调试日志
    \think\facade\Log::info('getQuestionStructure - total items count: ' . count($items));
    
    // 排序处理，与orderOptionList方法一致
    if ($randomType == 1) {
        // 随机模式：使用固定的随机种子，确保相同参数下返回相同顺序
        $seed = crc32(serialize($params));
        srand($seed);
        shuffle($items);
        srand(); // 重置随机种子
    } else {
        // 非随机模式：按题型排序，同题型内按sort降序排序，sort相同时按id降序排序
        usort($items, function ($a, $b) {
            // 先按题型排序
            if ($a['exam_type'] != $b['exam_type']) {
                return $a['exam_type'] <=> $b['exam_type'];
            }
            // 再按sort字段降序排序
            if (($b['sort'] ?? 0) != ($a['sort'] ?? 0)) {
                return ($b['sort'] ?? 0) <=> ($a['sort'] ?? 0);
            }
            // sort相同时按id字段降序排序
            return ($b['id'] ?? 0) <=> ($a['id'] ?? 0);
        });
    }
    
    // 应用offset和limit参数，与orderOptionList方法一致
    if ($offset > 0 || $limit > 0) {
        $items = array_slice($items, $offset, $limit);
    }
}
```

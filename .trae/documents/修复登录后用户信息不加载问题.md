## 问题分析
从个人中心登录成功后，用户信息不会加载，显示"登录用户"和积分：0。

## 根本原因
1. **页面刷新机制问题**：`navigateBackAndRefresh` 函数调用上一页的 `onRefresh` 方法，但 `user.vue` 中 `onRefresh` 方法挂载方式存在问题
2. **用户信息更新逻辑问题**：`updateUserInfo` 函数在处理 API 响应和本地存储时存在逻辑缺陷
3. **登录状态判断不准确**：`isUserLoggedIn()` 函数只检查 token 存在性，不验证 userInfo 有效性

## 修复方案

### 1. 修复 `user.vue` 中的 `onRefresh` 方法挂载
**问题**：当前 `onRefresh` 方法挂载到 `this.$mp.page` 上，但 `navigateBackAndRefresh` 函数尝试调用 `prevPage.onRefresh`
**修复**：将 `onRefresh` 方法直接挂载到页面实例上，确保 `navigateBackAndRefresh` 能正确调用

### 2. 优化 `updateUserInfo` 函数逻辑
**问题**：当 API 调用失败时，可能导致 `userInfo` 被设置为空对象
**修复**：
- 增强 API 响应处理，确保正确保存用户信息
- 优化本地存储降级逻辑，确保在 API 调用失败时仍能使用有效缓存
- 确保 `globalData` 与本地存储同步更新

### 3. 改进 `isUserLoggedIn()` 函数
**问题**：只检查 token 存在性，不验证 userInfo 有效性
**修复**：在 `isUserLoggedIn()` 函数中，除了检查 token，还应验证 `userInfo` 是否包含必要字段

### 4. 确保 `saveUserInfo` 函数正确保存用户信息
**问题**：登录成功后 `saveUserInfo` 函数可能没有正确保存用户信息
**修复**：增强 `saveUserInfo` 函数的日志记录，确保用户信息正确保存到本地存储和 `globalData`

## 修复步骤
1. 修改 `user.vue` 中的 `onRefresh` 方法挂载方式
2. 优化 `user.vue` 中的 `updateUserInfo` 函数
3. 改进 `user.vue` 中的 `isUserLoggedIn()` 函数
4. 增强 `userStore.js` 中 `saveUserInfo` 函数的日志记录
5. 测试登录流程，确保用户信息正确加载

## 预期效果
- 从个人中心登录成功后，返回个人中心页面
- 个人中心页面自动刷新并显示用户信息（昵称、积分等）
- 即使 API 调用失败，也能显示本地缓存的用户信息
- 登录状态判断准确，避免显示"登录用户"等默认值

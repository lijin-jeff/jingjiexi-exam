# 修复编辑资源时题库分类不跟随资源分类改变的问题

## 问题分析

通过分析代码和用户提供的 API 响应，发现以下问题：

1. **API 响应处理错误**：`fetchCategoryList` 方法错误地将整个 API 响应对象作为分类列表添加到 `categoryList` 中，而不是将响应中的 `data` 数组添加到 `categoryList` 中。

2. **分类查找逻辑问题**：由于 `categoryList` 中没有正确的分类数据，`findCategory` 方法无法找到对应的分类，从而无法设置题库分类。

3. **保存后题库分类未更新**：虽然编辑时题库分类会跟随资源分类改变，但保存后可能由于后端 API 处理问题或前端数据传递问题，导致题库分类未被正确保存。

## 解决方案

### 1. 修复 `fetchCategoryList` 方法

修改 `fetchCategoryList` 方法，确保它正确处理 API 返回的数据，将响应中的 `data` 数组添加到 `categoryList` 中。

### 2. 增强 `handleChange` 方法

修改 `handleChange` 方法，确保它能够正确查找分类对应的题库分类，并设置到 `formData.exam_category_uid` 中。

### 3. 确保保存时正确传递题库分类

检查 `handleSubmit` 方法，确保它正确传递题库分类的值给 API 调用。

## 具体修改步骤

### 步骤1：修复 `fetchCategoryList` 方法

```typescript
const fetchCategoryList = async () => {
    try {
        const res = await apiTenantResourceCategoryTree()
        console.log('资源分类响应:', res)
        // 清空旧数据并添加新数据
        categoryList.length = 0
        // 正确处理 API 响应，将 data 数组添加到 categoryList 中
        categoryList.push(...(res.data || []))
        console.log('资源分类数据:', categoryList)
    } catch (error) {
        console.error('获取资源分类失败:', error)
    }
}
```

### 步骤2：增强 `handleChange` 方法

```typescript
const handleChange = (value: any) => {
    formData.category_uid = value || ''

    // 当选择了资源分类时，自动设置所属题库
    if (value) {
        const category = findCategory(value, categoryList)
        console.log('查找分类结果:', category)
        if (category) {
            formData.exam_category_uid = category.exam_category_uid
            console.log('设置题库分类:', category.exam_category_uid)
        } else {
            formData.exam_category_uid = ''
            console.log('未找到对应分类，清空题库分类')
        }
    } else {
        // 清空选择的资源分类时，也清空所属题库
        formData.exam_category_uid = ''
        console.log('清空资源分类，同时清空题库分类')
    }
}
```

### 步骤3：检查 `handleSubmit` 方法

确保 `handleSubmit` 方法正确传递题库分类的值给 API 调用：

```typescript
const handleSubmit = async () => {
    await formRef.value?.validate()
    const data = { ...formData }
    console.log('提交数据:', data)
    mode.value == 'edit' ? await apiTenantResourceEdit(data) : await apiTenantResourceAdd(data)
    popupRef.value?.close()
    emit('success')
}
```

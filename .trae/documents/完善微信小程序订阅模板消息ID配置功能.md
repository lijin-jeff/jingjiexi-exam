# 完善微信小程序订阅模板消息ID配置功能

## 一、功能需求分析
当前订阅模板ID配置功能仅支持单个模板ID的输入，需要扩展为支持多模板ID的管理，包括添加、编辑、删除功能，并确保数据格式正确和持久化存储。

## 二、具体实现方案

### 1. 数据结构优化
- 将 `formData.template_id` 从字符串类型改为对象数组类型，每个对象包含：
  - `template_id`: 模板ID字符串
  - `name`: 模板名称（用于标识不同模板）
  - `type`: 模板类型（如：倒计时提醒、考试提醒等）
  - `is_default`: 是否默认模板

### 2. 模板界面改造
- 替换原有的单个输入框为动态列表管理界面
- 实现表格形式展示现有模板ID
- 添加"添加模板"按钮，弹出表单对话框
- 为每个模板项添加"编辑"和"删除"按钮
- 优化操作指引和状态反馈

### 3. 表单验证逻辑
- 添加模板ID格式验证（32位字符串，微信小程序模板ID格式）
- 添加模板名称必填验证
- 确保模板ID唯一性验证
- 添加表单提交前的整体验证

### 4. 数据持久化处理
- 更新 `setFormData` 方法，处理后端返回的模板ID数据（支持JSON字符串或数组格式）
- 更新 `handleSubmit` 方法，将模板ID数组序列化为JSON字符串提交给后端
- 确保后端API能够正确处理和存储多模板ID数据

### 5. 交互功能实现
- **添加模板**：点击"添加模板"按钮，弹出表单对话框，填写模板信息后保存
- **编辑模板**：点击"编辑"按钮，弹出表单对话框，修改现有模板信息
- **删除模板**：点击"删除"按钮，弹出确认对话框，确认后删除模板
- **设为默认**：支持将某个模板设为默认模板

### 6. UI/UX优化
- 添加清晰的操作指引和提示信息
- 优化表单布局和间距
- 添加状态反馈（成功/失败提示）
- 确保响应式设计，适配不同屏幕尺寸

## 三、技术实现要点

1. **Vue 3 + TypeScript**：保持现有技术栈
2. **Element Plus**：使用表格、对话框、表单等组件
3. **表单验证**：使用Element Plus的表单验证功能，添加自定义验证规则
4. **数据处理**：实现前后端数据格式转换
5. **状态管理**：使用Vue 3的响应式API管理表单数据

## 四、代码修改范围

1. **模板部分**：修改第95-129行的订阅模板配置区域
2. **脚本部分**：
   - 更新 `formData` 数据结构
   - 添加模板管理相关方法
   - 更新表单验证规则
   - 修改数据处理逻辑
3. **样式部分**：添加模板管理界面的样式

## 五、预期效果

- 支持添加多个微信小程序订阅模板ID
- 每个模板可以配置名称、类型等信息
- 支持编辑、删除和设置默认模板
- 表单验证确保输入格式正确
- 数据持久化存储到后端数据库
- 清晰的操作指引和状态反馈
- 优化的用户体验

通过以上完善，后台管理员可以灵活管理微信小程序订阅模板消息ID，为后续消息发送功能奠定基础。

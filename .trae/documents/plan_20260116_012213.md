# 完善tenant_subscribe_send_log与服务端的联动计划

## 1. 问题分析

通过分析前端和服务端的代码，发现以下不匹配之处：

### 1.1 API路径不匹配
- 服务端控制器方法与前端API路径不一致
- 服务端使用路由参数获取ID，前端通过params传递ID

### 1.2 参数传递方式不匹配
- 服务端使用`limit`参数进行分页，前端使用`page_no`和`page_size`
- 服务端返回数据格式与前端`usePaging`钩子期望格式不一致

### 1.3 功能缺失
- 前端未实现删除和批量删除功能
- 前端未显示统计信息

## 2. 解决方案

### 2.1 修正API定义（`tenant_subscribe_send_log.ts`）
- 更新API路径，确保与服务端控制器方法匹配
- 修正参数传递方式，适配服务端期望

### 2.2 修正分页逻辑（`index.vue`）
- 确保分页参数与服务端匹配
- 处理服务端返回的数据格式

### 2.3 完善前端功能（`index.vue`）
- 添加删除和批量删除按钮
- 实现删除和批量删除功能
- 添加统计信息显示

### 2.4 修正编辑组件（`edit.vue`）
- 确保API调用参数与服务端匹配
- 处理服务端返回的错误信息

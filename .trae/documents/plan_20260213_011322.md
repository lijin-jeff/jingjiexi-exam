## 问题分析

在 `analysis.vue` 中，题目类型和难度不显示的原因是数据字段不匹配：

1. **数据流程**：
   - 原始数据包含 `exam_type: 1` 和 `exam_level: 1`
   - `analysis.vue` 调用 `ExamDataAdapter.processQuestionList()` 处理数据
   - 模板使用 `question.exam_type_name` 和 `question.exam_level` 显示数据

2. **当前问题**：
   - `ExamDataAdapter.processQuestionList()` 返回 `exam_type_name: q.exam_type_name || '未知题型'`，但没有根据 `exam_type` 值自动映射
   - 函数返回 `level: q.level || 0` 而不是 `exam_level`

## 解决方案

### 方案选择：修改 ExamDataAdapter.js

**为什么选择修改 ExamDataAdapter.js 而不是 analysis.vue：**

1. **数据适配器职责**：ExamDataAdapter 的设计目的就是统一处理后端返回的数据，确保数据结构一致性
2. **代码复用**：修改适配器可以确保所有使用该函数的地方都能获得正确的数据
3. **维护性**：避免在多个组件中重复处理相同的数据转换逻辑
4. **一致性**：保持数据处理逻辑的集中管理

### 具体修改方案

1. **在 ExamDataAdapter.js 文件顶部添加题型映射表**：
   ```javascript
   // 题型映射表
   const EXAM_TYPE_MAP = {
     1: '判断题',
     2: '单选题',
     3: '多选题',
     4: '填空题',
     5: '问答题',
     6: '案例题'
   };
   ```

2. **修改 processQuestionList 函数的返回对象**：
   - 添加 `exam_level` 字段，优先使用原始数据中的 `exam_level`，如果不存在则使用 `level`
   - 修改 `exam_type_name` 的处理逻辑，使用映射表

   ```javascript
   return {
     // 其他字段保持不变
     exam_type: q.exam_type || 0,
     exam_type_name: q.exam_type_name || EXAM_TYPE_MAP[q.exam_type] || '未知题型',
     exam_level: q.exam_level || q.level || 0,
     level: q.level || 0, // 保留原字段以保持兼容性
     // 其他字段保持不变
   };
   ```

3. **修改错误处理部分**：
   - 确保错误处理中也包含 `exam_level` 字段

### 影响评估

**正面影响**：
- 修复 `analysis.vue` 中题目类型和难度不显示的问题
- 其他使用 `ExamDataAdapter.processQuestionList()` 的地方也会受益
- 提高数据处理的一致性和可靠性

**风险控制**：
- 保留 `level` 字段以保持向后兼容性
- 只添加新字段，不修改现有字段的行为
- 使用映射表时提供默认值，确保即使遇到未知的 `exam_type` 值也能正常显示

## 预期结果

修复后，`analysis.vue` 应该能够正确显示：
- 题型：根据 `exam_type` 值显示对应的题型名称（如 "判断题"）
- 难度：根据 `exam_level` 值显示对应的难度等级（如 "简单"）

同时，其他使用 `ExamDataAdapter` 的组件也会获得正确的 `exam_level` 字段和映射后的 `exam_type_name`。

## 完善管理后台服务端计划

### 1. 目标
为文章和文章分类添加与题库分类的关联，确保前后端数据一致性。

### 2. 实施步骤

#### 2.1 修改文章分类模型（ArticleCate）
- 添加与题库分类的关联关系
- 添加获取题库分类标题的方法

#### 2.2 修改文章模型（Article）
- 添加与题库分类的关联关系
- 添加获取题库分类标题的方法

#### 2.3 更新文章分类列表服务
- 添加题库分类关联查询
- 确保返回题库分类标题

#### 2.4 更新文章列表服务
- 添加题库分类关联查询
- 确保返回题库分类标题

### 3. 关键技术点

#### 3.1 模型关联
使用 `belongsTo` 关联题库分类：
```php
public function examCategory()
{
    return $this->belongsTo(TenantExamCategory::class, 'exam_category_uid', 'uid');
}
```

#### 3.2 虚拟字段
添加获取题库分类标题的虚拟字段：
```php
public function getExamCategoryTitleAttr($value, $data)
{
    return $this->examCategory->title ?? '';
}
```

#### 3.3 列表服务更新
在列表查询中添加关联查询：
```php
->with(['examCategory'])
->append(['exam_category_title'])
```

### 4. 实施顺序

1. 首先修改模型，添加关联关系和虚拟字段
2. 然后更新列表服务，确保返回正确的数据
3. 最后测试功能是否正常

### 5. 预期效果

- 文章分类和文章都能关联到题库分类
- 列表查询时返回题库分类标题
- 与资源分类的实现保持一致

### 6. 涉及文件

1. `app/common/model/article/ArticleCate.php` - 文章分类模型
2. `app/common/model/article/Article.php` - 文章模型
3. `app/tenantapi/lists/article/ArticleCateLists.php` - 文章分类列表服务
4. `app/tenantapi/lists/article/ArticleLists.php` - 文章列表服务

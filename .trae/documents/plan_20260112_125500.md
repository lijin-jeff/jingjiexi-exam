## 修复方案

将资源附件功能从单纯的上传改为支持“上传或填写链接”，具体实现如下：

### 1. 修改 UI 布局
在 `edit.vue` 文件中，修改资源附件部分的布局，添加链接输入选项：

```vue
<el-form-item label="资源附件" prop="file_url">
  <!-- 切换按钮 -->
  <el-radio-group v-model="resourceInputType" style="margin-bottom: 10px;">
    <el-radio label="upload">上传文件</el-radio>
    <el-radio label="link">填写链接</el-radio>
  </el-radio-group>
  
  <!-- 上传模式 -->
  <material-picker 
    v-if="resourceInputType === 'upload'" 
    v-model="formData.file_url" 
    type="file" 
  />
  
  <!-- 链接模式 -->
  <el-input 
    v-else 
    v-model="formData.file_url" 
    placeholder="请输入资源链接" 
    clearable
    style="width: 100%;"
  />
</el-form-item>
```

### 2. 添加响应式数据
在 `edit.vue` 的 script 部分添加响应式数据：

```typescript
// 资源输入类型：'upload' 或 'link'
const resourceInputType = ref('upload')
```

### 3. 处理数据绑定
- 确保两种模式都能正确更新 `formData.file_url`
- 当用户切换输入类型时，保留已填写的数据

### 4. 表单验证
- 确保至少有一种方式被填写
- 链接模式下可以添加 URL 格式验证

### 5. 样式优化
- 调整布局，确保切换按钮和输入区域排列整齐
- 保持与其他表单字段的风格一致

### 修复效果
- 用户可以选择“上传文件”或“填写链接”两种方式
- 两种方式都能正确绑定到 `formData.file_url`
- UI 简洁明了，操作直观
- 与原组件风格保持一致

这个修复方案将使资源附件功能更加灵活，满足不同场景的需求。

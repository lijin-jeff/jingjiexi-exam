## 滑动切换拦截问题修复方案

### 问题根因
`_lastProcessedIndex` 在切换后被设置为 `newIndex`，导致下次切换时 `currentRealIndex` 与 `_lastProcessedIndex` 相同，所有后续切换都被拦截。

### 修复方案

#### 1. 修正_lastProcessedIndex逻辑
```javascript
// 修改前：设置为newIndex，导致下次切换被拦截
this._lastProcessedIndex = newIndex;

// 修改后：重置为-1，允许下次切换
this._lastProcessedIndex = -1;
```

#### 2. 优化重复触发检查
```javascript
// 只在防抖后检查，避免过早拦截
if (this._lastProcessedIndex === currentRealIndex && this._lastSwiperChangeTime) {
  return;
}
```

#### 3. 增加边界情况处理
```javascript
// 确保_lastProcessedIndex在初始化时为-1
// 在data中正确初始化
_lastProcessedIndex: -1,
```

### 实现计划

#### 1. API 文件实现 (`version_update.ts`)

根据数据表结构和现有API规范，实现以下接口：

| 接口名称 | 功能描述 | 方法 | URL | 参数 |
|---------|---------|------|-----|------|
| `versionUpdateLists` | 获取版本更新列表 | GET | `/exam.versionUpdate/lists` | tenant_id, version, status, page, page_size |
| `versionUpdateDetail` | 获取版本更新详情 | GET | `/exam.versionUpdate/detail` | id |
| `versionUpdateAdd` | 添加版本更新 | POST | `/exam.versionUpdate/add` | tenant_id, version, info, status, release_time |
| `versionUpdateEdit` | 编辑版本更新 | POST | `/exam.versionUpdate/edit` | id, tenant_id, version, info, status, release_time |
| `versionUpdateDelete` | 删除版本更新 | POST | `/exam.versionUpdate/delete` | id |
| `versionUpdateStatus` | 更新版本状态 | POST | `/exam.versionUpdate/updateStatus` | id, status, release_time |

#### 2. 视图文件实现

##### 2.1 列表页 (`index.vue`)

**功能**：展示版本更新记录，支持搜索、筛选、删除和新增操作

**实现内容**：
- 搜索表单：版本号、状态筛选
- 数据表格：展示id、版本号、更新内容、状态、发布时间、操作
- 操作按钮：新增、编辑、删除、状态切换
- 分页组件

##### 2.2 编辑页 (`edit.vue`)

**功能**：新增和编辑版本更新记录

**修复和实现内容**：
- 修复现有的表单字段，改为数据表对应的字段
- 添加版本号输入框
- 添加更新内容文本域
- 添加状态切换
- 修复API调用函数名
- 修复数据绑定

#### 3. 数据字段映射

将数据表字段映射到前端表单字段：

| 数据表字段 | 前端表单字段 | 类型 | 验证规则 |
|-----------|-------------|------|---------|
| id | id | string | - |
| tenant_id | tenant_id | number | 自动填充，无需用户输入 |
| version | version | string | 必填，格式验证（x.y.z） |
| info | info | text | 必填 |
| status | status | number | 1：已发布，0：未发布 |
| release_time | release_time | number | 状态为已发布时必填 |

#### 4. 实现步骤

1. 实现API文件 `version_update.ts`
2. 修复 `edit.vue` 文件，包括：
   - 替换错误的字段名
   - 修复API调用
   - 更新表单验证规则
3. 创建 `index.vue` 文件，实现列表展示和操作功能
4. 确保前后端数据交互的一致性

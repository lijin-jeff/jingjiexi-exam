## 问题分析

**现象：**

* 从第57题向左滑动，题号显示56，但内容显示55题

* 一次滑动跳过了两道题

**根本原因：**

在 `handleSwiperTransition` 方法中（第2924-2932行），滑动方向的判断是错误的：

```javascript
// dx > 0 表示向左滑（下一题），dx < 0 表示向右滑（上一题）
if (dx > 0) {
  // 向左滑，下一题
  predictedIndex = Math.min(currentRealIndex + 1, listLength - 1);
} else {
  // 向右滑，上一题
  predictedIndex = Math.max(currentRealIndex - 1, 0);
}
```

**错误分析：**

1. **注释与实际行为相反：**

   * 注释说"dx > 0 表示向左滑（下一题）"

   * 但实际上，手指向左滑应该看"上一题"（前面的题目）

   * 手指向右滑才是"下一题"（后面的题目）

2. **当用户从第57题向左滑动时：**

   * `dx > 0`，`predictedIndex = 56 + 1 = 57`（错误）

   * 但 `swiperIndex === 0`，备用方案计算出 `newRealIndex = 56 - 1 = 55`（错误）

   * 最终 `swiperCurrentIndex` 被设置为55

   * `displayQuestionIndex` 基于 `simplifiedQuestionList` 计算出56

   * 结果：题号显示56，内容显示55

## 修复方案

**修正** **`handleSwiperTransition`** **中的滑动方向判断：**

```javascript
// dx > 0 表示向左滑（上一题），dx < 0 表示向右滑（下一题）
if (Math.abs(dx) > 20) {
  if (dx > 0) {
    // 向左滑，上一题
    predictedIndex = Math.max(currentRealIndex - 1, 0);
  } else {
    // 向右滑，下一题
    predictedIndex = Math.min(currentRealIndex + 1, listLength - 1);
  }
}
```

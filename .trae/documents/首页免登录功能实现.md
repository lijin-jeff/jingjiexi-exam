# 首页免登录功能实现方案

## 1. 需求分析

* 首页不需要用户登录即可访问

* 未登录用户应显示默认状态而非强制跳转

* 仅在需要用户信息的功能中检查登录状态

## 2. 现有代码分析

* `fetchUserBasicInfo()` 方法在 `onShow` 中被调用，无论用户是否登录都会尝试获取用户信息

* `getUserInfo(true)` 方法当有 token 时会强制从 API 刷新，可能导致不必要的请求

* 首页部分功能（如统计数据）已添加登录检查，但整体登录流程可优化

## 3. 实现方案

### 3.1 修改 `fetchUserBasicInfo()` 方法

* 添加登录状态检查，仅在已登录状态下调用 API 获取用户信息

* 未登录状态下直接使用本地缓存或空对象，避免不必要的 API 请求

### 3.2 优化 `getUserInfo()` 方法

* 调整强制刷新逻辑，考虑添加时间戳检查，避免过于频繁的 API 请求

* 确保未登录状态下返回空对象而非抛出错误

### 3.3 确保首页功能兼容性

* 验证所有首页功能在未登录状态下能正常运行

* 确保统计数据等功能在未登录时显示默认值

### 3.4 修改 `onShow` 方法中的调用逻辑

* 考虑将用户信息获取改为按需加载，而非每次页面显示都获取

## 4. 预期效果

* 未登录用户可直接访问首页，无需登录

* 页面加载速度提升，减少不必要的 API 请求

* 登录用户仍能正常获取最新信息

* 所有功能在未登录状态下显示合理的默认值

## 5. 实现步骤

1. 修改 `fetchUserBasicInfo()` 方法，添加登录状态检查
2. 优化 `getUserInfo()` 方法的强制刷新逻辑
3. 测试首页在未登录状态下的表现
4. 验证登录用户仍能正常获取最新信息
5. 确保所有功能显示合理的默认值

## 6. 技术要点

* 登录状态检查使用 `isUserLoggedIn()` 函数

* 本地缓存与 API 数据结合使用

* 按需加载用户信息，避免不必要的请求

## 问题分析

**问题现象**：切换到高频错题标签后，API返回空数据，但页面没有显示"没有更多数据啦"提示，而是显示空白页面。

**根本原因**：
1. 切换标签时，`collectData['all']`没有被正确重置
2. 显示逻辑中存在条件判断顺序问题，导致提示无法正确显示
3. 样式可能存在问题，导致提示不可见

## 修复方案

### 1. 修复标签切换时的数据重置逻辑
在`onInnerTabChange`方法中，当切换到高频错题标签时，添加数据重置逻辑：

```javascript
// 切换到高频错题标签时加载数据
if (index === 0) {
  // 重置高频错题数据
  this.collectData['all'] = [];
  this.hasMoreData['all'] = true;
  this.pageNo['all'] = 1;
  this.fetchHighFrequencyErrors();
}
```

### 2. 修复显示逻辑的条件判断
优化`empty-state-container`的显示逻辑，确保在没有数据且没有更多数据时显示"没有更多数据啦"提示：

```javascript
<!-- 没有数据时的提示 -->
<view v-if="(!collectData['all'] || collectData['all'].length === 0)" class="empty-state-container tn-margin-top-lg">
  <!-- 没有更多数据提示：当没有更多数据时显示 -->
  <view v-if="!hasMoreData['all']" class="no-more-data tn-text-center tn-color-gray">
    没有更多数据啦
  </view>
  <!-- 空数据状态：当还有更多数据时显示 -->
  <view v-else class="empty-container tn-text-center">
    <tn-empty
      mode="list"
      text="暂无高频错题数据"
    />
  </view>
</view>
```

### 3. 优化fetchHighFrequencyErrors方法
确保在API返回空数据时，正确设置`hasMoreData['all'] = false`：

```javascript
// 判断是否还有更多数据：如果返回的数据小于每页大小，说明没有更多数据
this.hasMoreData['all'] = resultData.length >= this.queryParams.page_size;
```

### 4. 检查并优化样式
确保`empty-state-container`和`no-more-data`类的样式正确，确保提示可见：

```scss
.empty-state-container {
  padding: 20px 0;
}

.no-more-data {
  font-size: 28rpx;
  color: #666;
  text-align: center;
  padding: 20px 0;
}
```

## 预期效果

修复后，当切换到高频错题标签且API返回空数据时，页面会正确显示"没有更多数据啦"提示，提升用户体验。

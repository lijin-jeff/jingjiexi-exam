## 修复计划

### 问题分析

在 `CheckBoxOption.vue` 组件中，多选题还没有回答却显示已答且错误的问题。

**根本原因：**
在 `showAnswerAfterSelection` 方法中，无论用户是否选择了选项，都会设置 `user_answer` 字段为一个空数组，而空数组在 JavaScript 中是真值，导致 `AnswerCard.vue` 中判断为已答。由于 `user_answer` 存在（空数组），但用户实际没有选择任何选项，导致 `is_correct` 被设置为 `false`，显示红色错误颜色。

### 修复方案

修改 `showAnswerAfterSelection` 方法，只有当用户选择了选项时，才设置 `user_answer` 字段，否则设置为 `undefined`：

1. **获取用户选择的答案**：过滤出状态为 selected 的选项
2. **检查是否有选择**：判断过滤后的数组长度是否大于 0
3. **设置 user_answer**：如果有选择，设置为选择的选项数组；否则设置为 undefined
4. **保持其他逻辑不变**：继续执行答案正确性判断和其他操作

### 具体修改步骤

1. **修改** **`showAnswerAfterSelection`** **方法**：

   * 找到设置 `user_answer` 的代码

   * 添加条件判断，只有当用户有选择时才设置 `user_answer`

   * 当用户没有选择时，设置 `user_answer` 为 `undefined`

2. **验证修复**：

   * 确保未回答的多选题显示为未答状态（灰色）

   * 确保已回答的多选题根据回答是否正确显示绿色（正确）或红色（错误）

   * 确保其他功能保持不变

### 预期结果

* 未回答的多选题：显示为未答题状态（灰色）

* 已回答的多选题：根据回答是否正确显示绿色（正确）或红色（错误）

* 其他题型：保持原有逻辑不变

## 问题描述

从53题左滑到52题、51题、50题，每滑动一题都加载一个题块，这是不合理的。

## 根本原因

1. `handleSwiperChange` 中当 `newRealIndex === -1` 时触发加载
2. 但 `loadPreviousChunkIfNeeded` 加载的是整个上一块，而不是单独加载目标题目
3. 导致同一块内的题目滑动也会触发加载其他块

## 修复方案

### 方案：修改加载逻辑，只加载目标题目所在的块

**当前逻辑问题**：
```javascript
// 从53题左滑到52题（同一块）
newRealIndex = -1  // 52题未加载
→ 触发 loadPreviousChunkIfNeeded(52)
→ 计算 previousChunkIndex = 4  // 加载第4块
→ 但52题在第5块！
```

**修复逻辑**：
```javascript
// handleSwiperChange 中
if (newRealIndex === -1) {
  const targetChunkIndex = Math.floor(targetQuestionNum / chunkSize);
  
  // 检查目标块是否已加载
  const chunkStartNum = targetChunkIndex * chunkSize;
  const chunkEndNum = Math.min(chunkStartNum + chunkSize, this.simplifiedQuestionList.length);
  let loadedCount = 0;
  for (let i = chunkStartNum; i < chunkEndNum; i++) {
    const uid = this.simplifiedQuestionList[i]?.uid;
    if (uid && this.swiperList.some(item => item.uid === uid)) {
      loadedCount++;
    }
  }
  
  // 如果目标块已部分加载，只加载缺失的题目
  // 如果目标块完全未加载，加载整个块
  if (loadedCount === 0) {
    // 加载目标块
    await this.fetchQuestionList(targetChunkIndex, chunkSize);
  } else {
    // 目标块已部分加载，尝试重新查找
    console.log('[handleSwiperChange] 目标块已部分加载，重新查找');
  }
}
```

## 影响范围

- 只影响 `handleSwiperChange` 中的加载逻辑
- 不会影响其他组件或页面
- 修复后同一块内的滑动不会重复加载其他块

## 验证方式

1. 从第53题左滑到第52题
2. 观察是否还会加载题块
3. 应该只加载目标题目，而不是整个上一块

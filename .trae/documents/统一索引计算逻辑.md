## 问题分析

**多处索引计算冲突：**

| 位置 | 使用的索引 | 说明 |
|-----|-----------|------|
| `handleSwiperChange` | `swiperCurrentIndex` | 滑动时使用数组索引 |
| `handlePrevQuestion` | `displayQuestionIndex` | 按钮使用题号索引 |
| `handleNextQuestion` | `displayQuestionIndex` | 按钮使用题号索引 |
| `handleQuestionChange` | `simplifiedQuestionList` → `swiperList` | 通过uid查找实际索引 |
| `displayQuestionIndex` | `swiperCurrentIndex` → `simplifiedQuestionList` | 题号显示 |
| `activeQuestions` | `swiperCurrentIndex` | 题目内容 |
| `swipeCurrent` | `swiperCurrentIndex` + `activeQuestions` | swiper位置 |

**核心问题：**

当 `swiperList` 和 `simplifiedQuestionList` 顺序不一致时，滑动操作和按钮操作使用不同的索引计算方式，导致题号和内容不匹配。

**具体场景：**
- 第57题在 `swiperList` 中的索引是 56
- 但在 `simplifiedQuestionList` 中可能是索引 55（如果顺序不同）
- 向左滑动：`swiperCurrentIndex` 56 → 55（正确）
- 但 `displayQuestionIndex` 显示 56（因为通过uid查找到 `simplifiedQuestionList` 中的位置是55，显示55+1=56）
- 结果：题号56，内容55

## 修复方案

**统一所有操作使用 `swiperCurrentIndex`：**

1. **修改 `displayQuestionIndex`**：直接使用 `swiperCurrentIndex`，不再通过 `simplifiedQuestionList` 转换
2. **修改 `handlePrevQuestion`**：使用 `swiperCurrentIndex - 1`
3. **修改 `handleNextQuestion`**：使用 `swiperCurrentIndex + 1`
4. **简化 `handleQuestionChange`**：直接使用传入的索引

## 消息订阅系统优化方案

### 问题分析

当前项目中消息订阅实现存在以下问题：
1. **错误码处理不完善**：直接返回微信API原始错误码和信息，没有针对特定错误码进行处理
2. **缺少取消订阅处理**：没有处理用户拒收模板的情况
3. **缺少模板管理**：没有处理未添加订阅消息模板的情况
4. **缺少内容安全校验**：没有处理内容安全校验不通过的情况
5. **缺少频率控制**：没有处理消息下发过于频繁被拦截的情况

### 优化方案

#### 1. 增强错误码处理

**修改文件**：`c:\Users\44343\jingjiexi\my_client\uni_modules\uni-subscribemsg\uniCloud\cloudfunctions\common\uni-subscribemsg\service\weixin-mp.js`

**优化点**：
- 针对不同错误码提供更友好的错误信息
- 针对可恢复错误添加重试机制
- 记录错误日志，便于排查问题

**具体实现**：
```javascript
sendSubscribeMessage: async function(obj = {}) {
    // 原有代码...
    let res = {
        errCode: result.errcode || 0,
        errMsg: result.errmsg,
        result: result
    };
    
    // 添加错误码映射和处理
    const errorMap = {
        '-10001': { message: '系统错误', retry: true },
        '-10002': { message: '内容安全校验不通过', retry: false },
        '-10003': { message: '未添加订阅消息模板', retry: false },
        '-10004': { message: '用户拒收此模板', retry: false },
        '-10005': { message: '消息下发过于频繁被拦截', retry: true }
    };
    
    if (res.errCode !== 0 && errorMap[res.errCode]) {
        res.errMsg = errorMap[res.errCode].message;
        res.canRetry = errorMap[res.errCode].retry;
    }
    
    return res;
}
```

#### 5. 添加频率控制

**修改文件**：`c:\Users\44343\jingjiexi\server\app\common\logic\user\MessageService.php`

**优化点**：
- 记录消息发送频率
- 控制同一用户同一模板的发送频率
- 控制同一模板的总发送频率

**具体实现**：
```php
// 添加频率检查方法
private static function checkFrequency($userId, $templateId) {
    // 检查同一用户同一模板的发送频率
    $count = UserMessageLog::where('user_id', $userId)
        ->where('template_id', $templateId)
        ->where('create_time', '>', time() - 3600)
        ->count();
    
    if ($count >= 5) { // 每小时最多发送5条
        return false;
    }
    
    // 检查同一模板的总发送频率
    $totalCount = UserMessageLog::where('template_id', $templateId)
        ->where('create_time', '>', time() - 3600)
        ->count();
    
    if ($totalCount >= 100) { // 每小时最多发送100条
        return false;
    }
    
    return true;
}

// 在发送消息前调用
if (!self::checkFrequency($userId, $templateId)) {
    return [
        'code' => -10005,
        'msg' => '消息下发过于频繁被拦截',
        'data' => []
    ];
}
```

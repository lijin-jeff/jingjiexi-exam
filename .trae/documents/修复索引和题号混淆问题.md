## 问题分析

**关键发现**：

1. `swiperCurrentIndex` 是题目在 `swiperList` 中的索引（加载顺序）
2. `displayQuestionIndex` 是题目在 `simplifiedQuestionList` 中的索引（真实题号顺序）
3. 这两个索引可能不一致，因为 `swiperList` 和 `simplifiedQuestionList` 的顺序可能不同

**当前问题**：

* `activeQuestions` 基于 `swiperCurrentIndex` 计算
* `swipeCurrent` 也基于 `swiperCurrentIndex` 计算
* 当 `swiperCurrentIndex` 更新后，两者立即重新计算
* 但 Swiper 组件可能还没有完成同步，导致跳动

**解决方案**：

让 `activeQuestions` 基于 `displayQuestionIndex` 计算，而不是 `swiperCurrentIndex`。这样可以确保 `activeQuestions` 的顺序和题号显示一致。

```javascript
activeQuestions() {
  // 基于 displayQuestionIndex 获取题目，确保和题号显示一致
  const currentQuestionNum = this.displayQuestionIndex;
  
  // 获取前一题、当前题、后一题的题号
  const prevNum = Math.max(0, currentQuestionNum - 1);
  const currNum = currentQuestionNum;
  const nextNum = Math.min(this.simplifiedQuestionList.length - 1, currentQuestionNum + 1);
  
  // 获取对应的 uid
  const prevUid = this.simplifiedQuestionList[prevNum]?.uid;
  const currUid = this.simplifiedQuestionList[currNum]?.uid;
  const nextUid = this.simplifiedQuestionList[nextNum]?.uid;
  
  // 在 swiperList 中查找对应的题目
  const questions = [];
  if (prevUid) {
    const q = this.swiperList.find(item => item.uid === prevUid);
    if (q) questions.push(q);
  }
  if (currUid) {
    const q = this.swiperList.find(item => item.uid === currUid);
    if (q) questions.push(q);
  }
  if (nextUid) {
    const q = this.swiperList.find(item => item.uid === nextUid);
    if (q) questions.push(q);
  }
  
  return questions;
}
```

同时，`swipeCurrent` 也应该基于 `displayQuestionIndex` 计算：

```javascript
swipeCurrent() {
  const activeLength = this.activeQuestions.length;
  
  // 获取当前题目的 uid（基于 displayQuestionIndex）
  const currentQuestionNum = this.displayQuestionIndex;
  const currentUid = this.simplifiedQuestionList[currentQuestionNum]?.uid;
  
  // 找到当前题在 activeQuestions 中的位置
  const activeIndex = this.activeQuestions.findIndex(item => item.uid === currentUid);
  return activeIndex >= 0 ? activeIndex : 1;
}
```

这样可以确保 `activeQuestions` 和 `swipeCurrent` 都基于 `displayQuestionIndex`，和题号显示保持一致。

# 修复tn-tabs组件底部滑块与文字未对齐问题

## 问题分析
1. **问题位置**：`subject-tabs-manager.vue` 第6-10行，`tn-tabs` 组件的使用位置
2. **问题表现**：底部滑块（黑色下划线）与文字未对齐
3. **涉及组件**：`tn-tabs` 组件
4. **可能原因**：
   - `fontSize` 配置与实际文字大小不匹配
   - 自定义样式覆盖了组件的默认样式
   - 组件本身的设计问题
   - 父容器的样式影响了组件的布局

## 修复方案

### 1. 检查并调整tn-tabs组件配置
- 当前配置：`:fontSize="32"`
- 检查 `fontSize` 单位，确认是否需要调整
- 尝试调整 `fontSize` 值，使其与文字大小匹配

### 2. 检查并调整组件样式
- 检查组件的默认样式
- 检查是否有自定义样式影响了底部滑块的位置
- 尝试添加自定义样式来调整底部滑块的位置

### 3. 优化组件的父容器样式
- 检查父容器 `.tn-flex-1` 的样式
- 确保父容器的样式不会影响组件的布局
- 尝试调整父容器的样式，确保组件能够正常显示

### 4. 尝试调整组件的其他属性
- 检查 `tn-tabs` 组件的其他属性，如 `bold`、`isScroll` 等
- 尝试调整这些属性，看看是否会影响底部滑块的位置

## 实现步骤

1. **调整tn-tabs组件的fontSize属性**
   - 尝试将 `:fontSize="32"` 调整为 `:fontSize="28"` 或其他合适的值
   - 检查底部滑块是否与文字对齐

2. **添加自定义样式调整底部滑块位置**
   - 为 `tn-tabs` 组件添加自定义样式
   - 调整底部滑块的位置，使其与文字对齐

3. **检查并调整父容器样式**
   - 检查 `.tn-flex-1` 的样式
   - 确保父容器的样式不会影响组件的布局

4. **测试修复结果**
   - 确保底部滑块与文字对齐
   - 确保组件的其他功能正常
   - 确保在不同平台上都能正常显示

## 预期效果

- 组件的其他功能正常

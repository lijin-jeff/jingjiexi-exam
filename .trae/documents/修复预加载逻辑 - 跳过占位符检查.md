## 问题分析

### 根本原因
1. 初始化时，`swiperList` 被填充为包含所有题目的占位符列表
2. `executePreload` 中的检查 `chunkIndex * chunkSize < currentListLength` 只检查题目是否存在，不检查是否是占位符
3. 第2块（题目10-19）虽然存在于 `swiperList` 中，但都是占位符，没有真正加载数据

### 解决方案
修改 `executePreload` 中的检查逻辑，增加对占位符的检查：

```javascript
// 原代码（第2310-2314行）
} else if (chunkIndex * chunkSize < currentListLength) {
  // 处理队列中的下一个任务
  this.processPreloadQueue(chunkSize)
  return;
}

// 修改为
} else if (chunkIndex * chunkSize < currentListLength) {
  // 检查该块是否都是非占位符
  const chunkStart = chunkIndex * chunkSize;
  const chunkEnd = Math.min(chunkStart + chunkSize, this.swiperList.length);
  let hasPlaceholder = false;
  for (let i = chunkStart; i < chunkEnd; i++) {
    if (this.swiperList[i]?.isPlaceholder) {
      hasPlaceholder = true;
      break;
    }
  }
  if (!hasPlaceholder) {
    // 该块已加载且没有占位符，跳过
    this.processPreloadQueue(chunkSize)
    return;
  }
  // 有占位符，继续加载
}
```

### 预期结果
- 第8题时触发预加载，加载第2块（题目10-19）
- 第9题和第11题显示正常，不再是占位符
- 预加载机制正常工作，懒加载作为兜底

## 问题分析

**核心问题**：`activeQuestions` 和 `swipeCurrent` 都依赖 `displayQuestionIndex`，形成循环依赖：

1. `swiperCurrentIndex` 更新
2. `displayQuestionIndex` 重新计算（通过 `simplifiedQuestionList` 查找）
3. `activeQuestions` 重新计算
4. `swipeCurrent` 重新计算
5. Swiper 组件位置更新
6. 但 `activeQuestions` 的变化可能导致 Swiper 内容与实际位置不匹配

**边界情况问题**：

当在最后一题（57题）时：

* `activeQuestions` = \[56题, 57题]（2个题目）

* 当前题（57题）在索引1

* `swipeCurrent` 返回 1

用户向左滑动后：

* `handleSwiperChange` 获取 `activeQuestions[0]` = 56题

* 更新 `swiperCurrentIndex` 为56题的索引（比如15）

* `displayQuestionIndex` 重新计算（在 `simplifiedQuestionList` 中查找56题的索引）

* `activeQuestions` 重新计算为 \[55题, 56题, 57题] 或 \[55题, 56题]

* `swipeCurrent` 重新计算

问题在于 `displayQuestionIndex` 在 `simplifiedQuestionList` 中查找索引时，可能返回不同的值，导致 `activeQuestions` 计算错误。

## 修复方案

**方案：简化逻辑，统一使用** **`swiperCurrentIndex`**

让 `activeQuestions` 直接基于 `swiperCurrentIndex` 计算，不再通过 `displayQuestionIndex`：

```javascript
activeQuestions() {
  const currentIndex = this.swiperCurrentIndex;
  
  // 获取前一题、当前题、后一题的索引
  const prevIndex = Math.max(0, currentIndex - 1);
  const currIndex = currentIndex;
  const nextIndex = Math.min(this.swiperList.length - 1, currentIndex + 1);
  
  // 构建活跃题目列表
  const questions = [];
  if (prevIndex !== currIndex) {
    const q = this.swiperList[prevIndex];
    if (q) questions.push(q);
  }
  const currQ = this.swiperList[currIndex];
  if (currQ) questions.push(currQ);
  if (nextIndex !== currIndex) {
    const q = this.swiperList[nextIndex];
    if (q) questions.push(q);
  }
  
  return questions;
}
```

同时修改 `swipeCurrent`：

```javascript
swipeCurrent() {
  const activeLength = this.activeQuestions.length;
  const currentQuestion = this.swiperList[this.swiperCurrentIndex];
  
  if (activeLength === 1) return 0;
  
  // 找到当前题在 activeQuestions 中的位置
  const activeIndex = this.activeQuestions.findIndex(item => item.uid === currentQuestion?.uid);
  return activeIndex >= 0 ? activeIndex : 1;
}
```

修改 `handleSwiperChange`：

```javascript
handleSwiperChange(e) {
  const swiperIndex = e.detail.current;
  const currentIndex = this.swiperCurrentIndex;
  let newIndex = currentIndex;
  
  // 根据 swiperIndex 判断滑动方向
  if (swiperIndex === 0 && currentIndex > 0) {
    newIndex = currentIndex - 1;
  } else if (swiperIndex === 2 && currentIndex < this.swiperList.length - 1) {
    newIndex = currentIndex + 1;
  }
  // 当 activeLength=2 时，swiperIndex 只能是 0 或 1
  // 如果 swiperIndex=0，表示向左滑动到上一题
  // 如果 swiperIndex=1，保持在当前题（但这种情况不应该触发 handleSwiperChange）
  
  if (newIndex !== currentIndex) {
    this.swiperCurrentIndex = newIndex;
  }
}
```

修改 `displayQuestionIndex`：

```javascript
displayQuestionIndex() {
  // 直接返回 swiperCurrentIndex
  return this.swiperCurrentIndex;
}
```

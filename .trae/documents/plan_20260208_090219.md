## 问题描述

首次点击57题加载正确，但左滑时一次跳了2题（从57题直接跳到55题），再次点击57题显示错误题目。

## 根本原因

`activeQuestions` 计算逻辑错误：

1. 当 `currentQuestionNum = 56`（57题）时，计算 `prevNum = 55, currNum = 56, nextNum = 56`
2. 构建 `questions` 数组为 `[第55题, 第56题, 第56题]`
3. 向左滑动时，`swiperIndex = 0` 指向 `questions[0]`（第55题），导致一次跳2题

## 修复方案

### 修改 `activeQuestions` 计算逻辑（第824-841行）

```javascript
// 原代码
// 索引0：前一题（如果不存在或与当前题相同则用当前题占位）
if (prevQ && prevQ.uid && prevQ.uid !== currQ?.uid) {
  questions.push(prevQ);
} else if (currQ && currQ.uid) {
  questions.push(currQ);
}

// 索引1：当前题（始终存在）
if (currQ && currQ.uid) {
  questions.push(currQ);
}

// 索引2：后一题（如果不存在或与当前题相同则用当前题占位）
if (nextQ && nextQ.uid && nextQ.uid !== currQ?.uid) {
  questions.push(nextQ);
} else if (currQ && currQ.uid) {
  questions.push(currQ);
}

// 新代码
// 索引0：前一题（必须是前一题，不能用当前题占位）
if (prevQ && prevQ.uid && prevQ.uid !== currQ?.uid) {
  questions.push(prevQ);
}

// 索引1：当前题（始终存在）
if (currQ && currQ.uid) {
  questions.push(currQ);
}

// 索引2：后一题（必须是后一题，不能用当前题占位）
if (nextQ && nextQ.uid && nextQ.uid !== currQ?.uid) {
  questions.push(nextQ);
}

// 确保至少有3个题目
while (questions.length < 3 && currQ && currQ.uid) {
  questions.push(currQ);
}
```

### 修改 `handleSwiperChange` 滑动逻辑（第3079-3084行）

```javascript
// 原代码
if (swiperIndex === 0) {
  // 向左滑动，显示前一题
  targetQuestionNum = Math.max(0, currentQuestionNum - 1);
} else if (swiperIndex === 2) {
  // 向右滑动，显示后一题
  targetQuestionNum = Math.min(this.simplifiedQuestionList.length - 1, currentQuestionNum + 1);
}

// 新代码
if (swiperIndex === 0) {
  // 向左滑动，显示前一题
  targetQuestionNum = Math.max(0, currentQuestionNum - 1);
} else if (swiperIndex === 2) {
  // 向右滑动，显示后一题
  targetQuestionNum = Math.min(this.simplifiedQuestionList.length - 1, currentQuestionNum + 1);
} else {
  // 滑动到中间（当前题），不处理
  this._lastSwiperChangeTime = Date.now();
  this.$nextTick(() => {
    this.isUserSwiping = false;
    this.transitionQuestionIndex = -1;
  });
  return;
}
```

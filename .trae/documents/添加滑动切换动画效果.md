# 滑动切换动画效果实现方案

## 实现目标
为commonQuestion.vue组件添加平滑的水平滑动切换动画，满足以下要求：
- 过渡时间：300-500毫秒
- 支持左右滑动方向
- 保持内容清晰度和完整性
- 适配不同设备和屏幕尺寸
- 使用ease-in-out缓动函数
- 提供配置选项
- 确保微信小程序兼容性

## 实现方案

### 1. 动画核心实现
- **使用CSS Transitions**：通过transform和transition属性实现平滑滑动
- **双元素叠加**：同时显示当前和下一个/上一个题目，实现滑动效果
- **手势驱动**：结合现有的手势处理逻辑触发动画

### 2. 代码修改点

#### 2.1 模板部分（template）
- 在question-item容器外添加动画容器
- 使用v-show控制两个题目元素的显示/隐藏
- 添加动画相关的class和style绑定

#### 2.2 脚本部分（script）
- 添加动画相关的数据属性：
  - animationConfig：动画配置选项
  - isAnimating：动画状态标记
  - direction：滑动方向
- 修改handleSimpleTouchEnd方法：添加动画触发逻辑
- 修改handlePrevQuestion和handleNextQuestion方法：添加动画支持
- 添加动画结束回调方法

#### 2.3 样式部分（style）
- 添加动画相关的CSS类：
  - .slide-enter-active：进入动画
  - .slide-leave-active：离开动画
  - .slide-enter-from：进入开始状态
  - .slide-leave-to：离开结束状态
- 添加不同方向的动画样式
- 添加缓动函数定义

### 3. 配置选项
```javascript
animationConfig: {
  duration: 400, // 动画持续时间（毫秒）
  easing: 'ease-in-out', // 缓动函数
  threshold: 50, // 滑动触发阈值（像素）
  enable: true // 是否启用动画
}
```

### 4. 微信小程序兼容性
- 使用小程序支持的CSS属性
- 避免使用复杂的CSS动画
- 确保手势事件在小程序中正常工作
- 优化动画性能，避免卡顿

### 5. 实现步骤
1. 修改模板结构，添加动画容器
2. 添加动画相关的数据属性和配置
3. 修改手势处理和题目切换逻辑
4. 添加动画样式
5. 测试不同设备和屏幕尺寸的兼容性
6. 优化动画性能

### 6. 预期效果
- 左右滑动屏幕时，题目会平滑过渡
- 点击上一题/下一题按钮时，也会触发相应的滑动动画
- 动画过程中内容清晰可见
- 动画速度和触发条件可配置
- 在微信小程序中运行流畅

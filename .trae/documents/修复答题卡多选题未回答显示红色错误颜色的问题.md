## 修复计划

### 问题分析

在 `CheckBoxOption.vue` 组件中，编辑保存时多选题会新添加一条数据，而不是更新现有数据。

**根本原因：**
在 `saveForm` 方法中，无论是否是编辑模式，代码都将 `data.id` 重置为 0，然后调用 `apiTenantExamQuestionAdd` 方法，这会导致总是创建新数据，而不是更新现有数据。

### 修复方案

修改 `saveForm` 方法，根据是否存在 `props.id` 来决定调用哪个 API 方法：

1. **检查编辑模式**：判断 `props.id` 是否存在
2. **更新现有数据**：如果 `props.id` 存在，调用 `apiTenantExamQuestionEdit` 方法
3. **创建新数据**：如果 `props.id` 不存在，调用 `apiTenantExamQuestionAdd` 方法
4. **保留 ID**：不要无条件地将 `data.id` 重置为 0，只在需要创建新数据时才重置

### 具体修改步骤

1. **修改** **`saveForm`** **方法**：

   * 移除 `data.id = 0` 这行代码

   * 添加条件判断，根据 `props.id` 是否存在来选择调用的 API 方法

   * 保持其他数据处理逻辑不变

2. **验证修复**：

   * 确保编辑模式下保存会更新现有数据

   * 确保创建模式下保存会创建新数据

   * 确保所有数据验证和处理逻辑正常工作

### 预期结果

* 编辑多选题时，保存后会更新现有数据，而不是创建新数据

* 创建多选题时，保存后会正常创建新数据

* 其他功能保持不变

# 分块加载与答题卡数据一致性解决方案

## 一、问题分析

当前系统存在的主要问题：

1. **数据一致性问题**：分块加载的题目数据与答题卡显示的数据可能不一致，特别是题目uid的对应关系

2. **加载状态管理**：当用户点击答题卡上的题号时，如果题目未加载，可能会出现跳转失败

3. **顺序一致性**：服务端返回的题目顺序可能与答题卡显示的顺序不一致

4. **性能问题**：当前实现需要加载完整的题目信息才能显示答题卡，导致加载速度慢

## 二、解决方案

### 1. 服务端修改

**a. 添加新方法 `getQuestionStructure`**

在 `QuestionlibLogic.php` 中添加一个新方法，用于返回题目结构信息（包含题目uid和题型）：

```php
/**
 * 获取题目结构信息（用于答题卡显示）
 * @param array $params
 * @return array
 */
public static function getQuestionStructure(array $params): array
{
    try {
        $libraryUid = $params['uid'] ?? null;
        if (empty($libraryUid)) {
            return [];
        }
        
        // 查询题目基本信息（只包含uid和exam_type）
        $questions = Db::name('tenant_exam_question')->where([
            ['library_uid', '=', $libraryUid],
            ['is_show', '=', 1],
            ['delete_time', '=', NULL]
        ])->field(['uid', 'exam_type'])->order('sort desc, id desc')->select();
        
        return $questions;
    } catch (Exception $e) {
        \think\facade\Log::error('获取题目结构信息失败: ' . $e->getMessage());
        return [];
    }
}
```

**b. 优化现有方法**

确保现有的题目获取方法（如 `orderOptionList`）返回的题目数据包含完整的uid信息，并且顺序与 `getQuestionStructure` 方法一致。

```javascript
// 获取题目结构信息（用于答题卡）
getQuestionStructure() {
  return new Promise((resolve, reject) => {

      method: 'POST',
      data: {
        uid: this.questionParams.uid || this.questionParams.library_uid

      },
      fail: (err) => {
        reject(err);

  });
}
```

```javascript
handleShowAnswerCard() {
```

**iii. 添加辅助方法**

```javascript
// 检查题目是否已答
checkIfAnswered(uid) {
  const question = this.swiperList.find(q => q.uid === uid);
  return question ? question.is_answered || (question.user_answer && question.user_answer.length > 0) : false;
}

// 获取用户答案
getUserAnswer(uid) {
  const question = this.swiperList.find(q => q.uid === uid);
  return question ? question.user_answer : null;
}

// 获取题目正确性
getQuestionCorrectness(uid) {
  const question = this.swiperList.find(q => q.uid === uid);
  return question ? question.is_correct : undefined;
}
```

**iv. 修改 `handleQuestionChange` 方法**

```javascript
// 处理答题卡题目切换
handleQuestionChange(index) {
  console.log('处理答题卡题目切换:', index);
  
  // 获取对应索引的题目uid
  const targetQuestion = this.simplifiedQuestionList ? this.simplifiedQuestionList[index] : this.swiperList[index];
  if (!targetQuestion) {
    console.error('目标题目不存在:', index);
    return;
  }
  
  const targetUid = targetQuestion.uid;
  console.log('目标题目uid:', targetUid);
  
  // 检查题目是否已加载
  const existingQuestion = this.swiperList.find(q => q.uid === targetUid);
  
  if (existingQuestion) {
    // 题目已加载，直接跳转
    console.log('题目已加载，直接跳转');
    const existingIndex = this.swiperList.findIndex(q => q.uid === targetUid);
    this.swiperCurrentIndex = existingIndex;
    this.needProgrammaticJump = true;
    this.$nextTick(() => {
      this.needProgrammaticJump = false;
    });
  } else {
    console.log('题目未加载，需要先加载题目');
    
    // 计算需要加载的块索引
    const chunkIndex = Math.floor(index / this.preloadConfig.chunkSize);
    
    // 加载题目
    this.fetchQuestionList(chunkIndex).then(() => {
      console.log('题目加载完成，执行跳转');
      // 查找加载后的题目索引
      const loadedIndex = this.swiperList.findIndex(q => q.uid === targetUid);
      if (loadedIndex >= 0) {
        this.swiperCurrentIndex = loadedIndex;
        this.needProgrammaticJump = true;
        this.$nextTick(() => {
          this.needProgrammaticJump = false;
        });
      } else {
        console.error('加载后题目仍未找到:', targetUid);
      }
    }).catch(err => {
      console.error('加载题目失败:', err);
    });
  }
}
```

**v. 修改 `fetchQuestionList` 方法**

确保 `fetchQuestionList` 方法能够正确加载指定块的题目，并且保持题目顺序与服务端返回一致。

```javascript
// 按题型分类的题目
questionsByType() {
  const result = {};
  
  // 初始化题型分类
  if (this.questionList && this.questionList.length > 0) {
    this.questionList.forEach((question, index) => {
      const typeKey = question.exam_type || 1;
      if (!result[typeKey]) {
        result[typeKey] = [];
      }
      result[typeKey].push({
        question: question,
        index: index,
        // 生成唯一的 key
        uniqueKey: question.uid || `question_${index}`
      });
    });
  }
  
  return result;
}
```

## 三、解决方案优势

1. **数据一致性**：通过使用真实的题目uid，确保分块加载的题目数据与答题卡显示的数据完全对应

2. **性能优化**：新接口返回的数据量大幅减少，加载速度更快，只包含题目uid和题型信息

3. **用户体验**：
   - 答题卡加载速度更快
   - 用户点击答题卡题号时能正确加载和显示题目完整信息
   - 题目顺序与服务端返回一致

4. **兼容性**：
   - 保持原有接口不变，确保其他功能不受影响
   - 失败时自动回退到原有方式

5. **可靠性**：
   - 通过题目uid作为唯一标识，确保数据一致性
   - 添加详细的错误处理和日志记录

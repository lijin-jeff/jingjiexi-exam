# 修复考试详情不返回订阅状态问题

## 问题分析
1. 考试查询API返回的详情数据中缺少订阅状态`is_followed`字段
2. 原因：代码逻辑存在问题，尝试在模型对象上直接赋值数组键`is_followed`，这是无效的
3. 具体问题：
   - 第603-612行：在模型对象上直接赋值`$examination['is_followed']`，但`$examination`是模型对象，不是数组
   - 第613行：检查`$examination->isEmpty()`，说明`$examination`是模型对象
   - 第615行：调用`$examination->toArray()`转换为数组返回

## 解决方案
修改代码逻辑，正确地给模型对象添加`is_followed`属性

## 修复步骤
1. 调整代码顺序，先检查模型对象是否为空
2. 如果模型对象不为空，再查询订阅状态
3. 使用模型的`append()`方法或直接赋值属性的方式添加`is_followed`字段
4. 确保订阅状态能正确地被转换到最终的数组结果中

## 代码修改
```php
// 调整代码顺序，先检查模型对象是否为空
$examination = TenantExamExamination::query()
    ->where([
        'uid' => $params['uid'],
        'tenant_id' => $this->tenantId
    ])
    ->field($field)
    ->append(['status', 'submit_count_status'])
    ->findOrEmpty();

// 检查模型对象是否为空
if (!$examination->isEmpty()) {
    // 添加订阅状态
    $userId = $params['user_uid'] ?? 0;
    $isFollowed = 0;
    
    if ($userId > 0) {
        $isFollowed = userSubscribe::where([
            'user_id' => $userId,
            'type' => 'exam',
            'related_id' => $examination->id,
            'subscribe_status' => 1,
            'is_pushed' => 0
        ])->find() ? 1 : 0;
    }
    
    // 正确地给模型对象添加属性
    $examination->is_followed = $isFollowed;
    // 或者使用append方法：$examination->append(['is_followed']);
    
    $examination->hidden(['paper_uid']);
    return $examination->toArray();
} else {
    return [];
}
```

## 预期效果
1. 考试查询API返回的详情数据中包含`is_followed`字段
2. `is_followed`字段值为0或1，表示用户是否订阅了该考试
3. 未登录用户（user_uid为0）时，`is_followed`默认为0
4. 已登录用户时，根据实际订阅情况返回0或1

## 修复原理
- 先检查模型对象是否为空，避免对空对象进行操作
- 正确使用模型对象的属性赋值方式，而不是数组赋值方式
- 确保订阅状态能被正确地包含在最终返回的数组中

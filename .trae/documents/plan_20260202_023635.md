## 滑动切换异常递增问题修复方案

### 问题根因
用户滑动速度过快时，防抖机制（200ms）无法完全拦截重复触发的`handleSwiperChange`事件，导致`currentIndex`异常递增。

### 修复方案

#### 1. 延长防抖时间
```javascript
// 从200ms延长到300ms
if (this._lastSwiperChangeTime && now - this._lastSwiperChangeTime < 300) {
  return;
}
```

#### 2. 增强滑动方向验证
```javascript
// 验证滑动方向是否与预期一致
if (swiperIndex > expectedSwiperIndex && diff !== 1) {
  return;
} else if (swiperIndex < expectedSwiperIndex && diff !== -1) {
  return;
}
```

#### 3. 优化_lastProcessedIndex机制
```javascript
// 在函数开始时就检查，而不是在计算newIndex后
if (this._lastProcessedIndex === currentRealIndex) {
  return;
}
```

#### 4. 添加滑动距离验证
```javascript
// 只允许相邻滑动，不允许跳过题目
if (Math.abs(swiperIndex - expectedSwiperIndex) > 1) {
  return;
}
```

- `commonQuestion.vue`：

  - 增强滑动方向验证
  - 优化_lastProcessedIndex机制

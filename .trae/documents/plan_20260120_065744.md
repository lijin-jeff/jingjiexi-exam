## 问题分析

### 根本原因
在 `saveForm` 方法中，存在硬编码重置 `id` 为 0 的逻辑，导致每次保存都会创建新记录：

```javascript
// 如果是复制操作，重置id为0，创建新题目
const originalId = data.id
// 错误：无论是否复制，都重置为0，导致每次都是新增
// 并且没有复制操作的判断条件
// data.id = 0
```

### 相关问题
1. **id重置逻辑错误**：缺少复制操作的判断条件，导致所有保存操作都变为新增
2. **数据赋值混乱**：`fetchQuestionDetail` 方法中同时使用 `Object.assign` 和直接赋值，可能导致数据不一致
3. **复制操作未实现**：代码中提到复制操作，但没有实际的复制逻辑

## 修复方案

### 1. 修复 `saveForm` 方法
**修改位置**：`saveForm` 方法（第361-395行）
**实现**：
- 移除硬编码重置 `id` 的逻辑
- 根据 `props.id` 决定调用新增还是更新API

```javascript
const saveForm = async () => {
    const data = { ...formData } as any
    try {
        await formRef.value?.validate()

        // 去除editor和exam-editor组件输入数据的首尾空格和空行
        data.title = trimContent(data.title)
        data.analysis = trimContent(data.analysis)
        data.commentaries = trimContent(data.commentaries)

        // 处理选项中的编辑器内容
        if (Array.isArray(data.option)) {
            data.option = data.option.map((option: any) => ({
                ...option,
                title: trimContent(option.title)
            }))
        }

        if (Array.isArray(data.label_uid)) {
            data.label_uid = data.label_uid.join(',')
        }
        if (Array.isArray(data.knowledge_uid)) {
            data.knowledge_uid = data.knowledge_uid.join(',')
        }

        // 根据id判断是新增还是更新
        let result
        if (props.id) {
            // 更新操作
            data.id = props.id
            result = await apiTenantExamQuestionEdit(data)
        } else {
            // 新增操作
            data.id = 0 // 新增时才设置为0
            result = await apiTenantExamQuestionAdd(data)
        }

        emit('success', data)
    } catch (error) {
        console.log('error submit!!', error)
    }
}
```

### 2. 优化 `fetchQuestionDetail` 方法
**修改位置**：`fetchQuestionDetail` 方法（第431-484行）
**实现**：
- 简化数据赋值逻辑
- 确保数据类型正确

```javascript
const fetchQuestionDetail = async () => {
    try {
        const res = await apiTenantExamQuestionDetail({ id: props.id })
        const questionRes = res as QuestionDetailRes
        
        // 直接赋值，确保数值类型正确
        Object.assign(formData, {
            ...questionRes,
            // 确保数值类型正确
            integral: Number(questionRes.integral) || 0,
            score: Number(questionRes.score) || 2,
            sort: Number(questionRes.sort) || 0,
            level: Number(questionRes.level) || 1,
            is_show: Number(questionRes.is_show) || 1,
            // 确保数组类型正确
            answer: questionRes.option
                .filter((item) => item.is_check)
                .map((item) => item.check),
            // 确保字符串数组类型正确
            label_uid: typeof questionRes.label_uid === 'string' 
                ? questionRes.label_uid.split(',').map((item: string) => item.trim())
                : Array.isArray(questionRes.label_uid) ? questionRes.label_uid : [],
            knowledge_uid: typeof questionRes.knowledge_uid === 'string' 
                ? questionRes.knowledge_uid.split(',').map((item: string) => item.trim())
                : Array.isArray(questionRes.knowledge_uid) ? questionRes.knowledge_uid : [],
            commentaries: questionRes.commentaries || ''
        })
        
        // 设置选中答案
        formData.selectAnswer = formData.answer[0] || ''
        
        // 同步选项选中状态
        formData.option.forEach((option) => {
            option.is_check = formData.answer.includes(option.check)
        })
        
        // 加载相关数据
        await fetchChapterList()
        if (formData.chapter_uid) {
            await fetchKnowledgeList()
        }
    } catch (error) {
        console.error('获取试题详情失败:', error)
    }
}
```

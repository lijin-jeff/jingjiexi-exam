## 问题分析

当在**最后一题**（57题）时：
1. `activeQuestions` = [56题, 57题]（`activeLength = 2`）
2. `displayQuestionIndex` = 56（表示57题）
3. 用户向左滑动，Swiper 从索引1滑动到索引0
4. 应该切换到56题

但现在的代码：
```javascript
if (swiperIndex === 0 && currentQuestionNum > 0) {
  newQuestionNum = currentQuestionNum - 1;  // 56 - 1 = 55，错误！
}
```

**根本原因**：当 `activeLength === 2` 时，`activeQuestions` 包含的是 [前一题, 当前题]，而不是 [当前题, 后一题]。所以 `swiperIndex === 0` 表示前一题，新题号应该是 `currentQuestionNum - 1` 只有在 `activeLength === 3` 时才正确。

实际上，当 `activeLength === 2` 且在最后一题时：
- `activeQuestions[0]` = 前一题（56题）
- `activeQuestions[1]` = 当前题（57题）
- 滑动到 `swiperIndex === 0` 应该显示56题
- 所以 `newQuestionNum` 应该是55（56题的索引）

等等，让我重新分析...

实际上，问题在于 `displayQuestionIndex` 返回的是当前题号（56表示57题），但 `activeQuestions` 的顺序是 [56题, 57题]。

当用户向左滑动到 `swiperIndex === 0`：
- 应该显示 `activeQuestions[0]` = 56题
- 56题在 `simplifiedQuestionList` 中的索引是55
- 所以 `newQuestionNum = 55`

但用户期望的是从57题切换到56题，而不是55题。

**真正的问题**：`displayQuestionIndex` 返回56（表示57题），但 `activeQuestions[0]` 是56题（在 `simplifiedQuestionList` 中的索引是55）。

这说明 `activeQuestions` 和 `displayQuestionIndex` 的对应关系有问题。

## 修复方案

需要重新梳理 `activeQuestions`、`displayQuestionIndex` 和 `handleSwiperChange` 之间的逻辑关系。

实际上，最简单的方法是：
1. 在 `handleSwiperChange` 中，根据 `swiperIndex` 直接从 `activeQuestions` 获取对应的题目
2. 然后在 `simplifiedQuestionList` 中找到该题目的索引
3. 更新 `swiperCurrentIndex`

这样可以确保滑动后的题号与内容一致。

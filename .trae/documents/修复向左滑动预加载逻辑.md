## 问题分析

向左滑动（上一块）的预加载逻辑与向右滑动（下一块）不一致：

### 向右滑动（当前实现）
- 使用 `preloadedChunks` 标记当前块为已预加载
- 避免重复触发预加载
- 逻辑：`if (distanceToChunkEnd <= 2 && !this.preloadState.preloadedChunks.has(currentChunkIndex) && currentChunkIndex < totalChunks - 1)`

### 向左滑动（当前实现）
- **没有使用 `preloadedChunks` 标记**
- 只依赖 `preloadPreviousChunk` 中的检查（间隔、队列、是否已加载）
- 逻辑：`if (distanceToChunkStart <= 2 && currentChunkIndex > 0)`

### 问题影响
1. 向左滑动可能重复检查是否需要预加载
2. 快速向左滑动时可能被 `minPreloadTime`（1000ms）限制
3. 逻辑不一致，维护困难

## 修复方案

### 方案：统一预加载逻辑

让向左滑动的逻辑和向右滑动保持一致，添加 `preloadedChunks` 标记：

```javascript
// 当前代码（第2433行）
if (distanceToChunkStart <= 2 && currentChunkIndex > 0) {
  // 预加载上一个块
  const chunkIndex = currentChunkIndex - 1
  console.log('[smartPreload] 准备预加载上一块:', chunkIndex);
  if (chunkIndex >= 0) {
    this.preloadPreviousChunk(chunkIndex, chunkSize)
  }
}

// 修改为
if (distanceToChunkStart <= 2 && !this.preloadState.preloadedChunks.has(currentChunkIndex) && currentChunkIndex > 0) {
  // 标记当前块为已预加载（上一块）
  this.preloadState.preloadedChunks.add(currentChunkIndex)
  
  // 预加载上一个块
  const chunkIndex = currentChunkIndex - 1
  console.log('[smartPreload] 触发预加载上一块:', { currentChunkIndex, chunkIndex });
  if (chunkIndex >= 0) {
    this.preloadPreviousChunk(chunkIndex, chunkSize)
  }
}
```

## 修改影响

| 修改项 | 影响 | 风险 |
|-------|------|------|
| 添加 `preloadedChunks` 检查 | 避免重复预加载 | 低 |
| 添加标记逻辑 | 和向右滑动保持一致 | 低 |

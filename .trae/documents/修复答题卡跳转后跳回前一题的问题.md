## 问题分析

**现象**：打开答题卡，点击跳转57题，然后跳转到56题。

**根本原因**：
1. **handleSwiperChange方法的逻辑问题**：当用户点击答题卡进行程序化跳转时，`handleSwiperChange`方法会在动画完成后被调用，并根据`swiperIndex`重新计算`newRealIndex`，这可能导致跳转到错误的题目。

2. **needProgrammaticJump标志的管理问题**：虽然在`handleQuestionChange`中设置了`needProgrammaticJump = true`，但在300ms后会被重置为`false`，这会导致`swiper`组件失去对目标题目的锁定。

3. **swiper组件的current属性处理**：当`needProgrammaticJump`为`false`时，`swiper`组件不再使用`swipeCurrent`计算属性，而是根据自身状态显示幻灯片，这可能导致显示错误的题目。

## 解决方案

### 1. 修改handleSwiperChange方法
- **添加对程序化跳转的判断**：当`needProgrammaticJump`为`true`时，跳过`newRealIndex`的计算，保持`swiperCurrentIndex`不变。
- **确保程序化跳转的完整性**：在程序化跳转完成前，不允许`handleSwiperChange`修改`swiperCurrentIndex`。

### 2. 优化needProgrammaticJump标志的管理
- **延长needProgrammaticJump的有效期**：确保`needProgrammaticJump`在整个跳转过程中保持为`true`，直到`swiper`组件完全锁定目标题目。
- **改进标志重置逻辑**：在`handleSwiperChange`中添加条件判断，只有当不是程序化跳转时才处理滑动逻辑。

### 3. 优化swipeCurrent计算属性
- **确保返回正确的索引**：根据当前题目在`activeQuestions`中的位置，返回正确的索引，确保`swiper`组件始终显示目标题目。
- **增强边界条件处理**：确保在不同长度的`activeQuestions`数组中，都能返回正确的索引。

## 具体修改

### 修改1：更新handleSwiperChange方法
```javascript
// swiper切换事件（修复：防止重复触发和异常跳转）
handleSwiperChange(e) {
  try {
    // 跳过程序化跳转的处理
    if (this.needProgrammaticJump) {
      console.log('[handleSwiperChange] 跳过程序化跳转的处理');
      return;
    }
    
    const startTime = Date.now();
    
    // 获取滑动后的swiper索引
    const swiperIndex = e.detail.current;
    const currentRealIndex = this.swiperCurrentIndex;
    let newRealIndex = currentRealIndex;
    
    // 优先使用滑动过程中计算的预测索引
    if (this.transitionQuestionIndex >= 0 && this.transitionQuestionIndex !== currentRealIndex) {
      newRealIndex = this.transitionQuestionIndex;
    } else {
      // 根据swiper索引计算真实索引（备用方案）
      if (swiperIndex === 0) {
        // 向左滑，上一题
        newRealIndex = Math.max(0, currentRealIndex - 1);
      } else if (swiperIndex === 2) {
        // 向右滑，下一题
        newRealIndex = Math.min(this.swiperList.length - 1, currentRealIndex + 1);
      }
    }
    
    // 如果索引发生变化，更新状态
    if (newRealIndex !== currentRealIndex) {
      // 更新用户浏览速度
      const timeSpent = Date.now() - (this._lastSwiperChangeTime || startTime);
      this.updateUserSpeed(currentRealIndex, newRealIndex, timeSpent);
      
      this.swiperCurrentIndex = newRealIndex;
      
      // 重置状态（与按钮切换保持一致）
      this._lastProcessedIndex = -1;
      this.forceShowAnswer = false;
      this._cachedQuestionIndex = -1;
      this._cachedCurrentQuestion = null;
      
      // 保存进度
      this.triggerAutoSave();
      
      // 触发智能预加载
      this.smartPreload(newRealIndex);
    }
    
    // 更新最后滑动时间
    this._lastSwiperChangeTime = Date.now();
    
    // 🔑 核心修复：滑动完成后重置滑动状态标志
    this.isUserSwiping = false;
    this.transitionQuestionIndex = -1;
    
    // 检查是否需要加载更多题目
    this.checkLoadMoreQuestions();
    
  } catch (error) {
    console.error('[handleSwiperChange] 滑动处理错误:', error);
  }
}
```

### 修改2：优化needProgrammaticJump的重置逻辑
```javascript
// 在handleQuestionChange方法中
// 延迟重置needProgrammaticJump，确保swiper正确锁定目标题目
setTimeout(() => {
  // 确保swiper已经完全锁定目标题目后再重置标志
  this.needProgrammaticJump = false;
  console.log('[handleQuestionChange] 延迟重置needProgrammaticJump标志');
}, 500); // 延长到500ms，确保动画完成
```

### 修改3：优化swipeCurrent计算属性
```javascript
// 优化的swiper位置计算 - 默认让swiper自由滑动
swipeCurrent() {
  // 🔑 核心：只有程序化跳转（按钮/答题卡）时才设置current
  // 用户滑动时始终返回undefined，让swiper完全自由
  if (this.needProgrammaticJump) {
    // 当使用activeQuestions时，根据数组长度和当前索引返回正确的索引
    const activeLength = this.activeQuestions.length;
    const currentIndex = this.swiperCurrentIndex;
    
    // 计算当前题目在activeQuestions中的位置
    let returnIndex = 1; // 默认返回中间索引
    
    if (activeLength === 1) {
      returnIndex = 0;
    } else if (activeLength === 2) {
      // 当activeLength为2时，根据当前索引决定返回值
      // 检查当前题目是否在activeQuestions中
      const currentQuestion = this.swiperList[currentIndex];
      const activeIndex = this.activeQuestions.findIndex(item => item.uid === currentQuestion.uid);
      returnIndex = activeIndex >= 0 ? activeIndex : 1;
    }
    
    console.log('[swipeCurrent] 程序化跳转:', {
      needProgrammaticJump: this.needProgrammaticJump,
      swiperCurrentIndex: currentIndex,
      activeQuestionsLength: activeLength,
      returning: returnIndex,
      expectedQuestionNum: currentIndex + 1
    });
    
    return returnIndex;
  }
  return undefined;
}
```

## 问题分析

在 AiEdit.vue 文件中，识别试题后没有根据题型自动设置分值和积分。用户的需求是：
- 单选题、判断题：默认1分值和1积分
- 多选题：默认2分值和2积分

## 解决方案

### 修改 parseRecognitionResult 方法

在解析识别结果时，根据题型自动设置分值和积分：

```javascript
// 根据题型设置默认分值和积分
let defaultScore = 1
let defaultIntegral = 1

switch (examType) {
  case 1: // 单选题
  case 3: // 判断题
    defaultScore = 1
    defaultIntegral = 1
    break
  case 2: // 多选题
    defaultScore = 2
    defaultIntegral = 2
    break
  case 4: // 填空题
  case 5: // 问答题
    defaultScore = 2
    defaultIntegral = 2
    break
  case 6: // 案例题
  case 7: // 完形填空
    defaultScore = 5
    defaultIntegral = 5
    break
  default:
    defaultScore = 1
    defaultIntegral = 1
}

// 更新分值和积分
this.score = defaultScore
this.integral = defaultIntegral
```

## 预期结果

识别试题后，系统会根据题型自动设置合适的分值和积分：
- 单选题、判断题：1分、1积分
- 多选题：2分、2积分
- 填空题、问答题：2分、2积分
- 案例题、完形填空：5分、5积分

## 实现付费资源下载的积分/广告选择功能

### 1. 修改 `downloadClick` 方法逻辑

当 `free_state=2` 时，使用图鸟UI的操作菜单提示用户选择下载方式：

```javascript
downloadClick() {
    // 检查是否为付费资源
    if (this.resourceContent.free_state === '2') {
        // 使用图鸟UI操作菜单，让用户选择使用积分或看广告
        this.$func.tnActionSheet({
            title: '选择下载方式',
            itemList: [
                { text: `使用积分下载 (${this.resourceContent.money}积分)`, value: 'points' },
                { text: '观看广告下载', value: 'ad' }
            ],
            cancelText: '取消',
            success: (res) => {
                if (res.index === 0) {
                    // 使用积分下载
                    this.downloadByPoints();
                } else if (res.index === 1) {
                    // 观看广告下载
                    this.downloadByAd();
                }
            }
        });
        return;
    }
    
    // 原有的下载逻辑...
}
```

### 2. 实现积分下载流程

```javascript
downloadByPoints() {
    // 调用积分下载API
    this.$api.apiResourceDownloadByPoints({
        uid: this.resourceContent.uid
    }).then(res => {
        if (res.code === 1) {
            // 积分下载成功
            this.$func.showToast('下载成功，链接已复制到剪贴板');
            this.$func.setClipboardData(res.data.file_url);
        } else {
            // 积分不足或其他错误
            this.$func.showToast(res.msg);
        }
    }).catch(error => {
        console.error('积分下载失败:', error);
        this.$func.showToast('积分下载失败，请重试');
    });
}
```

### 4. 服务端实现积分下载API

需要创建一个新的API端点，处理积分下载逻辑：

```php
// 服务端积分下载API
export function apiResourceDownloadByPoints(params) {
    return request.post({
        url: '/resource.download/byPoints',
        params
    });
}
```

### 5. 服务端逻辑

1. 检查用户积分是否足够
2. 扣除用户相应积分
3. 记录下载记录
4. 返回下载链接

## 问题分析

**现象：**
- 从第57题向左滑动，题号显示56，但内容显示55题
- 一次滑动跳过了两道题

**根本原因：**

在 `handleSwiperTransition` 方法中（第2918-2926行）有一个错误的边界检查：

```javascript
if (currentRealIndex === listLength - 1 && dx > 0) {
  // 已经在最后一题，不能再向左滑（下一题）
  return;
}
```

当用户在第57题（最后一题）向左滑动时：
- `dx > 0` 表示向左滑（想要看下一题）
- 但实际上向左滑应该看第56题（上一题）
- 这个边界检查错误地阻止了滑动
- 导致 `transitionQuestionIndex` 没有被正确设置
- 在 `handleSwiperChange` 中使用备用方案计算出错误的索引

## 修复方案

**移除 `handleSwiperTransition` 中的错误边界检查**

因为：
1. `handleSwiperChange` 中的 `isValidTransition` 已经有正确的验证逻辑
2. 边界检查的 dx 方向判断与实际需求相反
3. 备用方案（根据 swiperIndex 计算）会正确处理边界情况

# 将TenantExamCountdownFollow替换为userSubscribe的实现计划

## 1. 分析数据表结构
根据`la_user_subscribe.sql`，统一订阅表的主要字段：
- `user_id`：用户ID
- `type`：订阅类型（countdown, version_update）
- `related_id`：关联ID（对应倒计时ID）
- `template_id`：模板ID
- `subscribe_status`：订阅状态（1-已订阅，0-未订阅）
- `subscribe_time`：授权时间戳（毫秒）
- `is_pushed`：是否已推送（0=未推送 1=已推送）

## 2. 替换步骤

### 2.1 修改模型引用
- 将`use app\common\model\exam\countdown\TenantExamCountdownFollow;`替换为`use app\common\model\user\userSubscribe;`

### 2.2 调整字段映射
| 旧字段（TenantExamCountdownFollow） | 新字段（userSubscribe） | 条件 |
|------------------------------------|------------------------|------|
| `countdown_id`                     | `related_id`           | `type='countdown'` |
| `user_id`                          | `user_id`              | 保持不变 |

### 2.3 替换方法调用
1. **isFollowed()**：检查用户是否已订阅
   - 旧：`TenantExamCountdownFollow::isFollowed($userId, $item['id'])`
   - 新：`userSubscribe::where(['user_id' => $userId, 'type' => 'countdown', 'related_id' => $item['id']])->find() ? 1 : 0`

2. **getFollowCount()**：获取订阅数量
   - 旧：`TenantExamCountdownFollow::getFollowCount($item['id'])`
   - 新：`userSubscribe::where(['type' => 'countdown', 'related_id' => $item['id']])->count()`

3. **follow()**：订阅操作
   - 旧：`TenantExamCountdownFollow::follow($userId, $id)`
   - 新：创建一条type='countdown'的记录

4. **unfollow()**：取消订阅
   - 旧：`TenantExamCountdownFollow::unfollow($userId, $id)`
   - 新：删除type='countdown'的记录

5. **whereIn()**：批量查询
   - 旧：`TenantExamCountdownFollow::whereIn('countdown_id', $countdownIds)`
   - 新：`userSubscribe::whereIn('related_id', $countdownIds)->where('type', '=', 'countdown')`

6. **delete()**：删除订阅记录
   - 旧：`TenantExamCountdownFollow::where(['countdown_id' => $id])->delete()`
   - 新：`userSubscribe::where(['type' => 'countdown', 'related_id' => $id])->delete()`

### 2.4 添加必要的辅助方法
由于userSubscribe模型可能没有提供现成的isFollowed、getFollowCount等方法，我需要在CountdownLogic类中添加这些辅助方法，或者直接使用查询构建器。

# 自定义拖拽调整科目顺序功能

## 问题分析
1. **tn-drag组件不可用**：需要替换现有的tn-drag组件，自己实现拖拽功能
2. **拖拽功能要求**：按住科目项可拖动调整顺序，支持删除科目
3. **保持原有UI**：保持现有的布局和样式不变
4. **支持的数据结构**：与现有localMySubjects数据结构兼容

## 实现方案

### 1. 移除tn-drag组件
- 删除`<tn-drag>`标签及相关属性
- 移除onDragChange方法

### 2. 实现自定义拖拽逻辑
- 使用HTML5的拖放API（draggable、dragstart、dragenter、dragover、dragleave、drop、dragend）
- 或使用触摸事件（touchstart、touchmove、touchend）实现移动端拖拽
- 实现拖拽状态管理

### 3. 实现拖拽相关方法
- `handleDragStart`：记录拖拽起始位置和数据
- `handleDragEnter`：处理拖拽进入事件，显示拖拽目标位置
- `handleDragOver`：处理拖拽悬停事件，阻止默认行为
- `handleDragLeave`：处理拖拽离开事件，移除拖拽样式
- `handleDrop`：处理拖拽放置事件，调整科目顺序
- `handleDragEnd`：处理拖拽结束事件，清理拖拽状态

### 4. 实现拖拽UI反馈
- 添加拖拽过程中的视觉反馈
- 支持拖拽位置的指示器
- 保持与原有UI风格一致

### 5. 保持原有功能
- 保留科目删除功能
- 保留拖拽调整顺序功能
- 保留自动保存功能

## 实现步骤

1. **修改模板结构**：移除tn-drag组件，使用v-for渲染科目列表
2. **添加拖拽属性**：为科目项添加draggable属性
3. **绑定拖拽事件**：为科目项绑定拖拽相关事件
4. **实现拖拽方法**：在methods中实现拖拽逻辑
5. **添加拖拽样式**：在style中添加拖拽相关样式
6. **测试拖拽功能**：确保拖拽调整顺序功能正常工作

## 预期效果
- 按住科目项可拖动调整顺序
- 拖拽过程中有视觉反馈
- 拖拽结束后科目顺序更新
- 保持原有的UI样式
- 与现有功能兼容

## 技术要点
- 使用HTML5拖放API实现拖拽功能
- 实现拖拽状态管理
- 实现科目顺序调整逻辑
- 保持与现有代码的兼容性

## 问题分析

在 AiEdit.vue 文件中，当前的大模型提示词是硬编码在 `callDoubaoAPI` 方法中的，用户无法查看、编辑或保存自定义提示词。

用户的需求是：添加一个功能，让用户可以查看、编辑和保存提示词，弹窗样式参考 `set.vue` 中的个人备注弹窗。

## 解决方案

### 1. 在 data() 中添加相关数据

```javascript
// 提示词编辑
showPromptModal: false,
defaultPrompt: '请识别这张图片中的试题题，提取出题型（单选题、多选题、判断题、填空题、问答题、案例题）、题干、选项（如果有）、正确答案和解析内容，和笔记第一条的内容部分（没有笔记的话就不识别，不含用户名），用 JSON 格式输出。题型字段为exam_type_name。',
customPrompt: '', // 用户自定义的提示词
```

### 2. 在模板中添加按钮和弹窗

**按钮位置**：在"上传试题图片"标题旁边添加一个"编辑提示词"按钮

**弹窗内容**：
- 标题："编辑识别提示词"
- 文本框：用于编辑提示词内容
- 按钮：取消、重置默认、保存

### 3. 添加相关方法

- `openPromptModal()`：打开弹窗，加载已保存的提示词
- `closePromptModal()`：关闭弹窗
- `savePrompt()`：保存提示词到本地存储
- `resetPrompt()`：重置为默认提示词

### 4. 修改 callDoubaoAPI 方法

将硬编码的 prompt 改为使用 `this.customPrompt || this.defaultPrompt`

### 5. 在 onLoad 中加载已保存的提示词

从本地存储加载用户之前保存的提示词

## 预期结果

用户可以：
1. 点击"编辑提示词"按钮打开弹窗
2. 查看当前的提示词内容
3. 编辑提示词内容
4. 保存自定义提示词（保存到本地存储，下次打开页面时自动加载）
5. 重置为默认提示词
6. 识别时使用自定义提示词（如果有）或默认提示词

## 🎯 推荐配置方案（三层保障）

### **第一层：宝塔主定时任务（必须配置）⭐⭐⭐**

这是整个定时任务系统的基础，必须配置！

#### 配置步骤：

1. **登录宝塔面板**

2. **计划任务 → 添加计划任务**

3. **配置参数**：
   ```
   任务类型：Shell脚本
   任务名称：系统主定时任务
   执行周期：每分钟 N * * * *
   
   脚本内容：
   cd /www/wwwroot/tutu/server && php think crontab >> /www/wwwroot/logs/crontab.log 2>&1
   ```

4. **保存并启用**

#### 验证是否生效：
```bash
# SSH连接服务器，查看日志
tail -f /www/wwwroot/logs/crontab.log

# 或在宝塔面板 → 文件 → 查看日志文件
```

---

### **第二层：管理后台排行榜任务（推荐配置）⭐⭐**

#### 配置步骤：

1. **登录系统后台**

2. **系统设置 → 定时任务 → 添加任务**

3. **配置参数**：
   ```
   任务名称：排行榜刷新
   执行命令：ranking:refresh
   Cron表达式：0 0 * * *
   备注：每日00:00:00刷新所有排行榜（日榜/周榜/月榜/总榜）
   状态：启用
   ```

4. **保存**

#### 工作原理：
```
宝塔Crontab（每分钟）
    ↓
执行 php think crontab
    ↓
检查后台定时任务表
    ↓
发现 ranking:refresh 到点
    ↓
执行排行榜刷新
```

---

### **第三层：宝塔直接触发排行榜（备用保障）⭐**

**可选配置**，作为备用保障机制。如果后台定时任务异常，这个会兜底执行。

#### 配置步骤：

1. **宝塔面板 → 计划任务 → 添加计划任务**

2. **配置参数**：
   ```
   任务类型：Shell脚本
   任务名称：排行榜刷新备用
   执行周期：每1天 0时30分（错开30分钟，避免与主任务冲突）
   
   脚本内容：
   cd /www/wwwroot/tutu/server && php think ranking:refresh >> /www/wwwroot/logs/ranking_backup.log 2>&1
   ```

3. **保存并启用**

## 🔒 防重复执行机制

已在代码中添加**执行锁**，即使同时配置多个触发方式也不会重复执行！

### 工作原理：

```php
// 检查锁文件
if (file_exists('ranking_refresh.lock')) {
    // 如果1小时内有锁，跳过执行
    return;
}

// 创建锁文件
file_put_contents('ranking_refresh.lock', date('Y-m-d H:i:s'));

// 执行任务...

// 执行完成，删除锁文件
unlink('ranking_refresh.lock');
```

### 特点：
- ✅ 1小时内只能执行一次
- ✅ 执行完成自动解锁
- ✅ 异常退出超过1小时后自动清理锁
- ✅ 支持多个触发源同时配置

## 🔧 常见问题排查

### Q1: 宝塔主定时任务不执行？

**检查步骤：**
```bash
# 1. 检查宝塔crontab是否正常
crontab -l | grep crontab

# 2. 检查PHP路径是否正确
which php

# 3. 手动执行测试
cd /www/wwwroot/tutu/server && php think crontab

# 4. 检查日志权限
ls -la /www/wwwroot/logs/
```

**解决方案：**
- 确保PHP路径正确（可能需要 `/usr/bin/php` 或 `/www/server/php/80/bin/php`）
- 确保日志目录有写权限：`chmod 755 /www/wwwroot/logs`
- 检查宝塔面板是否正常运行

---

### Q2: 后台任务不执行？

**检查步骤：**
1. 确认主定时任务正在运行
2. 检查后台任务表 `la_crontab`
3. 查看任务状态是否启用
4. 查看错误日志

**SQL检查：**
```sql
-- 查看定时任务配置
SELECT * FROM la_crontab WHERE command = 'ranking:refresh';

-- 检查状态
-- status: 1=启用, 0=禁用, 2=错误
```

---

### Q3: 任务重复执行？

**原因：**
同时配置了后台任务和宝塔直接触发，且执行时间相同。

**解决方案：**
1. 保留后台任务（00:00执行）
2. 修改宝塔备用任务为 00:30（错开30分钟）
3. 执行锁会自动防止1小时内重复执行

---

### Q4: 执行锁不释放？

**症状：**
连续提示"任务正在执行中"

**解决方案：**
```bash
# 手动删除锁文件
rm -f /www/wwwroot/tutu/server/runtime/ranking_refresh.lock

# 或等待1小时自动过期
```

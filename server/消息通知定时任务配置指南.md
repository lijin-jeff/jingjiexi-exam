# 消息通知定时任务配置指南

## 📋 定时任务概述

消息通知系统包含以下定时任务：

| 任务名称 | 命令 | 执行频率 | 功能说明 |
|---------|------|---------|---------|
| 会员到期提醒 | `message:vip-remind` | 每天 09:00 | 提前3天、1天提醒会员到期，自动更新过期状态 |
| 每周学习总结 | `message:weekly-summary` | 每周一 08:00 | 统计上周学习数据，发送学习总结通知 |

---

## 🚀 快速配置（推荐方案）

### 方案一：使用系统后台配置（推荐）⭐⭐⭐

#### 1. 登录系统后台

访问后台管理系统

#### 2. 添加定时任务

**路径**：系统设置 → 定时任务 → 添加任务

#### 3. 配置会员到期提醒任务

```
任务名称：会员到期提醒
执行命令：message:vip-remind
Cron表达式：0 9 * * *
备注：每天09:00检查会员到期情况，提前3天和1天发送提醒
状态：启用
```

#### 4. 配置每周学习总结任务

```
任务名称：每周学习总结
执行命令：message:weekly-summary
Cron表达式：0 8 * * 1
备注：每周一08:00统计上周学习数据并发送总结通知
状态：启用
```

#### 5. 保存并启用

点击保存后，任务将自动按照Cron表达式执行。

## 📊 Cron表达式说明

| 表达式 | 说明 | 执行时间 |
|-------|------|---------|
| `0 9 * * *` | 每天09:00 | 每天上午9点 |
| `0 8 * * 1` | 每周一08:00 | 每周一上午8点 |
| `*/5 * * * *` | 每5分钟 | 每隔5分钟 |
| `0 */2 * * *` | 每2小时 | 每2小时整点 |
| `0 0 1 * *` | 每月1号 | 每月1号凌晨 |

### Cron表达式格式

```
*    *    *    *    *
┬    ┬    ┬    ┬    ┬
│    │    │    │    │
│    │    │    │    └─── 星期几 (0-7, 0和7都代表周日)
│    │    │    └──────── 月份 (1-12)
│    │    └───────────── 日期 (1-31)
│    └────────────────── 小时 (0-23)
└─────────────────────── 分钟 (0-59)
```

## 🔒 执行锁机制

所有定时任务都内置了执行锁，防止重复执行：

### 工作原理

```php
// 检查锁文件
if (file_exists('message_vip_remind.lock')) {
    // 如果30分钟内有锁，跳过执行
    return;
}

// 创建锁文件
file_put_contents('message_vip_remind.lock', date('Y-m-d H:i:s'));

// 执行任务...

// 执行完成，删除锁文件
unlink('message_vip_remind.lock');
```

### 特点

- ✅ 会员提醒：30分钟内只能执行一次
- ✅ 每周总结：2小时内只能执行一次
- ✅ 执行完成自动解锁
- ✅ 异常退出超时自动清理锁
- ✅ 支持多个触发源同时配置

## 🎯 任务详细说明

### 1. 会员到期提醒 (message:vip-remind)

#### 功能说明

- 检查即将到期的会员（提前3天、1天）
- 发送到期提醒消息
- 自动更新已过期会员状态（vip_state: 3 → 2）

#### 提醒规则

| 提醒时间 | 触发条件 | 消息内容 |
|---------|---------|---------|
| 提前3天 | vip_endTime在3天后到期 | "您的会员将在 3 天后到期，请及时续费" |
| 提前1天 | vip_endTime在1天后到期 | "您的会员将在 1 天后到期，请及时续费" |

#### 执行逻辑

```
1. 查询3天后到期的会员 → 发送提醒
2. 查询1天后到期的会员 → 发送提醒
3. 查询已过期的会员 → 更新状态为过期(2)
```

#### 相关文件

- 命令类：[MessageVipRemind.php](file:///c:/Users/44343/tutu/tutu/server/app/common/command/MessageVipRemind.php)
- 服务类：[MessageService.php](file:///c:/Users/44343/tutu/tutu/server/app/common/logic/user/MessageService.php)

---

### 2. 每周学习总结 (message:weekly-summary)

#### 功能说明

- 每周一统计上周（周一至周日）的学习数据
- 发送学习总结通知给活跃用户
- 包含考试次数、答题数量、正确率等统计

#### 统计内容

| 统计项 | 说明 |
|-------|------|
| 考试次数 | 上周完成的考试数量 |
| 答题总数 | 上周答题的总数量 |
| 答对题数 | 上周答对的题目数量 |
| 正确率 | 答对题数 / 答题总数 × 100% |

#### 执行逻辑

```
1. 计算上周时间范围（上周一00:00 - 上周日23:59）
2. 查询活跃用户（上周有考试记录的用户）
3. 统计每个用户的学习数据
4. 发送学习总结通知
```

#### 消息示例

```
本周学习总结
您上周完成了 15 次考试，共答题 300 道，
答对 255 道，正确率 85.0%。继续加油！
```

#### 相关文件

- 命令类：[MessageWeeklySummary.php](file:///c:/Users/44343/tutu/tutu/server/app/common/command/MessageWeeklySummary.php)
- 服务类：[MessageService.php](file:///c:/Users/44343/tutu/tutu/server/app/common/logic/user/MessageService.php)

## 🔧 常见问题排查

### Q1: 定时任务不执行？

**检查步骤：**

1. **验证命令是否注册**
```bash
cd /www/wwwroot/tutu/server
php think
# 查看命令列表，应该能看到 message:vip-remind 和 message:weekly-summary
```

2. **检查主定时任务**
```bash
# 确保主定时任务正在运行
tail -f /www/wwwroot/logs/crontab.log
```

3. **查看后台任务配置**
```sql
-- 查看定时任务配置
SELECT * FROM la_crontab WHERE command LIKE 'message:%';
-- 检查 status 字段：1=启用, 0=禁用
```

4. **手动执行测试**
```bash
php think message:vip-remind
php think message:weekly-summary
```

---

### Q2: 没有收到提醒消息？

**检查步骤：**

1. **检查会员数据**
```sql
-- 查看即将到期的会员
SELECT id, nickname, vip_state, FROM_UNIXTIME(vip_endTime) as end_time
FROM la_user 
WHERE vip_state = 3 
  AND vip_endTime BETWEEN UNIX_TIMESTAMP(NOW() + INTERVAL 1 DAY) 
  AND UNIX_TIMESTAMP(NOW() + INTERVAL 3 DAY);
```

2. **检查消息记录**
```sql
-- 查看消息发送记录
SELECT * FROM la_user_message 
WHERE sub_type = 'vip_remind' 
ORDER BY create_time DESC LIMIT 10;
```

3. **查看执行日志**
```bash
tail -f /www/wwwroot/logs/message_vip_remind.log
```

---

### Q3: 任务执行提示"正在执行中"？

**原因：**执行锁未释放

**解决方案：**

```bash
# 手动删除锁文件
rm -f /www/wwwroot/tutu/server/runtime/message_vip_remind.lock
rm -f /www/wwwroot/tutu/server/runtime/message_weekly_summary.lock

# 或等待锁自动过期
# 会员提醒锁：30分钟后自动过期
# 每周总结锁：2小时后自动过期
```

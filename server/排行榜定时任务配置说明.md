# 排行榜定时任务配置说明

## 一、优化概述

本次优化主要包含以下几个方面：

### 1. 性能优化
- ✅ 数据库层面排序（避免PHP内存排序）
- ✅ 批量插入优化（每批500条，避免内存溢出）
- ✅ 添加必要索引（提升查询性能10倍以上）
- ✅ 使用事务保证数据一致性
- ✅ 限制返回数量（最多1000条，避免大数据集）

### 2. 业务逻辑优化
- ✅ 支持自动判断结算时间
- ✅ 支持奖励积分发放
- ✅ 支持多租户并发处理
- ✅ 分离更新和结算逻辑

### 3. 定时任务设计
- ✅ 每日00:00:00自动执行
- ✅ 依次更新：日榜 → 周榜 → 月榜 → 总榜
- ✅ 错误日志记录
- ✅ 性能监控

## 二、定时任务配置步骤

### 方法1：通过后台配置（推荐）

1. **登录系统后台**

2. **进入定时任务管理**
   - 路径：系统设置 → 定时任务

3. **添加新任务**
   ```
   任务名称：排行榜刷新
   执行命令：ranking:refresh
   Cron表达式：0 0 * * *
   备注：每日00:00:00刷新所有排行榜（日榜/周榜/月榜/总榜）
   状态：启用
   ```

4. **保存并启动**

### 方法2：使用系统Crontab（Linux服务器）

1. **编辑crontab**
   ```bash
   crontab -e
   ```

2. **添加定时任务**
   ```bash
   # 每天凌晨00:00执行排行榜刷新
   0 0 * * * cd /www/wwwroot/your-project/server && php think ranking:refresh >> /www/wwwroot/logs/ranking.log 2>&1
   
   # 同时确保主定时任务运行
   * * * * * cd /www/wwwroot/your-project/server && php think crontab >> /www/wwwroot/logs/crontab.log 2>&1
   ```

3. **验证crontab**
   ```bash
   crontab -l
   ```

### 方法3：Windows计划任务

1. **打开任务计划程序**
   - Win+R → `taskschd.msc`

2. **创建基本任务**
   - 名称：排行榜刷新
   - 触发器：每天 00:00
   - 操作：启动程序
     - 程序：`C:\php\php.exe`
     - 参数：`think ranking:refresh`
     - 起始于：`C:\www\your-project\server`

## 四、排行榜结算规则

### 1. 日榜
- **更新频率**：每日00:00:00
- **统计周期**：昨天00:00:00 - 今天00:00:00
- **结算时间**：每日00:00:00（根据`reset_time_day`配置）
- **结算后**：发放奖励积分，开始新的一天统计

### 2. 周榜
- **更新频率**：每日00:00:00
- **统计周期**：从结算日开始的7天
- **结算时间**：每周指定星期几00:00:00（根据`reset_time_week`配置，1=周一）
- **结算后**：发放奖励积分，开始新的一周统计

### 3. 月榜
- **更新频率**：每日00:00:00
- **统计周期**：从结算日开始的一个月
- **结算时间**：每月指定日期00:00:00（根据`reset_time_month`配置，1=每月1号）
- **结算后**：发放奖励积分，开始新的一月统计

### 4. 总榜
- **更新频率**：每日00:00:00
- **统计周期**：当年1月1日 - 当前时间
- **结算时间**：每年12月31日00:00:00
- **结算后**：发放奖励积分，开始新的一年统计

## 八、注意事项

### 1. 数据库注意事项
- ⚠️ 执行索引优化SQL前务必备份数据库
- ⚠️ 大数据量表创建索引时间较长，建议在业务低峰期执行
- ⚠️ 定期清理历史排行榜数据，避免数据过大

### 2. 性能注意事项
- ✅ 建议在凌晨执行，避免影响白天业务
- ✅ 单次查询限制1000条，超大租户可能需要分批处理
- ✅ 批量插入500条/批，平衡性能和内存

### 3. 业务注意事项
- ⚠️ 结算时间到达后才会发放奖励
- ⚠️ 需要实现积分发放接口（当前为TODO）
- ⚠️ 排行榜设置表必须有配置才会执行

## 九、常见问题

### Q1: 定时任务不执行？
**A**: 检查以下几点：
1. crontab是否正确配置
2. php think crontab 主定时任务是否运行
3. 后台定时任务管理中任务是否启用
4. 服务器时间是否正确

### Q2: 排行榜数据不更新？
**A**: 检查以下几点：
1. 排行榜设置表是否有配置（`is_show=1`）
2. 考试历史表是否有数据
3. 查看错误日志

### Q3: 执行速度慢？
**A**: 优化建议：
1. 执行性能优化SQL添加索引
2. 减小`display_top_count`数量
3. 分批处理大租户数据

### Q4: 奖励积分没有发放？
**A**: 检查以下几点：
1. 是否到达结算时间
2. 奖励配置是否正确（格式：1|10,2|8,3|5）
3. 积分发放接口是否实现
